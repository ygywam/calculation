수직선 위의 속도와 가속도

🚀

33차시 학습 목표

미분을 활용하여 위치 함수의 순간변화율인 속도($v$)와 속도의 순간변화율인 가속도($a$)의 정의를 이해하고, 속도의 부호와 0이 되는 순간을 통해 물체의 운동 방향 전환과 최고점, 정차 조건을 완벽히 분석합니다.

생각 열기

속도와 가속도는 어떻게 구할까?

교과서 101쪽

직선 도로 위를 달리는 어떤 자동차의 출발한 지 $t$초 후의 위치를 $x\text{ m}$라고 하면
$x = t^2 + 2t \quad (0 \le t \le 10)$
라고 한다. $t = 1$에서 $t = 1 + \Delta t$까지 변할 때의 $x$의 평균변화율과 $\Delta t \to 0$일 때의 극한값(순간속도)을 구해보자.

✏️ 평균변화율 및 극한 계산 연습장
m/s
💡 생각 열기 풀이:
1) 평균변화율: $\frac{\Delta x}{\Delta t} = \frac{(1+\Delta t)^2 + 2(1+\Delta t) - (1+2)}{\Delta t} = \frac{\Delta t^2 + 4\Delta t}{\Delta t} = \Delta t + 4$
2) 극한값 (순간속도): $v = \lim_{\Delta t \to 0} (\Delta t + 4) = \mathbf{4\text{ m/s}}$
3) 이것은 위치 함수 $x = f(t)$를 미분한 도함수 $f'(1) = 2(1) + 2 = 4\text{ m/s}$와 완벽히 일치합니다!

속도, 가속도 및 운동 방향의 원리

1

속도 $v$와 속력 $|v|$

위치 $x = f(t)$의 시각 $t$에 대한 순간변화율입니다.
$v = \frac{dx}{dt} = f'(t)$

💡 속도의 크기(절댓값) $|v|$를 속력이라고 부릅니다.
2

가속도 $a$

속도 $v$의 시각 $t$에 대한 순간변화율입니다.
$a = \frac{dv}{dt} = f''(t)$

💡 위치를 2번 미분한 것이 가속도입니다. (단위: $\text{m/s}^2$)
3

운동 방향의 전환

• $v > 0$: 양의 방향으로 움직임 (우측/위)
• $v < 0$: 음의 방향으로 움직임 (좌측/아래)
• $v = 0$이고 좌우에서 부호 전환:
점 P가 운동 방향을 바꾸는 순간!

예제 1

수직선 위를 움직이는 점의 속도, 가속도, 운동 방향

교과서 102쪽

원점을 출발하여 수직선 위를 움직이는 점 P의 시각 $t$에서의 위치 $x$가 $x = t^2 - 6t$일 때, 다음을 구하시오.
⑴ 점 P의 $t = 1$에서의 속도와 가속도
⑵ 점 P가 운동 방향을 바꿀 때의 시각

⑴ 점 P의 시각 $t$에서의 속도를 $v$, 가속도를 $a$라고 하면
$v = \frac{dx}{dt} = 2t - 6, \quad a = \frac{dv}{dt} = 2$
따라서 $t = 1$에서의 점 P의 속도와 가속도는
$v = 2(1) - 6 = \mathbf{-4}, \quad a = \mathbf{2}$
⑵ 점 P가 운동 방향을 바꾸는 순간의 속도는 $0$이므로
$v = 2t - 6 = 0$에서 $t = 3$
$0 < t < 3$이면 $v < 0$, $t > 3$이면 $v > 0$이므로 점 P가 운동 방향을 바꿀 때의 시각은 3입니다.

문제 2 모형 기차의 제동 감속 운동
교과서 103쪽

어느 모형 전시회에서 철길을 따라 모형 기차가 달리고 있다. 모형 기차가 정차하기 위하여 제동을 건 후 $t$초 동안 움직인 거리 $x\text{ cm}$가 $x = -\frac{5}{2}t^2 + 15t$일 때, 다음을 구하시오.
⑴ 모형 기차가 제동을 건 후 1초가 지났을 때의 속도
⑵ 모형 기차가 제동을 건 후 정지할 때까지 걸린 시간과 움직인 거리

✏️ v = -5t + 15 미분 및 정지 조건 연습장
💡 상세 해설:
1) $v = \frac{dx}{dt} = -5t + 15$
2) $t = 1$일 때의 속도: $v = -5(1) + 15 = \mathbf{10\text{ cm/s}}$
3) 정지할 때는 속도가 $0$이므로: $-5t + 15 = 0 \implies \mathbf{t = 3\text{초}}$
4) $t = 3$일 때 움직인 제동 거리:
$x(3) = -\frac{5}{2}(9) + 15(3) = -\frac{45}{2} + 45 = \frac{45}{2} = \mathbf{22.5\text{ cm}}$

"$t = 1$일 때, 점 P의 속도는 0이야."

✓ 이유: $t = 1$에서 위치 함수 $x = f(t)$가 극댓값을 가지므로 접선의 기울기 $f'(1) = 0$이 되어 속도는 $0$입니다.
수연 👩‍🎓 거짓 (오류!)

"$0 < t < 6$에서 점 P의 운동 방향은 총 3번 바뀌었어."

준혁 🧑‍🎓 거짓 (오류!)

"$0 < t < 6$에서 출발 지점으로부터 가장 멀리 떨어져 있는 순간은 $t = 3$일 때야."

⚠️ 오류 수정: 출발 지점(원점)으로부터의 거리는 $|x| = |f(t)|$입니다. $t=3$에서는 $x=0$이므로 출발 지점에 다시 돌아온 순간입니다!

처음으로 운동 방향을 바꾸는 순간의 위치

교과서 104쪽

원점을 출발하여 수직선 위를 움직이는 점 P의 시각 $t$에서의 위치 $x$가 $x = \frac{1}{3}t^3 - 3t^2 + 8t$일 때, 점 P가 출발 후 처음으로 운동 방향을 바꾸는 순간의 위치를 구하시오.

✏️ v = t² - 6t + 8 = 0 및 위치 x(t) 계산 연습장
구한 위치를 선택하세요:
💡 상세 해설:
1) $v = \frac{dx}{dt} = t^2 - 6t + 8 = (t - 2)(t - 4) = 0 \implies t = 2$ 또는 $t = 4$
2) 출발 후 처음으로 운동 방향을 바꾸는 순간은 $t = 2$초입니다.
3) $t = 2$일 때의 위치:
$x(2) = \frac{1}{3}(8) - 3(4) + 8(2) = \frac{8}{3} - 12 + 16 = \frac{8}{3} + 4 = \mathbf{\frac{20}{3}}$
스스로 확인 04

자동차 제동 거리와 미정계수 k 결정

교과서 104쪽

직선 도로 위를 달리는 어떤 자동차가 제동이 걸린 후 $t$초 동안 움직인 거리 $x\text{ m}$가 $x = -20t^2 + kt$이다. 제동이 걸린 후 이 자동차가 정지할 때까지 움직인 거리가 $45\text{ m}$일 때, 양수 $k$의 값을 구하시오.

✏️ 정지 조건 v = 0 및 k에 대한 방정식 연습장
💡 상세 풀이:
1) 정지할 때의 속도는 $0$이므로: $v = \frac{dx}{dt} = -40t + k = 0 \implies t = \frac{k}{40}$
2) 이때까지 움직인 거리가 $45\text{ m}$이므로:
$x\left(\frac{k}{40}\right) = -20\left(\frac{k}{40}\right)^2 + k\left(\frac{k}{40}\right) = -\frac{k^2}{80} + \frac{k^2}{40} = \frac{k^2}{80} = 45$
3) $k^2 = 80 \times 45 = 3600 \implies k > 0$이므로 k = 60입니다.
스스로 확인 05

두 점 P, Q가 서로 반대 방향으로 움직이는 시간 범위

교과서 104쪽

원점을 출발하여 수직선 위를 움직이는 두 점 P, Q의 시각 $t$에서의 위치가 각각
$f(t) = 2t^2 - 4t, \quad g(t) = t^2 - 6t$
일 때, 두 점 P, Q가 서로 반대 방향으로 움직이는 $t$의 값의 범위를 구하시오.

✏️ v_P(t) × v_Q(t) < 0 부등식 연습장
$t$의 값의 범위를 선택하세요:
💡 상세 해설:
1) 점 P의 속도: $v_P = f'(t) = 4t - 4 = 4(t - 1)$
2) 점 Q의 속도: $v_Q = g'(t) = 2t - 6 = 2(t - 3)$
3) 두 점이 서로 반대 방향으로 움직이려면 두 속도의 부호가 반대이어야 하므로:
$v_P \times v_Q < 0 \implies 8(t - 1)(t - 3) < 0 \implies \mathbf{1 < t < 3}$

수직선 위를 움직이는 두 점 $P(2t^2 - 4t)$와 $Q(t^2 - 6t)$입니다. 슬라이더를 움직여 $t$를 변화시키면서 $1 < t < 3$초 구간에서 P(우측 $\rightarrow$)와 Q(좌측 $\leftarrow$)가 서로 반대 방향으로 움직이는 현상을 실시간 화살표로 관찰하세요!

t = 2.0 s
0 s 반대 방향: 1 < t < 3 4.5 s
⏱️ 두 점 실시간 상태 서로 반대 방향! ↔️
점 P 속도 v_P: +4.0 (우측 이동)
점 Q 속도 v_Q: -2.0 (좌측 이동)
운동 방향 관계: 서로 반대 방향 (1 < t < 3)
수학적 원리: $t=1$에서 점 P가 운동 방향을 바꾸고, $t=3$에서 점 Q가 운동 방향을 바꿉니다. 따라서 그 사이인 $1 < t < 3$에서 두 점의 속도 부호가 반대가 됩니다.
생각 키우는 문제 06

스카이다이버의 자유 낙하와 낙하산 전개 속도

교과서 104쪽

어떤 스카이다이버가 지상 $4180\text{ m}$ 높이에서 뛰어내려 낙하산을 펼치기 전까지 자유 낙하를 할 때, 뛰어내린 지 $t$초 후의 높이 $h\text{ m}$가 $h = 4180 - 5t^2$이라고 한다. 다음을 구하시오.
⑴ 뛰어내린 지 2초 후의 속도 (m/s)
⑵ 지상 $800\text{ m}$에서 낙하산을 펼치는 순간의 스카이다이버의 속도 (m/s)

✏️ v = -10t 및 4180 - 5t² = 800 계산 연습장
m/s
m/s
💡 상세 풀이:
1) 속도 함수: $v = \frac{dh}{dt} = -10t$
2) 2초 후의 속도: $v(2) = -10(2) = \mathbf{-20\text{ m/s}}$
3) 지상 $800\text{ m}$에서의 시각: $4180 - 5t^2 = 800 \implies 5t^2 = 3380 \implies t^2 = 676 \implies \mathbf{t = 26\text{초}}$
4) 이때의 속도: $v(26) = -10(26) = \mathbf{-260\text{ m/s}}$ (낙하 방향이므로 음수!)
