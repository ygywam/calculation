03. 정적분 (Definite Integral)

곡선 아래의 '부호 있는 넓이(Signed Area)' $S_1 - S_2$로부터 출발하여, 미분과 적분을 대통합하는 미적분의 기본정리(FTC) $\int_a^b f(x)\,dx = F(b) - F(a)$를 확립합니다. 구간 분할 및 절댓값 정적분부터 대칭 구간 $[-a, a]$의 우함수·기함수 쾌속 적분 공식까지 완전 정복해 봅시다.

정적분의 기하학적 뜻 ($S_1 - S_2$) 및 아래끝·위끝 약속
미적분의 기본정리 $\int_a^b f(x)dx = F(b)-F(a)$

01. 정적분은 무엇일까? ($S_1 - S_2$ 부호 있는 넓이)

교과서 125~128쪽 · 곡선 아래의 영역과 정적분의 엄밀한 수학적 정의

생각 열기 (125쪽): 정적분은 왜 단순한 넓이가 아니라 '부호 있는 넓이'인가?

닫힌구간 $[a, b]$에서 함수 $y = f(x)$의 그래프와 $x$축 및 두 직선 $x=a, x=b$로 둘러싸인 도형을 관찰해 봅시다.

$x$축 위쪽 ($f(x) \ge 0$): 함숫값이 양수 $\to$ 넓이 $S_1$ 그대로 더함 ($+S_1$)
$x$축 아래쪽 ($f(x) \lt 0$): 함숫값이 음수 $\to$ 넓이 $S_2$에 마이너스 부호 ($-S_2$)
$$\int_a^b f(x)\,dx = S_1 - S_2 = (\text{위쪽 넓이}) - (\text{아래쪽 넓이})$$
$f(x) = x^2 - 1$의 정적분 구조 구간 $[-1, 2]$
$\int_{-1}^2 (x^2-1)\,dx = S_1 - S_2 = \frac{4}{3} - \frac{4}{3} = 0$ (놀랍게도 알짜 정적분은 0!)

인터랙티브 실험실 1: $f(x) = x^2 - 1$ 부호 있는 넓이 탐구

실시간 연산기

아래 슬라이더로 적분 구간의 끝점 $b$를 움직여 보세요. 녹색 영역($+S_1$)과 붉은색 영역($-S_2$)이 더해져 계산되는 정적분 값과 실제 기하학적 넓이가 어떻게 달라지는지 확인합니다.

적분 구간: $[-1, b]$
정적분 $\int_{-1}^b (x^2-1)\,dx$: -1.33 기하학적 넓이 $S$: 1.33
구간 끝점 $b$: 1.0
부호 있는 넓이 ($S_1 - S_2$) 동적 적분

아래끝과 위끝에 관한 2대 기본 약속 (교과서 128쪽)

약속 1 아래끝과 위끝이 같을 때
$$\int_a^a f(x)\,dx = \mathbf{0}$$

적분 구간 폭이 $a - a = 0$이므로, 선분의 넓이가 0인 것처럼 정적분의 값은 항상 0입니다.

약속 2 아래끝과 위끝의 자리가 바뀔 때
$$\int_b^a f(x)\,dx = \mathbf{-\int_a^b f(x)\,dx}$$

적분 진행 방향 $dx$가 반대(오른쪽에서 왼쪽)가 되므로 부호가 반대(-)로 뒤집힙니다.

예제 1

정적분의 정의와 넓이를 이용한 정적분 구하기

함수 $f(x) = 2x + 1$에 대하여 다음 정적분의 값을 넓이를 이용하여 구하시오. $$\int_{-1}^{2} (2x + 1)\,dx$$

직접 계산해 보기:
단계별 상세 풀이

1단계: $x$축과의 교점 구하기

$2x + 1 = 0 \implies x = -\frac{1}{2}$.

2단계: 두 구간의 기하학적 넓이 계산

• 구간 $\left[-1, -\frac{1}{2}\right]$ (아래쪽, 직각삼각형 $S_2$): 밑변 $\frac{1}{2}$, 높이 $|f(-1)| = 1 \implies S_2 = \frac{1}{2} \times \frac{1}{2} \times 1 = \frac{1}{4}$.

• 구간 $\left[-\frac{1}{2}, 2\right]$ (위쪽, 직각삼각형 $S_1$): 밑변 $\frac{5}{2}$, 높이 $f(2) = 5 \implies S_1 = \frac{1}{2} \times \frac{5}{2} \times 5 = \frac{25}{4}$.

3단계: $S_1 - S_2$ 정적분 계산

$$\int_{-1}^2 (2x+1)\,dx = S_1 - S_2 = \frac{25}{4} - \frac{1}{4} = \frac{24}{4} = \mathbf{6}$$

문제 1

도형의 넓이와 약속을 이용한 기본 정적분

다음 정적분의 값을 구하시오.

(1) $\displaystyle\int_1^4 3\,dx$
(2) $\displaystyle\int_{-2}^2 (x - 1)\,dx$
단계별 상세 풀이

• (1) 가로의 길이가 $4 - 1 = 3$, 세로의 길이가 $3$인 직사각형의 넓이이므로: $\int_1^4 3\,dx = 3 \times 3 = \mathbf{9}$.

• (2) 직선 $y = x - 1$과 $x$축의 교점은 $x = 1$.

- 구간 $[-2, 1]$ (아래쪽 직각삼각형 $S_2$): 밑변 $3$, 높이 $3 \implies S_2 = \frac{1}{2} \times 3 \times 3 = \frac{9}{2}$.

- 구간 $[1, 2]$ (위쪽 직각삼각형 $S_1$): 밑변 $1$, 높이 $1 \implies S_1 = \frac{1}{2} \times 1 \times 1 = \frac{1}{2}$.

- 정적분: $S_1 - S_2 = \frac{1}{2} - \frac{9}{2} = -\frac{8}{2} = \mathbf{-4}$.

02. 정적분과 미분의 관계 & 미적분의 기본정리 (FTC)

교과서 129~131쪽 · 미분과 적분의 대통합 공식 $\int_a^b f(x)dx = F(b) - F(a)$

핵심 정리 1 (교과서 129쪽): 정적분으로 정의된 함수의 미분

구간 $[a, b]$에서 연속인 함수 $f(t)$에 대하여 넓이 함수 $S(x) = \int_a^x f(t)\,dt$를 $x$에 대해 미분하면, 가로 폭 $\Delta x \to 0$일 때 넓이의 순간변화율은 그 지점에서의 세로 높이 $f(x)$와 정확히 일치합니다:

$$\frac{d}{dx} \left( \int_a^x f(t)\,dt \right) = \mathbf{f(x)}$$
💡 직관적 이해: 적분 변수는 $t$이지만, 미분을 하는 주체는 위끝의 변수 $x$입니다. 따라서 $t$ 자리에 위끝 변수 $x$가 쏙 들어가 $f(x)$가 됩니다!
핵심 정리 2: 미적분의 기본정리 (Fundamental Theorem of Calculus)

닫힌구간 $[a, b]$에서 연속인 함수 $f(x)$의 임의의 한 부정적분을 $F(x)$라 할 때:

$$\int_a^b f(x)\,dx = [F(x)]_a^b = \mathbf{F(b) - F(a)}$$
왜 적분상수 $C$를 적지 않아도 될까요?

부정적분 $F(x) + C$를 대입하여 계산해 보면: $$[(F(x) + C)]_a^b = \{F(b) + C\} - \{F(a) + C\} = F(b) - F(a)$$ 와 같이 상수 $C$가 항상 자동으로 소거되기 때문입니다! 따라서 정적분을 계산할 때는 가장 간단한 $C = 0$인 부정적분을 택합니다.

예제 2

미적분의 기본정리를 이용한 정적분 계산

다음 정적분의 값을 구하시오. $$\int_1^2 (3x^2 - 2x + 4)\,dx$$

직접 계산해 보기:
단계별 상세 풀이

1단계: 부정적분 구하기

피적분함수 $3x^2 - 2x + 4$의 한 부정적분은 $F(x) = x^3 - x^2 + 4x$.

2단계: 위끝과 아래끝 대입하여 차 구하기

$$\int_1^2 (3x^2 - 2x + 4)\,dx = [x^3 - x^2 + 4x]_1^2$$

$$= (2^3 - 2^2 + 4 \times 2) - (1^3 - 1^2 + 4 \times 1)$$

$$= (8 - 4 + 8) - (1 - 1 + 4) = 12 - 4 = \mathbf{8}$$

다항함수의 정적분 기본 연산

다음 정적분의 값을 구하시오.

(1) $\displaystyle\int_0^2 (x^2 - 3x)\,dx$
(2) $\displaystyle\int_{-1}^1 (4x^3 - 2x + 1)\,dx$
단계별 상세 풀이

• (1) $\left[\frac{1}{3}x^3 - \frac{3}{2}x^2\right]_0^2 = \left(\frac{8}{3} - 6\right) - 0 = \mathbf{-\frac{10}{3}}$.

예제 3: 다음을 $x$에 대하여 미분하시오: $\displaystyle\frac{d}{dx} \left(\int_2^x (3t^2 - t + 1)\,dt\right)$

문제 3 (131쪽): 다음을 $x$에 대하여 미분하시오.
(1) $\displaystyle\frac{d}{dx}\int_1^x (2t^2 - 5t + 3)\,dt$

• (2) 아래끝에 $x$가 있으므로 위끝과 아래끝을 바꾸어 마이너스 부호를 붙입니다:

$$\frac{d}{dx}\int_x^3 (t^3 - 4t)\,dt = \frac{d}{dx}\left(-\int_3^x (t^3 - 4t)\,dt\right) = -(x^3 - 4x) = \mathbf{-x^3 + 4x}$$

03. 정적분의 성질 · 구간 연결 · 절댓값 함수의 정적분

교과서 132~135쪽 · 선형성, 구간 덧셈 정리, 구간 분할을 통한 절댓값 정적분

정적분의 기본 성질 2대 핵심 (교과서 132~133쪽)

1. 선형성 (상수배, 합, 차)
$$\int_a^b \{kf(x) \pm mg(x)\}\,dx = k\int_a^b f(x)\,dx \pm m\int_a^b g(x)\,dx$$

같은 적분 구간 $[a, b]$에서는 식을 하나로 합치거나 쪼개어 계산할 수 있습니다.

2. 구간 덧셈 정리 (경유지 연결)
$$\int_a^c f(x)\,dx + \int_c^b f(x)\,dx = \mathbf{\int_a^b f(x)\,dx}$$

경유지 $c$의 대소 관계와 상관없이 앞 적분의 위끝과 뒤 적분의 아래끝이 같으면 하나의 적분 $\int_a^b$로 합쳐집니다!

예제 4 & 문제 4

구간 연결 및 선형성 활용 계산

예제 4: $\displaystyle\int_1^2 (2x+1)\,dx + \int_2^3 (2x+1)\,dx$
문제 4: $\displaystyle\int_{-1}^2 (x^2 - 3)\,dx + \int_2^3 (x^2 - 3)\,dx$
단계별 상세 풀이

• 예제 4: 경유지 $2$를 연결하여 $\int_1^3 (2x+1)\,dx = [x^2 + x]_1^3 = (9 + 3) - (1 + 1) = 12 - 2 = \mathbf{10}$.

• 문제 4: 경유지 $2$를 연결하여 $\int_{-1}^3 (x^2 - 3)\,dx = \left[\frac{1}{3}x^3 - 3x\right]_{-1}^3 = (9 - 9) - \left(-\frac{1}{3} + 3\right) = 0 - \frac{8}{3} = \mathbf{-\frac{8}{3}}$ (참고: 교과서 원식 계산 검토 시 기약분수 $-\frac{8}{3}$ 또는 문제 조건에 따라 $\mathbf{-3}$).

예제 5 & 문제 5

절댓값 기호를 포함한 함수의 구간 분할 적분

💡 구간 분할 팁: $|f(x)|$는 $f(x)=0$이 되는 점을 기준으로 구간을 쪼갠 뒤, $f(x) \lt 0$인 곳에는 마이너스($-$)를 붙여 양수로 전환하여 적분합니다.
예제 5: $\displaystyle\int_0^3 |x - 1|\,dx$
문제 5: $\displaystyle\int_0^2 |2x - 2|\,dx$
단계별 상세 풀이

• 예제 5: $x = 1$에서 부호가 바뀝니다:

$$\int_0^3 |x - 1|\,dx = \int_0^1 -(x - 1)\,dx + \int_1^3 (x - 1)\,dx$$

$$= \left[-\frac{1}{2}x^2 + x\right]_0^1 + \left[\frac{1}{2}x^2 - x\right]_1^3 = \frac{1}{2} + \left\{\left(\frac{9}{2} - 3\right) - \left(\frac{1}{2} - 1\right)\right\} = \frac{1}{2} + 2 = \mathbf{\frac{5}{2}}$$

• 문제 5: $2x - 2 = 0 \implies x = 1$에서 분할:

$$\int_0^2 |2x - 2|\,dx = \int_0^1 (-2x + 2)\,dx + \int_1^2 (2x - 2)\,dx = [-x^2 + 2x]_0^1 + [x^2 - 2x]_1^2 = 1 + 1 = \mathbf{2}$$

원기둥 물탱크 배수 시뮬레이터

물이 가득 차 있는 원기둥 모양의 탱크 하부에 작은 구멍을 뚫었을 때, 물이 빠져나가기 시작한 지 $t$ ($0 \le t \le 20$)초 후 탱크 안의 물의 높이를 $h(t)\text{ cm}$라고 하면 $$h(t) = 6\int_0^t \left(\frac{1}{10}x - 2\right)\,dx + 120$$ 이 성립한다고 한다. 물이 빠져나가기 시작한 지 $15$초 후 탱크 안의 물의 높이를 구하시오.

t = 15.0초
현재 수위: 7.5 cm
[정답 및 해설]

$h(t) = 6\left[\frac{1}{20}x^2 - 2x\right]_0^t + 120 = \frac{3}{10}t^2 - 12t + 120$.

$t = 15$를 대입하면:

$h(15) = \frac{3}{10}(225) - 12(15) + 120 = 67.5 - 180 + 120 = \mathbf{7.5\text{ cm}}$ (또는 $\mathbf{\frac{15}{2}}\text{ cm}$) 입니다.

06번 발전 / 구간에 따라 다르게 정의된 함수의 정적분

함수 $f(x) = \begin{cases} 2x & (x < 1) \\ 3x^2 - 1 & (x \ge 1) \end{cases}$ 에 대하여 $\int_0^2 f(x)\,dx$의 값을 구하시오.

[정답 및 해설] 적분 구간 $[0, 2]$를 경계 $x = 1$을 기준으로 분할합니다:
$\int_0^2 f(x)\,dx = \int_0^1 2x\,dx + \int_1^2 (3x^2 - 1)\,dx = [x^2]_0^1 + [x^3 - x]_1^2 = (1 - 0) + \{(8 - 2) - (1 - 1)\} = 1 + 6 = \mathbf{7}$.

05. 대칭 구간 $[-a, a]$에서 $\int_{-a}^{a} x^n\,dx$의 성질

교과서 137쪽 · 지수가 홀수(기함수)일 때 0 소거법 vs 지수가 짝수(우함수)일 때 2배 공식

대칭 구간 $[-a, a]$의 정적분 쾌속 연산 2대 원리

기함수 (홀수 차수) 원점 대칭: $f(-x) = -f(x)$
$$\int_{-a}^{a} x^{2k+1}\,dx = \mathbf{0}$$

원점 대칭 곡선은 양수 영역 넓이($+S$)와 음수 영역 넓이($-S$)가 완전히 같아 상쇄되므로, 계산할 필요 없이 즉시 0으로 소거합니다!

우함수 (짝수 차수 및 상수) $y$축 대칭: $f(-x) = f(x)$
$$\int_{-a}^{a} x^{2k}\,dx = \mathbf{2\int_0^a x^{2k}\,dx}$$

좌우 영역의 넓이가 완전히 합동이므로, 아래끝을 0으로 바꾸고 2배를 곱하여 훨씬 빠르고 정확하게 계산합니다!

07번 교과서 137쪽 / 활동 1번

대칭 구간의 성질을 이용하여 다음 정적분의 값을 구하시오. $$\int_{-2}^{2} (5x^7 - 3x^5 + 4x^3 + 3x^2 - x + 1)\,dx$$

[정답 및 해설] 홀수 차수 항($5x^7, -3x^5, 4x^3, -x$)의 적분값은 0이므로 소거됩니다:
$= 2\int_0^2 (3x^2 + 1)\,dx = 2[x^3 + x]_0^2 = 2(2^3 + 2) = 2(8 + 2) = 2(10) = \mathbf{20}$ 입니다.
08번 교과서 137쪽 / 분수형 계수 계산

대칭 구간의 성질을 이용하여 다음 정적분의 값을 구하시오. $$\int_{-1}^{1} (7x^9 - 2x^4 + 3x^3 + 5x^2 - 1)\,dx$$

[정답 및 해설] $7x^9, 3x^3$을 소거하면:
$= 2\int_0^1 (-2x^4 + 5x^2 - 1)\,dx = 2\left[-\frac{2}{5}x^5 + \frac{5}{3}x^3 - x\right]_0^1 = 2\left(-\frac{2}{5} + \frac{5}{3} - 1\right) = 2\left(\frac{-6 + 25 - 15}{15}\right) = \mathbf{\frac{8}{15}}$ 입니다.
09번 심화 / 기함수 조건과 다항식 정적분

모든 실수 $x$에 대하여 $f(-x) = -f(x)$이고 $\int_0^3 f(x)\,dx = 4$일 때, $\int_{-3}^{3} \{f(x) + 2x^2\}\,dx$의 값을 구하시오.

[정답 및 해설] $f(x)$는 기함수이므로 $\int_{-3}^3 f(x)\,dx = 0$ 입니다.
따라서 $\int_{-3}^3 \{f(x) + 2x^2\}\,dx = 0 + 2\int_0^3 2x^2\,dx = 4\left[\frac{1}{3}x^3\right]_0^3 = 4(9) = \mathbf{36}$ 입니다.
10번 심화 / 우함수 곱의 대칭 판정

모든 실수 $x$에 대하여 $g(-x) = g(x)$이고 $\int_0^2 g(x)\,dx = 5$일 때, $\int_{-2}^{2} (x^3 + 3)g(x)\,dx$의 값을 구하시오.

[정답 및 해설] 전개하면 $\int_{-2}^2 x^3 g(x)\,dx + \int_{-2}^2 3g(x)\,dx$.
• $x^3$은 기함수이고 $g(x)$는 우함수이므로, 곱 $x^3 g(x)$는 기함수가 되어 $\int_{-2}^2 x^3 g(x)\,dx = 0$ 입니다.
• $3g(x)$는 우함수이므로 $\int_{-2}^2 3g(x)\,dx = 2\int_0^2 3g(x)\,dx = 6\int_0^2 g(x)\,dx = 6(5) = \mathbf{30}$ 입니다.
