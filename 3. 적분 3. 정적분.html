1. 정적분은 무엇일까? ($S_1 - S_2$ 부호 있는 넓이)

생각 열기 (p.125) & 정적분의 정의 ($S_1 - S_2$) 실험실
① 생각 열기 활동 1 ($f(x)=x, \; a=0, b=2$)

밑변과 높이가 각각 $2$인 직각이등변삼각형의 넓이이므로 $S = \dfrac{1}{2} \times 2 \times 2 = \mathbf{2}$이다.

② 생각 열기 활동 2 ($f(x)=x, \; a=1, b=3$)

사다리꼴(또는 큰 삼각형 $-$ 작은 삼각형)의 넓이이므로 $S = \dfrac{1}{2}\times 3^2 - \dfrac{1}{2}\times 1^2 = \mathbf{4}$이다.

핵심 개념 · 정적분의 정의 (p.126~127) $a$: 아래끝, $b$: 위끝

닫힌구간 $[a, b]$에서 연속인 함수 $f(x)$의 그래프와 $x$축 및 두 직선 $x=a, x=b$로 둘러싸인 도형 중 $f(x) \ge 0$인 부분의 넓이를 $S_1$, $f(x) \le 0$인 부분의 넓이를 $S_2$라고 할 때:

$$\int_{a}^{b} f(x)\,dx = S_1 - S_2$$

📌 $a=b$ 또는 $a>b$일 때의 정의 (p.127):

① $a=b$일 때, $\int_{a}^{a} f(x)\,dx = 0$

② $a>b$일 때, $\int_{a}^{b} f(x)\,dx = -\int_{b}^{a} f(x)\,dx$

💡 적분 변수는 다른 문자를 써도 같습니다: $\int_a^b f(x)\,dx = \int_a^b f(t)\,dt = \int_a^b f(s)\,ds$

2. 정적분과 미분의 관계 & 미적분의 기본정리

정적분과 미분의 관계 유도 실험실 (p.128~129)
생각 열기: $f(t)=2t$일 때 $S(x)=\int_1^x 2t\,dt = x^2-1 \implies S'(x)=2x=f(x)$
구간 $[x, x+\Delta x]$에서 $m\Delta x \le \Delta S \le M\Delta x$ 관찰 Δx = 0.80

슬라이더를 왼쪽으로 움직여 $\Delta x \to 0$으로 보내면 $m$과 $M$이 모두 $f(x)$로 수렴합니다!

① 넓이의 증분 $\Delta S$와 극한의 대소 관계 (p.128~129):
$$m\Delta x \le \Delta S \le M\Delta x \implies m \le \frac{\Delta S}{\Delta x} \le M$$

$\Delta x \to 0$일 때 $\lim_{\Delta x\to 0}m = \lim_{\Delta x\to 0}M = f(x)$이므로 $\dfrac{d}{dx}S(x) = \lim_{\Delta x\to 0}\dfrac{\Delta S}{\Delta x} = f(x)$이다.

핵심 1 · 정적분과 미분의 관계 (p.129)

함수 $f(t)$가 닫힌구간 $[a, b]$에서 연속일 때:

$$\frac{d}{dx}\int_{a}^{x} f(t)\,dt = f(x) \quad (\text{단, } a < x < b)$$
핵심 2 · 부정적분과 정적분의 관계 (미적분의 기본정리 | p.130) 수학자 배로(Barrow) 착안

3. 정적분의 성질 · 나누어진 구간 · 절댓값 함수의 정적분

성질 1 · 함수의 실수배, 합, 차의 정적분 (p.133)

생각 열기(p.132): $\int_0^3 x^2\,dx + \int_0^3 2x\,dx = 9 + 9 = 18 = \int_0^3 (x^2+2x)\,dx$

① $\int_{a}^{b} kf(x)\,dx = k\int_{a}^{b} f(x)\,dx$ (단, $k$는 실수)

② $\int_{a}^{b} \{f(x) \pm g(x)\}\,dx = \int_{a}^{b} f(x)\,dx \pm \int_{a}^{b} g(x)\,dx$

💡 부정적분과 달리 정적분에서는 $k=0$일 때도 좌변과 우변이 모두 $0$이므로 모든 실수 $k$에 대하여 성립합니다!

성질 2 · 나누어진 구간에서의 정적분 (p.134)

세 실수 $a, b, c$의 대소에 관계없이 항상 성립합니다.

$$\int_{a}^{c} f(x)\,dx + \int_{c}^{b} f(x)\,dx = \int_{a}^{b} f(x)\,dx$$

5. 대칭 구간 $[-a, a]$에서 $\int_{-a}^{a} x^n\,dx$의 값의 성질 알아보기

대칭성 실험실 (p.137)

지수가 홀수(원점 대칭)일 때 vs 지수가 짝수($y$축 대칭)일 때

구간 $[-a, a]$의 경계 $a$: 1.5 n = 3 (홀수 · 원점 대칭) ⟹ (-S) + S = 0
(1) $n$이 홀수일 때 (그래프가 원점에 대하여 대칭)

$\int_{-a}^{0} x^n\,dx = -S$, $\int_{0}^{a} x^n\,dx = S$이므로 서로 상쇄되어 항상 $0$이 됩니다!

$$\int_{-a}^{a} x^n\,dx = (-S) + S = \mathbf{0} \quad (n\text{이 홀수})$$
(2) $n$이 짝수일 때 (그래프가 $y$축에 대하여 대칭)

$\int_{-a}^{0} x^n\,dx = S$, $\int_{0}^{a} x^n\,dx = S$이므로 $[0, a]$ 구간 정적분의 $2$배가 됩니다!

$$\int_{-a}^{a} x^n\,dx = S + S = 2S = \mathbf{2\int_{0}^{a} x^n\,dx} \quad (n\text{이 짝수})$$
