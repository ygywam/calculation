💡 생각 열기 : 그래프가 '끊어지지 않는다'는 것의 수학적 의미?

선이나 곡선이 중간에 끊어짐 없이 이어져 있다는 직관적 개념을 수학적으로 엄밀하게 정의하려면 어떻게 해야 할까요? 특정 점 $x=a$에서 함수가 연속이 되기 위한 조건을 살펴봅시다.

함숫값이 정의되고, 극한값이 존재하며, 그 두 값이 서로 일치해야 합니다!

1. $x=a$에서 연속의 3가지 조건

함수 $f(x)$가 $x=a$에서 연속이 되기 위해서는 다음 3가지 조건을 모두 만족해야 합니다:

1

함숫값의 존재

$x=a$에서 함숫값 $f(a)$가 정의되어 있다.

2

극한값의 존재

극한값 $\lim_{x \to a} f(x)$가 존재한다.
(좌극한 = 우극한)

3

두 값의 일치

$$\lim_{x \to a} f(x) = f(a)$$

셋 중 하나라도 만족하지 않으면 함수 $f(x)$는 $x=a$에서 불연속이라고 합니다.

2. 불연속의 대표 3가지 유형 & 구간 기호

유형 1

함숫값이 정의되지 않음

예: $f(x) = \frac{x^2-1}{x-1}$ ($x=1$에서 분모가 0이 되어 정의 안 됨)

유형 2

극한값이 존재하지 않음

예: 가우스 기호 $[x]$ 또는 좌극한 $\ne$ 우극한인 계단형 조각함수

유형 3

극한값 $\ne$ 함숫값

점 하나만 다른 곳에 찍혀 있는 경우 (동떨어진 점)

📌 구간의 기호 정리

닫힌구간 $[a, b]$ : $a \le x \le b$
열린구간 $(a, b)$ : $a < x < b$
반열린구간 $[a, b)$ : $a \le x < b$
전체 실수 $(-\infty, \infty)$

함수의 연속성 동적 시뮬레이터

x = 1 에서의 연속 판정
0.0 f(1) = 2.0 4.0
함수 $f(x)$ ($x \ne 1$): $f(x) = x + 1$
극한값 $\lim_{x \to 1} f(x)$: 2.0
연속성 판정: 연속 (Continuous)

대표 예제 풀이 & 연습장

예제 1 (미정계수와 연속)

함수 $f(x) = \begin{cases} \frac{x^2 - x + a}{x - 2} & (x \ne 2) \\ b & (x = 2) \end{cases}$ 가 $x = 2$에서 연속일 때, 상수 $a, b$의 값을 구하시오.

$x=2$에서 연속이려면 $\lim_{x \to 2} f(x) = f(2) = b$ 이어야 합니다.

$x \to 2$일 때 분모 $\to 0$이므로 분자도 $\to 0$이어야 합니다: $2^2 - 2 + a = 0 \implies a = -2$.

$$\lim_{x \to 2} \frac{x^2 - x - 2}{x - 2} = \lim_{x \to 2} \frac{(x-2)(x+1)}{x-2} = \lim_{x \to 2} (x+1) = 3$$

따라서 $a = -2, b = 3$ 입니다.

문제 풀이 연습장

스스로 확인하기 (형성평가)

01. 함수 $f(x) = \frac{1}{x-3}$이 연속인 구간을 기호로 나타내시오.

$(-\infty, 3) \cup (3, \infty)$ ($x \ne 3$인 모든 실수)

02. 함수 $f(x) = \sqrt{2x - 4}$가 연속인 구간을 기호로 나타내시오.

$[2, \infty)$ (근호 안 $2x-4 \ge 0$)

03. 다항함수 $f(x) = 2x^2 - 3x + 1$은 모든 실수에서 연속인가?

그렇다 (모든 다항함수는 $(-\infty, \infty)$에서 연속)
