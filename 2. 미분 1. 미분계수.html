01. 평균변화율 (Average Rate of Change)

일상 속 수많은 변화 현상(온도, 속도, 주가, 판매량)에서 두 시점 사이의 평균적인 변화를 수학적 비(ratio)로 정량화하고, 기하학적으로는 곡선 위의 두 점을 잇는 할선의 기울기로 직관화합니다.

🎯 핵심 성취기준: 함수의 증분과 평균변화율의 의미를 이해하고 이를 구할 수 있다.

• 기호 \(\Delta\)의 도입 지도: 그리스 문자 delta(\(\Delta\))는 영어의 차(Difference)를 뜻하는 기호임을 설명하여 학생들의 기호에 대한 거부감을 줄입니다. 특히 \(\Delta x\)는 하나의 문자처럼 취급되므로 \(\Delta\)와 \(x\)의 곱이 아님을 명확히 주지시킵니다.

• 직관과 기하의 결합: 1차시 생각 열기의 모래 온도 실험 자료를 통해 비(ratio)로서의 평균변화율을 먼저 체감하게 한 후, 좌표평면 위의 곡선에서 두 점 \(A, B\)를 잇는 할선(Secant Line)의 기울기와 완전히 일치함을 시각적으로 증명합니다.

• 오개념 방지 팁: \(\Delta x\)가 음수일 수도 있는지 묻는 질문이 많습니다. \(b < a\)인 경우에도 \(\Delta x = b - a < 0\)이며 평균변화율의 공식은 부호와 무관하게 동일하게 성립함을 환기합니다.

1

개념 정립: 증분(Increment)과 평균변화율

함수 \(y=f(x)\)에서 \(x\)의 값이 \(a\)에서 \(b\)까지 변할 때, \(y\)의 값은 \(f(a)\)에서 \(f(b)\)까지 변합니다.

\(x\)의 증분 (Increment of \(x\))

\(x\)의 값의 변화량: \(\Delta x = b - a\)

따라서 \(b = a + \Delta x\)로 나타낼 수 있습니다.

\(y\)의 증분 (Increment of \(y\))

\(y\)의 값의 변화량: \(\Delta y = f(b) - f(a)\)

즉, \(\Delta y = f(a + \Delta x) - f(a)\)입니다.

핵심 정의 교과서 53쪽

함수의 평균변화율 (Average Rate of Change)

\(x\)의 증분 \(\Delta x\)에 대한 \(y\)의 증분 \(\Delta y\)의 비를 \(x\)가 \(a\)에서 \(b\)까지 변할 때의 평균변화율이라고 합니다.

\(\frac{\Delta y}{\Delta x} = \frac{f(b) - f(a)}{b - a} = \frac{f(a + \Delta x) - f(a)}{\Delta x}\)
📐 기하학적 의미: 곡선 \(y=f(x)\) 위의 두 점 \(A(a, f(a))\), \(B(b, f(b))\)를 지나는 직선 \(AB\)(할선)의 기울기와 완전히 일치합니다.
예제 1

평균변화율 구하기

교과서 53쪽
함수 \(f(x) = x^2\)에서 \(x\)의 값이 다음과 같이 변할 때의 평균변화율을 구하시오.
⑴ \(0\)에서 \(2\)까지
⑵ \(a\)에서 \(a + \Delta x\)까지

단계별 모범 풀이 및 검증

⑴ \(0\)에서 \(2\)까지의 평균변화율
\(\frac{\Delta y}{\Delta x} = \frac{f(2) - f(0)}{2 - 0} = \frac{2^2 - 0^2}{2} = \frac{4}{2} = \mathbf{2}\)
💡 기하학적 확인: 원점 \((0, 0)\)과 점 \((2, 4)\)를 잇는 직선의 기울기는 \(\frac{4 - 0}{2 - 0} = 2\)입니다.
⑵ \(a\)에서 \(a + \Delta x\)까지의 평균변화율
\(\begin{aligned} \frac{\Delta y}{\Delta x} &= \frac{f(a + \Delta x) - f(a)}{\Delta x} = \frac{(a + \Delta x)^2 - a^2}{\Delta x} \\[6pt] &= \frac{a^2 + 2a\Delta x + (\Delta x)^2 - a^2}{\Delta x} = \frac{2a\Delta x + (\Delta x)^2}{\Delta x} \\[6pt] &= \mathbf{2a + \Delta x} \end{aligned}\)
💡 핵심 연결고리: 여기서 \(\Delta x \to 0\) 극한을 취하면 다음 시간에 배울 점 \(x=a\)에서의 미분계수 \(f'(a) = 2a\)가 유도됩니다!
즉시 정답 확인 & 자동 채점
정답: \(6a + 3\Delta x\)
\(\frac{f(a+\Delta x)-f(a)}{\Delta x} = \frac{\{3(a+\Delta x)^2-2\} - (3a^2-2)}{\Delta x} = \frac{6a\Delta x + 3(\Delta x)^2}{\Delta x} = 6a + 3\Delta x\)
문제 2 경제·금융 융합

항공권 티켓 판매량과 수익의 평균변화율

교과서 53쪽

항공사들은 수익을 극대화하기 위해 비행 요금을 정기적으로 변경합니다. 한 항공사 연구팀이 연구한 결과, 어떤 비행편의 티켓 \(x\)장을 판매했을 때의 수익 \(R(x)\)원(단, \(0 \le x \le 100\))이 다음과 같았다고 합니다.

\(R(x) = 1300(x^2 + 90x)\)

이 티켓의 판매량이 \(50\)장에서 \(60\)장까지 변할 때, 수익의 평균변화율을 구하시오.

원/장
단계별 계산 과정:

• \(\Delta x = 60 - 50 = 10\) (장)
• \(R(60) = 1300(60^2 + 90 \times 60) = 1300(3600 + 5400) = 1300 \times 9000 = 11,700,000\) 원
• \(R(50) = 1300(50^2 + 90 \times 50) = 1300(2500 + 4500) = 1300 \times 7000 = 9,100,000\) 원
• \(\Delta y = R(60) - R(50) = 11,700,000 - 9,100,000 = 2,600,000\) 원
• 따라서 평균변화율은:

\(\frac{\Delta y}{\Delta x} = \frac{2,600,000}{10} = 260,000\text{ (원/장)}\)

💡 경제학적 해석: 티켓을 50장에서 60장까지 판매할 때 티켓 1장을 추가 판매할 때마다 평균적으로 260,000원의 수익이 증가함을 의미합니다. (한계수익의 기초 개념)

02. 미분계수와 그 기하학적 의미 (Derivative & Tangent Slope)

평균변화율에서 간격 \(\Delta x \to 0\) 극한을 취할 때 얻어지는 순간변화율(미분계수)의 엄밀한 정의를 정립하고, 곡선 위의 고정점으로 이동점이 다가갈 때 할선이 접선으로 수렴하는 기하학적 본질을 탐구합니다.

🎯 핵심 성취기준: 미분계수의 뜻을 알고, 그 기하학적 의미가 접선의 기울기임을 이해한다.

• 두 가지 표현식의 동치성 훈련: \(f'(a) = \lim_{\Delta x \to 0} \frac{f(a+\Delta x)-f(a)}{\Delta x}\)와 \(f'(a) = \lim_{x \to a} \frac{f(x)-f(a)}{x-a}\)는 본질적으로 동일한 극한입니다. 문제 상황에 따라 인수분해가 쉬운 식은 후자를, 계수 변형이나 도함수 전개는 전자를 적절히 선택하도록 지도합니다.

• 접선의 정의의 진화: 중학교 원의 접선(한 점에서 만나는 직선) 개념에 머물러 있는 학생들에게, 곡선을 스쳐 지나가며 뚫고 지나갈 수도 있는(예: 삼차함수 변곡점의 접선) '할선의 극한'으로서의 고등학교 접선의 정의를 확립시켜야 합니다.

• 구조적 대칭성 강조: \(\lim_{\Delta x \to 0} \frac{f(a+k\Delta x)-f(a)}{\Delta x} = k f'(a)\)와 같이 분모와 괄호 안의 증분이 정확히 일치해야 함을 '형태 맞추기(Pattern Matching)' 관점에서 명확히 각인시킵니다.

2

개념 정립: 순간변화율과 미분계수(Derivative at a Point)

함수 \(y=f(x)\)에서 \(x\)의 값이 \(a\)에서 \(a+\Delta x\)까지 변할 때의 평균변화율은 \(\frac{\Delta y}{\Delta x} = \frac{f(a+\Delta x)-f(a)}{\Delta x}\)입니다. 여기서 \(\Delta x \to 0\)일 때 이 평균변화율의 극한값이 존재하면, 함수 \(y=f(x)\)는 \(x=a\)에서 미분가능(Differentiable)하다고 합니다.

핵심 정리 교과서 54쪽

미분계수의 두 가지 표현 형식

[형태 1] 증분 \(\Delta x\) 기준
\(f'(a) = \lim_{\Delta x \to 0} \frac{f(a + \Delta x) - f(a)}{\Delta x}\)

보통 \(\Delta x\) 대신 \(h\)를 쓰기도 합니다: \(f'(a) = \lim_{h \to 0} \frac{f(a+h)-f(a)}{h}\)

[형태 2] 변수 \(x\) 수렴 기준
\(f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}\)

\(a + \Delta x = x\)로 치환하면 \(\Delta x = x - a\)이며 \(\Delta x \to 0 \iff x \to a\)입니다.

📖 읽는 법: \(f'(a)\)는 "f prime a (f 프라임 a)"라고 읽습니다.
🏛️ 수학사 노트: 미적분학의 두 거인

미적분학은 17세기 후반 영국의 수학자 뉴턴(Newton, I., 1642~1727)과 독일의 철학자·수학자 라이프니츠(Leibniz, G. W., 1646~1716)에 의해 독립적으로 창시되었습니다. 뉴턴은 행성의 운동과 물체의 순간속도를 기술하기 위해 '유율법(fluxion)'을 개발했고, 라이프니츠는 기하학적 접선 문제와 미세 증분을 탐구하며 오늘날 우리가 사용하는 \(dx, dy, \int\) 기호를 정립했습니다.

생각 넓히기 추론 & 문제해결

미분계수의 구조와 증분 계수 변형

교과서 55쪽

다음은 미분계수에 대한 두 학생의 대화입니다.

👦 정화:

"미분가능한 함수 \(f(x)\)의 \(x=a\)에서의 미분계수는 \(f'(a) = \lim_{\Delta x \to 0} \frac{f(a+\Delta x)-f(a)}{\Delta x}\)인데, \(\Delta x\)를 모두 \(2\Delta x\)로 바꾸어도 성립할까?"

👧 진욱:

"\(\lim_{\square \to 0} \frac{f(a+\square)-f(a)}{\square}\)의 꼴의 극한은 네모가 같은 속도로 0으로 가면 모두 \(f'(a)\)가 된다는 뜻이니까..."

1 \(f'(a) = \lim_{\Delta x \to 0} \frac{f(a+\Delta x)-f(a)}{\Delta x}\)에서 \(\Delta x\)를 모두 \(2\Delta x\)로 바꾼 식을 구하시오.
\(\Delta x \to 0\)이면 \(2\Delta x \to 0\)이므로:
\(\lim_{2\Delta x \to 0} \frac{f(a + 2\Delta x) - f(a)}{2\Delta x} = \lim_{\Delta x \to 0} \frac{f(a + 2\Delta x) - f(a)}{2\Delta x} = \mathbf{f'(a)}\)
2 미분가능한 함수 \(f(x)\)에 대하여 \(\lim_{\Delta x \to 0} \frac{f(a+2\Delta x)-f(a)}{\Delta x} = 8\)일 때, 1을 이용하여 \(f'(a)\)의 값을 구하시오.

분모에 \(2\)가 없으므로 분모·분자에 \(2\)를 곱하여 분모의 증분을 괄호 안의 \(2\Delta x\)와 일치시킵니다:

\(\lim_{\Delta x \to 0} \frac{f(a+2\Delta x)-f(a)}{\Delta x} = \lim_{\Delta x \to 0} \left\{ \frac{f(a+2\Delta x)-f(a)}{2\Delta x} \times 2 \right\} = 2 f'(a)\)
따라서 \(2 f'(a) = 8 \implies \mathbf{f'(a) = 4}\)
SIMULATOR 3

미분계수 형태 맞추기 (Structure Pattern Matching)

분자·분모의 \(\Delta x\) 계수를 조절하여 극한 배율을 확인하세요
\(f(a + m\Delta x)\)
\(k\Delta x\)
미분계수 극한 분해 계산 2/1 · f'(a) = 2 f'(a)
\(\lim_{\Delta x \to 0} \frac{f(a + m\Delta x) - f(a)}{k\Delta x} = \frac{m}{k} \cdot \lim_{m\Delta x \to 0} \frac{f(a + m\Delta x) - f(a)}{m\Delta x} = \mathbf{\frac{m}{k} f'(a)}\)
형태 맞추기 원리: 분자의 증분 \(m\Delta x\)와 분모의 증분이 같아야만 \(f'(a)\)의 정의가 적용됩니다. 따라서 분모를 \(m\Delta x\)로 변형한 뒤 보정 계수 \(\frac{m}{k}\)를 곱합니다.
예제 2

미분계수 구하기 (두 가지 방법 비교)

교과서 55쪽
함수 \(f(x) = 2x^2 + x\)의 \(x=1\)에서의 미분계수를 구하시오.
[방법 1] \(\Delta x \to 0\) 정의 이용 증분 전개형
\(f'(1) = \lim_{\Delta x \to 0} \frac{f(1+\Delta x)-f(1)}{\Delta x}\)
\(= \lim_{\Delta x \to 0} \frac{\{2(1+\Delta x)^2 + (1+\Delta x)\} - (2 \times 1^2 + 1)}{\Delta x}\)
\(= \lim_{\Delta x \to 0} \frac{5\Delta x + 2(\Delta x)^2}{\Delta x}\)
\(= \lim_{\Delta x \to 0} (5 + 2\Delta x) = \mathbf{5}\)
[방법 2] \(x \to a\) 정의 이용 인수분해형
\(f'(1) = \lim_{x \to 1} \frac{f(x)-f(1)}{x - 1}\)
\(= \lim_{x \to 1} \frac{(2x^2 + x) - 3}{x - 1}\)
\(= \lim_{x \to 1} \frac{(x - 1)(2x + 3)}{x - 1}\)
\(= \lim_{x \to 1} (2x + 3) = 2(1) + 3 = \mathbf{5}\)
💡 비교 총평: 두 방법 모두 정답은 \(5\)로 일치합니다! [방법 2]는 분자를 \((x-1)\)로 인수분해하여 약분하므로 계산이 간결하고 실수할 확률이 적습니다.
즉시 정답 확인 & 자동 채점
⑴ 풀이: \(f'(-1) = \lim_{x \to -1} \frac{(2x-3)-(-5)}{x - (-1)} = \lim_{x \to -1} \frac{2x+2}{x+1} = \lim_{x \to -1} 2 = \mathbf{2}\)
💡 직선 \(y=2x-3\)의 기울기는 항상 2이므로 미분계수 역시 2입니다.
⑵ 풀이: \(f(-1) = -(-1)^2 + (-1) + 2 = 0\)
\(f'(-1) = \lim_{x \to -1} \frac{-x^2+x+2 - 0}{x + 1} = \lim_{x \to -1} \frac{-(x+1)(x-2)}{x+1} = \lim_{x \to -1} -(x-2) = -(-1-2) = \mathbf{3}\)
3

미분계수의 기하학적 의미: 접선의 기울기 (Tangent Slope)

곡선 \(y=f(x)\) 위의 고정된 점 \(P(a, f(a))\)와 그 주변의 이동점 \(Q(a+\Delta x, f(a+\Delta x))\)를 생각합니다. 두 점 \(P, Q\)를 지나는 할선(Secant Line) \(PQ\)의 기울기는 두 점 사이의 평균변화율입니다:

\(\text{할선 } PQ\text{의 기울기} = \frac{f(a+\Delta x) - f(a)}{\Delta x}\)

여기서 \(\Delta x \to 0\)이면 점 \(Q\)는 곡선 \(y=f(x)\)를 따라 고정된 점 \(P\)에 한없이 가까워집니다. 이때 직선 \(PQ\)는 점 \(P\)를 지나면서 특정 극한 기울기를 갖는 직선 \(l\)에 한없이 가까워집니다. 이 직선 \(l\)을 곡선 \(y=f(x)\) 위의 점 \(P\)에서의 접선(Tangent Line)이라 하고, 점 \(P\)를 접점(Point of Tangency)이라고 합니다.

✨ 기하학적 대소 결론 (위로 볼록 곡선)

위로 볼록한 곡선에서는 \(x\)가 증가할수록 곡선의 접선 기울기가 계속 감소합니다. 따라서 \(a < b\)일 때 점 \(A\)에서의 접선 기울기가 가장 가파르고, 그 다음이 두 점을 잇는 할선, 점 \(B\)에서의 접선 기울기가 가장 완만합니다:

\(f'(a) > \frac{f(b) - f(a)}{b - a} > f'(b)\)

💡 팁: 아래로 볼록한 곡선에서는 반대로 \(f'(a) < \frac{f(b)-f(a)}{b-a} < f'(b)\)가 성립합니다.

예제 3

곡선 위의 점에서의 접선의 기울기

교과서 57쪽
곡선 \(y = x^2 + 2x\) 위의 점 \((1, 3)\)에서의 접선의 기울기를 구하시오.

\(f(x) = x^2 + 2x\)라고 하면 점 \((1, 3)\)에서의 접선의 기울기는 함수 \(f(x)\)의 \(x=1\)에서의 미분계수 \(f'(1)\)과 같습니다:

\(\begin{aligned} f'(1) &= \lim_{\Delta x \to 0} \frac{f(1+\Delta x) - f(1)}{\Delta x} \\[6pt] &= \lim_{\Delta x \to 0} \frac{\{(1+\Delta x)^2 + 2(1+\Delta x)\} - (1^2 + 2 \times 1)}{\Delta x} \\[6pt] &= \lim_{\Delta x \to 0} \frac{4\Delta x + (\Delta x)^2}{\Delta x} \\[6pt] &= \lim_{\Delta x \to 0} (4 + \Delta x) = \mathbf{4} \end{aligned}\)
정답: 접선의 기울기는 4입니다. (접선의 방정식: \(y - 3 = 4(x - 1) \implies y = 4x - 1\))
즉시 정답 확인 & 자동 채점
⑴ 풀이: \(f(x) = 3x^2 + 4x\)라 하면 \((-1, -1)\)에서의 접선 기울기는 \(f'(-1)\)입니다:
\(f'(-1) = \lim_{x \to -1} \frac{(3x^2+4x) - (-1)}{x - (-1)} = \lim_{x \to -1} \frac{3x^2+4x+1}{x+1} = \lim_{x \to -1} \frac{(x+1)(3x+1)}{x+1} = 3(-1)+1 = \mathbf{-2}\)
⑵ 풀이: \(g(x) = -x^3\)이라 하면 \((2, -8)\)에서의 접선 기울기는 \(g'(2)\)입니다:
\(g'(2) = \lim_{x \to 2} \frac{-x^3 - (-8)}{x - 2} = \lim_{x \to 2} \frac{-(x^3-8)}{x-2} = \lim_{x \to 2} \frac{-(x-2)(x^2+2x+4)}{x-2} = -(2^2+2\times 2+4) = \mathbf{-12}\)

학습 목표 되새기기 (핵심 개념 완성)

⑴ 함수 \(y=f(x)\)에서 \(x\)의 값이 \(a\)에서 \(b\)까지 변할 때의 평균변화율은:
\(\frac{\Delta y}{\Delta x} = \frac{f(b) - f(\fbox{\text{가}})}{\fbox{\text{나}} - a} = \frac{f(a + \fbox{\text{다}}) - f(a)}{\Delta x}\)
⑵ 함수 \(y=f(x)\)가 \(x=a\)에서 미분가능할 때, \(x=a\)에서의 미분계수 \(f'(a)\)는 곡선 \(y=f(x)\) 위의 점 \((a, f(a))\)에서의 접선의 과/와 같고
\(f'(a) = \lim_{\Delta x \to 0} \frac{f(a + \Delta x) - f(a)}{\Delta x} = \lim_{x \to \fbox{\text{라}}} \frac{f(x) - \fbox{\text{마}}}{x - a}\)

미분계수의 정의를 이용한 계산

접선의 기울기를 이용한 미정계수 결정

교과서 58쪽
곡선 \(y = 2x^2 + ax + b\) 위의 점 \((1, 6)\)에서의 접선의 기울기가 \(7\)일 때, 상수 \(a, b\)의 값을 구하시오.

조건 1 (곡선 위의 점): 점 \((1, 6)\)을 지나므로 \(2(1)^2 + a(1) + b = 6 \implies a + b = 4\) ⋯ ㉠

조건 2 (접선 기울기): \(x=1\)에서의 미분계수가 7이므로:
\(f'(1) = \lim_{x \to 1} \frac{(2x^2+ax+b) - 6}{x - 1}\)
㉠에서 \(b = 4 - a\) 대입: \(2x^2+ax+4-a-6 = 2x^2+ax-a-2 = 2(x^2-1)+a(x-1) = (x-1)(2x+2+a)\)
\(\lim_{x \to 1} (2x+2+a) = 4 + a = 7 \implies \mathbf{a = 3}\)

㉠에 대입하면 \(3 + b = 4 \implies \mathbf{b = 1}\)

다항함수의 평균변화율과 순간변화율 연계

교과서 58쪽
다항함수 \(f(x)\)에 대하여 \(f(0) = 2\)이고 \(x\)의 값이 \(0\)에서 \(a\)까지 변할 때의 평균변화율이 \(a + 3\)일 때, \(x=1\)에서의 순간변화율을 구하시오. (단, \(a > 0\))

\(0\)에서 \(a\)까지의 평균변화율은 \(\frac{f(a) - f(0)}{a - 0} = a + 3\)입니다.
\(f(0) = 2\)이므로 \(\frac{f(a) - 2}{a} = a + 3 \implies f(a) - 2 = a^2 + 3a \implies f(a) = a^2 + 3a + 2\)입니다.

모든 양수 \(a\)에 대해 성립하므로 함수식은 \(f(x) = x^2 + 3x + 2\)입니다.
\(f(1) = 1^2 + 3(1) + 2 = 6\)이므로 \(x=1\)에서의 순간변화율은:
\(f'(1) = \lim_{x \to 1} \frac{f(x) - f(1)}{x - 1} = \lim_{x \to 1} \frac{(x^2+3x+2) - 6}{x - 1} = \lim_{x \to 1} \frac{x^2+3x-4}{x-1} = \lim_{x \to 1} (x+4) = \mathbf{5}\)

푸아죄유의 법칙 (혈관 내 혈류 속도와 순간변화율)

교과서 58쪽

푸아죄유의 법칙(Poiseuille’s Law)은 동맥에서 거의 원통 모양인 부분의 혈관을 통과하는 혈액의 속도 \(v\)에 대한 물리 법칙입니다. 혈관을 반지름의 길이가 \(R\, \text{cm}\)인 원기둥으로 생각할 때, 혈관의 중심축으로부터의 거리가 \(r\, \text{cm}\)인 지점에서 흐르는 혈류의 속도 \(v(r)\, \text{cm/s}\)는 다음과 같습니다:

\(v(r) = k(R^2 - r^2) \quad (0 \le r \le R,\; k\text{는 상수})\)

\(R = 0.1\), \(k = 10000\)이라고 할 때, 다음 물음에 답하시오.

⑴ \(r\)의 값이 \(0.01\)에서 \(0.01 + \Delta r\)까지 변할 때, \(v(r)\)의 평균변화율을 구하시오.
⑵ \(v'(0.01)\)의 값을 구하시오.
SIMULATOR 6: 혈관 단면 유속 포물선 및 전단율(Shear Rate) 시각화 거리 r을 조절하여 유속과 속도 변화율을 관찰하세요
동맥 반경 \(R = 0.1\,\text{cm}\)
관측 위치 비율 \(r / R\)
10.0 % (중심 부근)

99.0 cm/s
순간속도 변화율 \(v'(r)\) (전단율)
-200 cm/s/cm
의학적 의의: 중심축(\(\mathbf{r=0}\))에서 속도 최고, 변화율 \(0\)이며, 혈관 벽(\(\mathbf{r=0.1}\))에 닿을수록 마찰로 인해 속도가 급감하고 변화율의 크기(전단율)가 최대가 됩니다.

\(v(r) = 10000(0.1^2 - r^2) = 10000(0.01 - r^2) = 100 - 10000r^2\)
\(v(0.01) = 100 - 10000(0.0001) = 99\)

미분계수의 기하적 의미 이해하기 (국소적 선형성)

공학 도구를 이용하여 곡선 \(y = \frac{1}{2}x^2\) 위의 점 \(A(2, 2)\)에서의 접선 \(y = 2x - 2\)를 그려 보고, 점 \(A\)의 주변을 계속 확대할 때 곡선과 접선이 어떻게 관찰되는지 탐구합니다.
