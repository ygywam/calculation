1

함수의 극한

  • • 수렴: $\lim_{x o a} f(x) = L$ (유한한 값 $L$)
  • • 발산: $\lim_{x o a} f(x) = \infty$ 또는 $-\infty$
  • • $\infty$는 특정 숫자가 아닌 무한히 커지는 상태
2

우극한과 좌극한

  • • 우극한: $\lim_{x o a^+} f(x) = L$
  • • 좌극한: $\lim_{x o a^-} f(x) = M$
  • • 존재 조건: 좌극한 = 우극한 $\iff \lim_{x o a} f(x) = L$
3

극한의 성질 & 대소

  • • $\lim(cf) = cL$, $\lim(f \pm g) = L \pm M$
  • • $\lim(fg) = LM$, $\lim(f/g) = L/M$ ($M e 0$)
  • • 샌드위치 정리: $f \le h \le g$ 이고 $L=M$이면 $\lim h = L$
4

함수의 연속 3대 조건

  • ① $f(a)$ 함숫값 정의되어 있음
  • ② $\lim_{x o a} f(x)$ 극한값 존재함
  • ③ $\lim_{x o a} f(x) = f(a)$ 일치
5

연속함수와 구간

  • • 구간: $[a, b]$, $(a, b)$, $[a, b)$, $(-\infty, \infty)$
  • • 닫힌구간 연속 조건: 내부 열린구간 연속 + 양 끝점 일방극한 일치 ($\lim_{x o a^+} f(x)=f(a)$)
6

최대·최소 & 사잇값 정리

  • • 최대·최소 정리: 닫힌구간 연속 $\implies$ 반드시 최대/최소 존재
  • • 사잇값 정리: $f(a) e f(b) \implies f(c)=k$ 존재
  • • 실근 판정: $f(a)f(b) < 0 \implies$ $(a, b)$에 실근 존재

01. 극한값이 존재하는 것 찾기 오지선다

다음 중 극한값이 존재하는 것은?

• ① 좌극한 $-\infty$, 우극한 $\infty$ 로 발산

• ② 좌극한 $-1$, 우극한 $1$ 로 불일치하여 존재하지 않음

• ③, ④ 양의 무한대 $\infty$ 로 발산

• ⑤ 분모·분자를 $x$로 나누면 $\lim_{x o -\infty} rac{2/x - 1}{1 + 3/x} = rac{-1}{1} = -1$ 로 유한하게 수렴! (정답 ⑤)

02. 그래프에서 좌우극한 읽기 그래프 해석

함수 $y=f(x)$ 의 그래프를 보고 $\lim_{x o -1^+} f(x) + \lim_{x o 1^-} f(x)$ 의 값을 구하시오.

• $x o -1^+$ 일 때의 우극한값은 2 입니다.

• $x o 1^-$ 일 때의 좌극한값은 1 입니다.

• 따라서 $2 + 1 = 3$ (정답 ④)

03. 극한의 성질 연립

$\lim_{x o \infty} f(x) = 4, \quad \lim_{x o \infty} \{2f(x) - 3g(x)\} = 6$

일 때, $\lim_{x o \infty} g(x)$ 의 값을 구하시오.

• $3g(x) = 2f(x) - \{2f(x) - 3g(x)\}$

• $3\lim_{x o \infty} g(x) = 2(4) - 6 = 8 - 6 = 2$

$ herefore \lim_{x o \infty} g(x) = rac{2}{3}$

04. 인수분해를 통한 함수 극한값

$\lim_{x o 1} rac{(x-1)f(x)}{x^3 - 1} = 2$

를 만족시킬 때, $\lim_{x o 1} f(x)$ 의 값을 구하시오.

• 분모를 인수분해: $x^3 - 1 = (x-1)(x^2 + x + 1)$

• $\lim_{x o 1} rac{(x-1)f(x)}{(x-1)(x^2 + x + 1)} = \lim_{x o 1} rac{f(x)}{x^2 + x + 1} = rac{\lim f(x)}{1+1+1} = rac{\lim f(x)}{3} = 2$

$ herefore \lim_{x o 1} f(x) = 6$

05. 닫힌구간에서의 유리함수 최대·최소

닫힌구간 $[-1, 1]$ 에서 함수 $f(x) = rac{2x + 8}{x + 3}$ 의 최댓값과 최솟값을 구하시오.

• $f(x) = rac{2(x+3)+2}{x+3} = 2 + rac{2}{x+3}$ 는 구간 $[-1, 1]$에서 감소함수입니다.

• 최댓값: $f(-1) = rac{-2+8}{-1+3} = rac{6}{2} = \mathbf{3}$

• 최솟값: $f(1) = rac{2+8}{1+3} = rac{10}{4} = \mathbf{ rac{5}{2}}$ (또는 2.5)

06. 무한대 차수 비교 곱 극한

$\lim_{x o \infty} \{f(x) - 4x^2\} = 3, \quad \lim_{x o \infty} x^2 g(x) = 5$

일 때, $\lim_{x o \infty} f(x)g(x)$ 의 값을 구하시오.

• $\lim_{x o \infty} rac{f(x) - 4x^2}{x^2} = 0 \implies \lim_{x o \infty} rac{f(x)}{x^2} = 4$

• $\lim_{x o \infty} f(x)g(x) = \lim_{x o \infty} \left\{ rac{f(x)}{x^2} \cdot x^2 g(x) ight\} = 4 imes 5 = \mathbf{20}$

07. 무한대 무리식 미정계수 결정

$\lim_{x o \infty} (\sqrt{4x^2 + 3x} - ax) = b$ (단, $a > 0$)

일 때, 상수 $a, b$의 값을 구하시오.

• 유한한 극한값이 존재하려면 최고차항 차수와 계수가 일치해야 하므로 $a = \sqrt{4} = \mathbf{2}$

• 분자 유리화: $\lim rac{4x^2+3x - 4x^2}{\sqrt{4x^2+3x} + 2x} = \lim rac{3x}{\sqrt{4x^2+3x} + 2x} = rac{3}{2+2} = \mathbf{ rac{3}{4}}$ (또는 0.75)

08. 다항함수 결정 복합

㈎ $\lim_{x o \infty} rac{f(x)}{x^2 + 2x} = 2$

㈏ $\lim_{x o -2} rac{f(x)}{x^2 - 4} = rac{3}{2}$

를 만족시킬 때, $f(2)$ 의 값을 구하시오.

• ㈎에서 $f(x)$는 최고차항이 $2x^2$인 이차다항식

• ㈏에서 분모 $ o 0$ 이므로 $f(-2) = 0 \implies f(x) = 2(x+2)(x-k)$

• $\lim_{x o -2} rac{2(x+2)(x-k)}{(x+2)(x-2)} = rac{2(-2-k)}{-4} = rac{k+2}{2} = rac{3}{2} \implies k = 1$

• $f(x) = 2(x+2)(x-1) \implies f(2) = 2(4)(1) = \mathbf{8}$

무리식 극한 유리화 실험실 : $y = \sqrt{4x^2 + 3x} - ax$ ★ a = 2.0 ⟹ 유한 수렴값 b = 0.75

09. 극한의 참·거짓 보기 판정 오개념 빈출

두 함수 $f(x), g(x)$에 대하여 옳은 것만을 보기에서 있는 대로 고른 것은?

ㄱ. $\lim \{f(x)\}^2$ 이 존재하면 $\lim f(x)$ 도 존재한다.

ㄴ. $\lim f(x)$ 와 $\lim \{f(x)-g(x)\}$ 가 존재하면 $\lim g(x)$ 도 존재한다.

ㄷ. $\lim rac{f(x)}{g(x)}$ 와 $\lim g(x)$ 가 존재하면 $\lim f(x)$ 도 존재한다.

ㄹ. $f(x) < g(x)$ 이고 $\lim g(x)$ 가 존재하면 $\lim f(x)$ 도 존재한다.

• ㄱ (거짓): 반례 $f(x) = egin{cases} 1 & (x \ge 0) \ -1 & (x < 0) \end{cases} \implies \{f(x)\}^2 = 1$ 수렴하지만 $f(x)$는 발산

• ㄴ (참): $g(x) = f(x) - \{f(x)-g(x)\}$ 이므로 두 극한의 차로 존재함

• ㄷ (참): $f(x) = rac{f(x)}{g(x)} \cdot g(x)$ 이므로 두 극한의 곱으로 존재함

• ㄹ (거짓): 반례 $f(x) = - rac{1}{x^2}$, $g(x) = 1$ 이면 $f < g$ 이지만 $x o 0$ 에서 $f(x) o -\infty$ 발산

$ herefore$ 정답: ② ㄴ, ㄷ

10. 연속함수 항등식과 f(5)

㈎ $f(2) > 0$

㈏ 모든 실수 $x$에 대하여 $(x-a)f(x) = x^2 - 4x + 3$

를 만족시킬 때, $f(5)$ 의 값을 구하시오.

• 우변 $= (x-1)(x-3)$. $x=a$ 대입 시 $(a-1)(a-3) = 0 \implies a = 1$ 또는 $a = 3$

• $a=1$ 이면 $x e 1$에서 $f(x)=x-3 \implies f(2) = -1 < 0$ (조건 ㈎ 위배)

• $a=3$ 이면 $x e 3$에서 $f(x)=x-1 \implies f(2) = 1 > 0$ (조건 ㈎ 만족!)

$ herefore f(5) = 5 - 1 = \mathbf{4}$

11. 곱함수 f(x)g(x)의 닫힌구간 연속성

$x=0$에서 불연속인 $f(x)$에 대해 $f(x)g(x)$가 $[-2, 2]$에서 연속이 되도록 하는 $g(x)$ 고르기

ㄱ. $g(x) = x^2 + x$

ㄴ. $g(x) = rac{|x|}{x}$

ㄷ. $g(x) = rac{x^2 - 3x}{x - 3}$

• $f(x)$는 $x=0$에서 좌극한 $-1$, 우극한 $1$로 불연속이므로, 연속이 되려면 $g(0) = \lim_{x o 0} g(x) = 0$ 이어야 합니다.

• ㄱ: $g(0) = 0$, 연속이므로 $fg$는 $x=0$에서 $0$으로 연속 (참)

• ㄴ: $g(0)$ 자체가 정의되지 않아 불연속 (거짓)

• ㄷ: $g(x) = x$ ($x e 3$) 이므로 $x=0$에서 $g(0)=0$ 연속 (참)

$ herefore$ 정답: ④ ㄱ, ㄷ

12. 사잇값 정리와 실근 범위 n의 최솟값

방정식 $x^3 + 3x - 10 = 0$ 이 단 하나의 실근 $lpha$를 가질 때,

$0 < lpha < n$ 을 만족시키는 자연수 $n$의 최솟값을 구하시오.

• $f(x) = x^3 + 3x - 10$

• $f(0) = -10 < 0$

• $f(1) = 1 + 3 - 10 = -6 < 0$

• $f(2) = 8 + 6 - 10 = 4 > 0$

• $f(1)f(2) < 0$ 이므로 사잇값 정리에 의해 $1 < lpha < 2$

$ herefore 0 < lpha < n$ 을 만족하는 자연수 $n$의 최솟값은 $\mathbf{2}$ 입니다.

13. 샌드위치 정리와 합성 극한

$ rac{x+8}{x+2} \le f(x) \le rac{3x+4}{x+1}$

를 만족시킬 때, $\lim_{x o \infty} f( rac{1}{x})$ 의 값을 구하시오.

• $t = rac{1}{x}$ 로 치환하면 $x o \infty$ 일 때 $t o 0^+$

• $\lim_{t o 0^+} rac{t+8}{t+2} = rac{8}{2} = 4$

• $\lim_{t o 0^+} rac{3t+4}{t+1} = rac{4}{1} = 4$

$ herefore$ 샌드위치 정리에 의해 $\lim_{x o \infty} f( rac{1}{x}) = \lim_{t o 0^+} f(t) = \mathbf{4}$

14. 연속함수 미정계수와 f(b)

$(x-2)f(x) = x^3 - 3x^2 + ax + b, \quad f(2) = 4$

일 때, $f(b)$ 의 값을 구하시오. (단, $a, b$는 상수)

• $f(x) = x^2 - x + 2 \implies f(b) = f(-4) = (-4)^2 - (-4) + 2 = 16 + 4 + 2 = \mathbf{22}$

15. 원과 접선의 기하 극한 S/m

원 $x^2 + y^2 = 4$ 와 직선 $y = mx$ 의 1사분면 교점 P에서의 접선과 $x$축, $y$축으로 둘러싸인 삼각형 넓이 $S$

일 때, $\lim_{m o \infty} rac{S}{m}$ 의 값을 구하시오.

• 점 P의 좌표: $\left( rac{2}{\sqrt{1+m^2}}, rac{2m}{\sqrt{1+m^2}} ight)$

• 접선 $l$: $ rac{2}{\sqrt{1+m^2}}x + rac{2m}{\sqrt{1+m^2}}y = 4$

• $x$절편 $2\sqrt{1+m^2}$, $y$절편 $ rac{2\sqrt{1+m^2}}{m}$

• $S = rac{1}{2} \cdot 2\sqrt{1+m^2} \cdot rac{2\sqrt{1+m^2}}{m} = rac{2(1+m^2)}{m}$

$ herefore \lim_{m o \infty} rac{S}{m} = \lim_{m o \infty} rac{2(1+m^2)}{m^2} = \mathbf{2}$

햄샌드위치 정리 (Ham Sandwich Theorem):

$n$차원 공간의 $n$개의 물체는 각각 이등분이 되도록 $(n-1)$차원의 평면 공간으로 단 한 번에 자를 수 있다.

평면(2차원)에서는 2개의 도형을 직선(1차원)으로 동시에 이등분할 수 있으며, 이를 팬케이크 정리라고 부릅니다. 이 아름다운 정리의 수학적 증명 핵심이 바로 사잇값 정리입니다!

사잇값 정리를 이용한 넓이 이등분선 증명 (교과서 47쪽)

좌표평면 위에 넓이가 $S$인 도형이 있을 때, $a \le k \le b$ 인 $k$에 대하여 직선 $x = k$에 의하여 나누어진 도형의 왼쪽 부분 넓이를 $f(k)$라고 하자.
