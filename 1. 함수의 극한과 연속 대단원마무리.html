Ⅰ. 함수의 극한과 연속 핵심 개념 마인드맵

1. 함수의 극한

  • 수렴과 발산: $\lim_{x \to a} f(x) = L$ (우극한 = 좌극한)
  • 기본 성질: 수렴할 때 사칙연산 분배 가능
  • 부정형: $\frac{0}{0}$ (인수분해/유리화), $\frac{\infty}{\infty}$ (최고차항 나누기)
  • 조임정리: $g(x) \le f(x) \le h(x)$이고 양끝 극한이 같으면 가운데도 동일

2. 함수의 연속

  • 연속 조건: ① $f(a)$ 정의, ② $\lim_{x \to a} f(x)$ 존재, ③ 두 값 일치
  • 최대·최소 정리: 닫힌구간에서 연속이면 반드시 최댓값, 최솟값 존재
  • 사잇값 정리: 닫힌구간 연속 & $f(a) \ne f(b)$이면 사잇값 $k$를 만족하는 $c$ 존재
  • 실근 판정: $f(a)f(b) < 0$이면 열린구간 $(a, b)$에서 적어도 하나의 실근 가짐

기본 평가 문제 (01 ~ 02)

문제 01 (극한 계산)

다음 극한값을 구하시오: $\lim_{x \to 2} \frac{x^2 + x - 6}{x - 2}$

분자를 인수분해하면 $(x-2)(x+3)$입니다.

$$\lim_{x \to 2} \frac{(x-2)(x+3)}{x-2} = \lim_{x \to 2} (x+3) = 5$$

문제 풀이 연습장
문제 02 (무한대 극한)

다음 극한값을 구하시오: $\lim_{x \to \infty} (\sqrt{x^2 + 4x} - x)$

분자를 유리화합니다:

$$\lim_{x \to \infty} \frac{(x^2 + 4x) - x^2}{\sqrt{x^2 + 4x} + x} = \lim_{x \to \infty} \frac{4x}{\sqrt{x^2 + 4x} + x} = \frac{4}{1 + 1} = 2$$

문제 풀이 연습장

표준 평가 문제 (03 ~ 04)

문제 03 (미정계수 결정)

$\lim_{x \to 1} \frac{x^2 + ax + b}{x - 1} = 3$ 을 만족시키는 상수 $a, b$에 대하여 $a - b$의 값을 구하시오.

분모 $\to 0$이므로 분자 $1 + a + b = 0 \implies b = -a - 1$.

분자 $x^2 + ax - a - 1 = (x-1)(x + a + 1)$.

$$\lim_{x \to 1} (x + a + 1) = a + 2 = 3 \implies a = 1, b = -2$$

따라서 $a - b = 1 - (-2) = 3$ 입니다.

문제 풀이 연습장
문제 04 (연속성과 미정계수)

모든 실수에서 연속인 함수 $f(x)$가 $(x-2)f(x) = x^2 + ax - 6$ 을 만족시킬 때, $f(2)$의 값을 구하시오.

$x=2$를 대입하면 $0 = 4 + 2a - 6 \implies 2a = 2 \implies a = 1$.

$f(x)$가 연속이므로 $f(2) = \lim_{x \to 2} f(x) = \lim_{x \to 2} \frac{x^2 + x - 6}{x - 2} = \lim_{x \to 2} (x+3) = 5$.

문제 풀이 연습장

발전 & 수능형 서술형 문제 (05 ~ 06)

문제 05 (사잇값 정리의 활용)

연속함수 $f(x)$에 대하여 $f(0) = 1, f(1) = -2, f(2) = 3, f(3) = 1$ 일 때, 방정식 $f(x) = 0$은 열린구간 $(0, 3)$에서 적어도 몇 개의 실근을 갖는가?

• 구간 $(0, 1)$: $f(0)f(1) = 1 \times (-2) = -2 < 0 \implies$ 적어도 1개 실근

• 구간 $(1, 2)$: $f(1)f(2) = (-2) \times 3 = -6 < 0 \implies$ 적어도 1개 실근

• 구간 $(2, 3)$: $f(2)f(3) = 3 \times 1 = 3 > 0$

따라서 열린구간 $(0, 3)$에서 적어도 2개의 실근을 갖습니다.

문제 풀이 연습장
문제 06 (다항함수 추론 수능형)

다항함수 $f(x)$가 $\lim_{x \to \infty} \frac{f(x)}{2x^2 + 1} = 1$, $\lim_{x \to 0} \frac{f(x)}{x} = 3$ 을 만족할 때, $f(2)$의 값을 구하시오.

1) 첫 번째 조건: $f(x)$는 최고차항이 $2x^2$인 2차 다항함수입니다.

2) 두 번째 조건: $x \to 0$일 때 분모 $\to 0$이므로 $f(0) = 0$ (상수항 0).

따라서 $f(x) = 2x^2 + ax$로 둘 수 있고, $\lim_{x \to 0} \frac{2x^2 + ax}{x} = a = 3$.

$$f(x) = 2x^2 + 3x \implies f(2) = 2(4) + 3(2) = 8 + 6 = 14$$

문제 풀이 연습장
