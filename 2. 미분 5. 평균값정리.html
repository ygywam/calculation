핵심 정리

롤의 정리 (Rolle's Theorem)

교과서 75쪽

함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이고 열린구간 $(a, b)$에서 미분가능할 때,

$$f(a) = f(b) \implies f'(c) = 0$$

인 $c$가 열린구간 $(a, b)$에 적어도 하나 존재한다.

롤의 정리의 3대 필수 전제 조건
  • 연속성: 닫힌구간 $[a, b]$에서 끊김이 없어야 함 (최대·최소 정리의 보장).
  • 미분가능성: 열린구간 $(a, b)$에서 뾰족점(첨점)이 없어야 함 (접선의 유일성).
  • 양 끝점 높이 일치: $f(a) = f(b)$여야 수평선(기울기 0)이 됨.
프랑스의 수학자 롤 (Rolle, M., 1652~1719)

방정식의 실근 위치를 다항식의 도함수를 통해 연구하는 과정에서 롤의 정리를 발표하였습니다.

배운 내용: 최대·최소 정리 연계
수학적 증명

최대·최소 정리를 이용한 롤의 정리 증명

교과서 75~76쪽 상세 증명

함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이므로 최대·최소 정리에 의하여 이 구간에서 반드시 최댓값과 최솟값을 갖습니다.

1 (i) 함수 $f(x)$가 상수함수인 경우

$f(x) = C$ (상수)이면 열린구간 $(a, b)$에 속하는 모든 $c$에 대하여 도함수 $f'(c) = 0$이 성립합니다.

2 (ii) 함수 $f(x)$가 상수함수가 아닌 경우

$f(a) = f(b)$이지만 상수함수가 아니므로, $f(x)$는 양 끝점이 아닌 열린구간 $(a, b)$에 속하는 어떤 점 $x = c$에서 최댓값 또는 최솟값을 갖습니다.

ⓐ $x = c$에서 최댓값을 갖는 경우:

절댓값이 충분히 작은 수 $h \neq 0$에 대하여 $f(c+h) \le f(c)$이므로 $f(c+h) - f(c) \le 0$입니다.

$h < 0$이면 $\dfrac{f(c+h)-f(c)}{h} \ge 0$
$h > 0$이면 $\dfrac{f(c+h)-f(c)}{h} \le 0$

그런데 $f(x)$는 $x = c$에서 미분가능하므로 좌극한과 우극한이 같습니다. 따라서

$$0 \le \lim_{h \to 0^-} \frac{f(c+h)-f(c)}{h} = \lim_{h \to 0^+} \frac{f(c+h)-f(c)}{h} \le 0 \implies f'(c) = 0$$
ⓑ $x = c$에서 최솟값을 갖는 경우:

부등호 방향만 반대로 바뀌고 ⓐ와 완전히 동일한 방법으로 $f'(c) = 0$임을 증명할 수 있습니다.

롤의 정리를 만족시키는 상수 구하기

교과서 76쪽

함수 $f(x) = -x^2 + 4x$에 대하여 닫힌구간 $[0, 4]$에서 롤의 정리를 만족시키는 상수 $c$의 값을 구하시오.

풀이 과정:

1) 함수 $f(x) = -x^2 + 4x$는 다항함수이므로 닫힌구간 $[0, 4]$에서 연속이고 열린구간 $(0, 4)$에서 미분가능합니다.

2) 양 끝값 확인: $f(0) = 0$, $f(4) = -16 + 16 = 0 \implies f(0) = f(4) = 0$.

3) 따라서 롤의 정리에 의해 $f'(c) = 0$인 $c$가 열린구간 $(0, 4)$에 적어도 하나 존재합니다.

4) 도함수 $f'(x) = -2x + 4$이므로 $f'(c) = -2c + 4 = 0 \implies \mathbf{c = 2}$. ($2 \in (0, 4)$ 적합)

정답: $c = 2$

평균값 정리는 무엇일까?

두 점을 잇는 직선의 기울기(평균변화율)와 같은 접선의 기울기(순간변화율)를 갖는 점이 구간 내에 반드시 존재한다는, 미적분학의 가장 중요한 정리입니다.

대정리

평균값 정리 (Mean Value Theorem, MVT)

교과서 77쪽

함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이고 열린구간 $(a, b)$에서 미분가능하면

$$\frac{f(b) - f(a)}{b - a} = f'(c)$$

인 $c$가 열린구간 $(a, b)$에 적어도 하나 존재한다.

기하학적 본질: 할선과 평행한 접선의 존재

곡선 위의 두 점 $A(a, f(a))$와 $B(b, f(b))$를 지나는 할선의 기울기 $\frac{f(b)-f(a)}{b-a}$와 같은 기울기를 갖는 접선이 곡선 위에 적어도 하나 반드시 존재함을 뜻합니다.

💡 롤의 정리와의 관계

평균값 정리에서 $f(a) = f(b)$가 되면 좌변 평균변화율이 $0$이 되어 $f'(c) = 0$인 롤의 정리가 됩니다. 즉, 롤의 정리는 평균값 정리의 특수한 경우입니다.

수학적 증명

롤의 정리를 이용한 평균값 정리의 증명

교과서 77~78쪽

곡선 $y = f(x)$ 위의 두 점 $A(a, f(a))$, $B(b, f(b))$를 지나는 직선을 $y = g(x)$라 하면 직선의 방정식은 다음과 같습니다:

$$g(x) = \frac{f(b) - f(a)}{b - a}(x - a) + f(a)$$
★ 보조함수 $h(x) = f(x) - g(x)$의 도입

곡선과 직선의 함숫값 차이를 나타내는 보조함수 $h(x) = f(x) - g(x)$를 생각합니다.

1) 양 끝점 확인:
$h(a) = f(a) - g(a) = f(a) - f(a) = 0$
$h(b) = f(b) - g(b) = f(b) - f(b) = 0$
$\implies \mathbf{h(a) = h(b) = 0}$
2) 연속과 미분가능:
$f(x)$와 $g(x)$가 모두 $[a, b]$에서 연속이고 $(a, b)$에서 미분가능하므로 차함수 $h(x)$도 연속 및 미분가능합니다.

따라서 함수 $h(x)$에 롤의 정리를 적용하면 $h'(c) = 0$인 $c$가 열린구간 $(a, b)$에 적어도 하나 존재합니다.

$$h'(c) = f'(c) - g'(c) = f'(c) - \frac{f(b) - f(a)}{b - a} = 0 \implies \mathbf{f'(c) = \frac{f(b) - f(a)}{b - a}}$$

Q.E.D. (증명 완료)

예제 2

평균값 정리를 만족시키는 상수 구하기

교과서 78쪽

함수 $f(x) = x^2 - 3x$에 대하여 닫힌구간 $[1, 4]$에서 평균값 정리를 만족시키는 상수 $c$의 값을 구하시오.

단계별 풀이:

1) 구간 $[1, 4]$에서의 평균변화율 계산:

$$\frac{f(4) - f(1)}{4 - 1} = \frac{(16 - 12) - (1 - 3)}{3} = \frac{4 - (-2)}{3} = \frac{6}{3} = \mathbf{2}$$

2) 도함수 $f'(x) = 2x - 3$이므로 $f'(c) = 2c - 3$.

3) 평균값 정리에 의해 $f'(c) = 2$를 만족해야 하므로:

$$2c - 3 = 2 \implies 2c = 5 \implies \mathbf{c = \frac{5}{2}}$$

4) $c = \frac{5}{2} = 2.5$는 열린구간 $(1, 4)$에 속하므로 적합합니다.

정답: $c = \frac{5}{2}$

예제 3 $f'(x) = 0 \implies f(x) = C$ 증명

함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이고 열린구간 $(a, b)$에서 미분가능할 때, 열린구간 $(a, b)$에 속하는 모든 $x$에서 $f'(x) = 0$이면 함수 $f(x)$는 닫힌구간 $[a, b]$에서 상수함수임을 보이시오.

증명:

$a < x \le b$인 임의의 실수 $x$에 대하여 $f(x)$는 닫힌구간 $[a, x]$에서 연속이고 열린구간 $(a, x)$에서 미분가능합니다.

평균값 정리에 의하여 $\dfrac{f(x) - f(a)}{x - a} = f'(c)$인 $c$가 열린구간 $(a, x)$에 적어도 하나 존재합니다.

그런데 모든 $x$에서 $f'(x) = 0$이므로 $f'(c) = 0$입니다. 따라서

$$f(x) - f(a) = 0 \implies \mathbf{f(x) = f(a) = \text{상수 } C}$$

따라서 함수 $f(x)$는 닫힌구간 $[a, b]$에서 상수함수입니다.

문제 4 (추론)

두 함수 $f(x), g(x)$가 닫힌구간 $[a, b]$에서 연속이고 열린구간 $(a, b)$에서 미분가능할 때, 열린구간 $(a, b)$에 속하는 모든 $x$에서 $f'(x) = g'(x)$이면 닫힌구간 $[a, b]$에서 $f(x) = g(x) + k$ 임을 보이시오. (단, $k$는 상수이다.)

증명 풀이:

$h(x) = f(x) - g(x)$라고 놓으면, $h(x)$는 $[a, b]$에서 연속이고 $(a, b)$에서 미분가능합니다.

모든 $x \in (a, b)$에 대하여 $h'(x) = f'(x) - g'(x) = 0$입니다.

따라서 위의 예제 3의 결과에 의해 $h(x)$는 닫힌구간 $[a, b]$에서 상수함수입니다. 즉, $h(x) = k$ (상수).

$$f(x) - g(x) = k \implies \mathbf{f(x) = g(x) + k}$$

1. $h(t) = f(t) - g(t)$ 일 때 $h(0)$과 $h(15)$의 값

출발 시각($t=0$)과 결승선 통과 시각($t=15$)에서 두 사람의 위치 차이를 구해 보세요.

$h(0) = f(0) - g(0) = 0 - 0 = \mathbf{0}$
$h(15) = f(15) - g(15) = 100 - 100 = \mathbf{0}$
2. 순간속도가 같았던 시각의 존재 증명

함수 $h(t)$가 $[0, 15]$에서 연속이고 $(0, 15)$에서 미분가능함을 이용하여 설명하세요.

$h(0) = h(15) = 0$이므로 롤의 정리에 의하여

$$h'(c) = 0 \iff f'(c) = g'(c)$$

인 시각 $c \in (0, 15)$가 반드시 적어도 한 번 존재합니다!

함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이고 열린구간 $(a, b)$에서 미분가능하면

$$\frac{f(b) - f(a)}{b - a} = $$ 인 $c$가 열린구간 $(a, b)$에 적어도 하나 존재한다.
[01번 정답 및 개념 해설]

• 평균값 정리의 정의: 함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이고 열린구간 $(a, b)$에서 미분가능하면 $\dfrac{f(b) - f(a)}{b - a} = \mathbf{f'(c)}$인 $c$가 열린구간 $(a, b)$에 적어도 하나 존재합니다.

• 기하학적으로는 두 점 $(a, f(a))$, $(b, f(b))$를 잇는 할선의 기울기와 같은 기울기를 갖는 접선이 곡선 위에 적어도 하나 존재함을 뜻합니다.

06 생각을 키우는 문제

도함수 범위 $1 \le f'(x) \le 2$와 $f(3)$의 범위 추론

다음은 다항함수 $f(x)$가 $f(0) = 3$이고 $0 < x < 3$인 모든 $x$에서 $1 \le f'(x) \le 2$일 때, $f(3)$의 값의 범위를 구하는 과정이다. (가), (나), (다)에 알맞은 것을 써넣으시오.

함수 $f(x)$는 닫힌구간 $[0, 3]$에서 연속이고 열린구간 $(0, 3)$에서 미분가능하므로 평균값 정리에 의하여

$$\frac{\text{(가)}}{3 - 0} = f'(c)$$

인 상수 $c$가 열린구간 $(0, 3)$에 적어도 하나 존재한다.

이때 $\text{(가)} = 3f'(c)$이고 $1 \le f'(c) \le 2$이므로

$$\text{(나)} \le f(3) \le \text{(다)}$$

이다.

모범 풀이:

1) 구간 $[0, 3]$에서 평균값 정리: $\dfrac{f(3) - f(0)}{3 - 0} = f'(c) \implies \dfrac{f(3) - 3}{3} = f'(c)$.

따라서 (가) = $f(3) - 3$.

2) 양변에 $3$을 곱하면 $f(3) - 3 = 3f'(c)$.

3) $1 \le f'(c) \le 2$이므로 각 변에 $3$을 곱하면 $3 \le 3f'(c) \le 6 \implies 3 \le f(3) - 3 \le 6$.

4) 각 변에 $3$을 더하면 $\mathbf{6 \le f(3) \le 9}$.

따라서 (나) = 6, (다) = 9 입니다.
