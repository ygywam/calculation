# 2022 개정 교육과정 고등학교 미적분Ⅰ 수업 대시보드

> 고등학교 2학년 수학과 「미적분Ⅰ」 전 단원(20개 단원, 40차시 완결)의 인터랙티브 웹 수업자료 및 교과서 원본 PDF를 한곳에서 연결하는 디지털 수업 포털입니다.
> 교실 전자칠판, PC, 태블릿에서 별도의 설치 없이 브라우저로 즉시 수업에 활용할 수 있습니다.

---

## ✨ 핵심 기능 및 특징

1. **전 단원 전자칠판(Whiteboard) 판서 탑재**:
   - 모든 20개 HTML 수업자료에 스크롤 동기화형 전자칠판 캔버스 및 플로팅 툴바 내장
   - 펜, 형광펜, 지우개, 색상 팔레트, 굵기 조절, 판서 초기화 및 PNG 이미지 저장 지원
2. **단원별 인터랙티브 캔버스 실험실**:
   - 각 소단원마다 직관적 개념 탐구를 위한 전용 동적 시뮬레이터(HTML5 Canvas API) 제공
   - 슬라이더 조작을 통한 실시간 그래프 변화, 수렴 과정, 실근 탐색, 극값 판정
3. **문제 풀이 연습장 (스크래치패드)**:
   - 예제 및 평가 문항마다 인라인 모눈 연습장 캔버스가 내장되어 직접 손글씨로 풀이 가능
4. **KaTeX 고품질 수식 렌더링**:
   - 교과서 수준의 미려한 수식 표기
5. **라이트 모드 최적화 (Enforce Light Mode)**:
   - 교실 빔 프로젝터 및 디스플레이 가독성을 극대화한 밝고 선명한 UI

## 📌 단원 구성 (전 단원 총 20개 단원, 40차시 완결)

### Ⅰ. 함수의 극한과 연속 (5개 단원)
1. **01. 함수의 극한** (`1. 함수의 극한과 연속 1. 함수의 극한.html` / `pdf`)
   - 수렴과 발산, 좌극한과 우극한, 극한값의 존재
2. **02. 함수의 극한에 대한 성질** (`1. 함수의 극한과 연속 2. 함수의 극한에 대한 성질.html` / `pdf`)
   - 극한의 기본 성질, $\frac{0}{0}$ 부정형(인수분해·유리화), $\frac{\infty}{\infty}$, 미정계수 결정
3. **03. 함수의 연속** (`1. 함수의 극한과 연속 3. 함수의 연속.html` / `pdf`)
   - $x=a$에서 연속의 3조건, 불연속 유형, 구간의 기호
4. **04. 연속함수의 성질** (`1. 함수의 극한과 연속 4. 연속함수의 성질.html` / `pdf`)
   - 연속함수의 연산, 최대·최소 정리, 사잇값 정리 및 실근의 존재 판정
5. **대단원 마무리평가 (Ⅰ. 함수의 극한과 연속)** (`1. 함수의 극한과 연속 대단원마무리.html` / `pdf`)
   - 1단원 핵심 개념 총정리 및 수능/내신 대비 6대 핵심 문항 풀이

### Ⅱ. 미분 (10개 단원)
6. **01. 미분계수** (`2. 미분 1. 미분계수.html` / `pdf`)
   - 평균변화율, 미분계수, 기하학적 의미(접선의 기울기)
7. **02. 미분가능성과 연속성** (`2. 미분 2. 미분가능성과 연속성.html` / `pdf`)
   - 미분가능 $\implies$ 연속, 뾰족점(첨점)에서의 미분불가, 좌우미분계수
8. **03. 도함수** (`2. 미분 3. 도함수.html` / `pdf`)
   - 도함수의 정의, $y=x^n$ 미분법, 곱의 미분법 공식
9. **04. 접선의 방정식** (`2. 미분 4. 접선의 방정식.html` / `pdf`)
   - 곡선 위의 점, 기울기 주어짐, 곡선 밖의 점에서 그은 접선 3가지 유형
10. **05. 평균값정리** (`2. 미분 5. 평균값정리.html` / `pdf`)
    - 롤의 정리, 평균값 정리 및 기하학적 의미
11. **06. 함수의 증가와 감소, 극대와 극소** (`2. 미분 6. 함수의 증가와 감소, 극대와 극소.html` / `pdf`)
    - 도함수 부호와 증가·감소, 극대·극소 판정, 증감표
12. **07. 함수의 그래프** (`2. 미분 7. 함수의 그래프.html` / `pdf`)
    - 다항함수 그래프 개형 4단계, 닫힌구간에서의 최대·최소
13. **08. 방정식과 부등식에의 활용** (`2. 미분 8. 방정식과 부등식.html` / `pdf`)
    - 실근의 개수 판정, 모든 실수 또는 구간에서의 부등식 증명
14. **09. 속도와 가속도** (`2. 미분 9. 속도와 가속도.html` / `pdf`)
    - 수직선 위 점의 위치, 속도, 가속도, 운동 방향 전환
15. **대단원 마무리평가 (Ⅱ. 미분)** (`2. 미분 대단원마무리.html` / `pdf`)
    - 2단원 핵심 총정리 및 실전 8문항 풀이

### Ⅲ. 적분 (5개 단원)
16. **01~02. 부정적분과 그 계산** (`3. 적분 1~2. 부정적분, 계산.html` / `pdf`)
    - 부정적분의 뜻과 성질, 적분상수 $C$, 거듭제곱 적분 공식
17. **03. 정적분** (`3. 적분 3. 정적분.html` / `pdf`)
    - 정적분의 정의, 미적분의 기본정리, 우함수·기함수 대칭 정적분
18. **04. 넓이** (`3. 적분 4. 넓이.html` / `pdf`)
    - 곡선과 좌표축 사이의 넓이, 두 곡선 사이의 넓이, 포물선 넓이 공식
19. **05. 속도와 거리** (`3. 적분 5. 속도와 거리.html` / `pdf`)
    - 위치의 변화량(변위)과 실제로 움직인 거리의 구분 및 계산
20. **대단원 마무리평가 (Ⅲ. 적분)** (`3. 적분 대단원마무리.html` / `pdf`)
    - 3단원 핵심 총정리 및 미적분Ⅰ 전 단원 종합 성취평가

## 🚀 GitHub & Vercel 배포 가이드

본 프로젝트는 순수 정적 웹사이트(Static Web App)이므로 빌드 설정 없이 즉시 배포할 수 있습니다.

1. **GitHub 저장소에 푸시**
   - 워크스페이스 내 모든 파일(HTML, PDF, `index.html`, `vercel.json` 등)을 그대로 커밋 및 푸시합니다.
2. **Vercel 프로젝트 생성 (https://vercel.com)**
   - Vercel에서 **[Add New...]** → **[Project]**를 선택하고 GitHub 저장소를 Import합니다.
3. **배포 완료**
   - Framework Preset: `Other` (기본값)
   - Root Directory: `./` (기본값)
   - Build Settings: 변경 없이 그대로 **[Deploy]** 클릭!
   - 10초 이내에 전 세계 어디서나 접속 가능한 수업 포털 주소(`https://your-project.vercel.app`)가 생성됩니다.
