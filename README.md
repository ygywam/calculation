## 📌 단원 구성 (기말고사 범위 총 8개 단원)

### Ⅱ. 미분 (도함수의 활용)
1. **08. 방정식과 부등식에의 활용** (`2. 미분 8. 방정식과 부등식.html` / `pdf`)
   - 방정식 $f(x)=0$, $f(x)=a$의 실근의 개수 탐구
   - 극값을 이용한 삼차방정식 근의 판별
   - 최솟값을 이용한 부등식 증명 및 매개변수 $k$의 범위
2. **09. 속도와 가속도** (`2. 미분 9. 속도와 가속도.html` / `pdf`)
   - 수직선 위를 움직이는 점의 위치, 속도, 가속도
   - 운동 방향 전환($v=0$)의 조건
   - 연직 투상 운동(물로켓) 해석
3. **대단원 마무리평가 (미분)** (`2. 미분 대단원마무리.html` / `pdf`)
   - 미분 전 단원 핵심 마인드맵 및 대단원 실전 기출 문제

### Ⅲ. 적분 (부정적분, 정적분 및 그 활용)
4. **01~02. 부정적분과 그 계산** (`3. 적분 1~2. 부정적분, 계산.html` / `pdf`)
   - 부정적분의 뜻과 적분상수 $C$
   - 거듭제곱 함수의 부정적분 공식 및 성질
5. **03. 정적분** (`3. 적분 3. 정적분.html` / `pdf`)
   - 정적분의 정의와 미적분의 기본정리
   - 정적분의 성질 및 우함수·기함수 대칭 정적분
   - 정적분으로 정의된 함수
6. **04. 넓이** (`3. 적분 4. 넓이.html` / `pdf`)
   - 곡선과 $x$축 사이의 넓이
   - 두 곡선 사이의 넓이 및 포물선 공식
   - 역함수 그래프와 넓이
7. **05. 속도와 거리** (`3. 적분 5. 속도와 거리.html` / `pdf`)
   - 속도 함수의 적분과 수직선 위 점의 위치
   - 위치의 변화량(변위)과 움직인 거리의 구분
8. **대단원 마무리평가 (적분)** (`3. 적분 대단원마무리.html` / `pdf`)
   - 적분 전 단원 핵심 총정리 및 수능 연계 실전 문제

## 🚀 Vercel 배포 가이드 (3단계)

본 프로젝트는 별도의 빌드 과정(npm run build 등)이 필요 없는 **순수 정적 웹사이트(Static Web App)**입니다.

1. **GitHub 저장소 생성 및 푸시**
   - GitHub에 새 저장소(Repository)를 만들고 이 폴더의 파일들을 업로드합니다.
2. **Vercel 연동 (https://vercel.com)**
   - Vercel 로그인 후 **[Add New...]** → **[Project]** 클릭
   - 방금 올린 GitHub 저장소를 선택하고 **[Import]** 클릭
3. **배포 (Deploy)**
   - **Framework Preset**: `Other` (자동 감지됨)
   - **Root Directory**: `./` (기본값 그대로)
   - **Build and Output Settings**: 모두 비워둠 (정적 파일 배포)
   - **[Deploy]** 버튼 클릭! (약 10초 만에 나만의 수업 도메인 `https://your-project.vercel.app` 발급)
