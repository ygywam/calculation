07. 함수의 그래프와 최대·최소

도함수의 부호와 증감표를 통해 3차·4차 다항함수의 그래프 개형을 완벽히 스케치하고, 닫힌구간에서의 최대·최소 판정법과 실생활 상자 부피 최적화 랩 등 4종의 인터랙티브 실험실을 탐구합니다.

27차시 · 교과서 87~89쪽

함수의 그래프의 개형은 어떻게 그릴까?

도함수 $f'(x)$의 부호 변화를 증감표로 정리하여 극값과 절편을 구하면 함수의 그래프 개형을 정확히 그릴 수 있습니다.

생각 열기

삼차함수의 그래프 개형 탐구하기

교과서 87쪽

함수 $f(x) = x^3 - 3x^2 + 2$에 대하여 도함수 $f'(x) = 3x^2 - 6x = 3x(x - 2)$의 부호가 변하는 지점을 관찰하여 극댓값과 극솟값을 찾아보세요.

극댓값 $f(0)$:
극솟값 $f(2)$:
삼차함수 $y = x^3 - 3x^2 + 2$의 개형 스케치

생각 열기 상세 해설

도함수 $f'(x) = 3x^2 - 6x = 3x(x - 2) = 0$에서 $x = 0$ 또는 $x = 2$입니다.

1) $x = 0$의 좌우에서 $f'(x)$의 부호가 양($+$)에서 음($-$)으로 바뀌므로 $x = 0$에서 극댓값 $f(0) = 2$를 갖습니다.

2) $x = 2$의 좌우에서 $f'(x)$의 부호가 음($-$)에서 양($+$)으로 바뀌므로 $x = 2$에서 극솟값 $f(2) = 8 - 12 + 2 = -2$를 갖습니다.

핵심 정리

다항함수의 그래프 개형을 그리는 3단계

교과서 88쪽
1 도함수 $f'(x)$ 구하기

함수를 미분하여 도함수 $f'(x)$를 구하고, $f'(x) = 0$을 만족하는 $x$의 값을 구합니다.

2 증감표 작성하기

$f'(x)$의 부호를 조사하여 함수의 증가($\nearrow$)와 감소($\searrow$)를 나타내는 증감표를 작성하고 극값을 구합니다.

3 극값 & 절편 연결

극점 및 좌표축과의 교점($y$절편 $f(0)$ 등)을 좌표평면에 표시하고 매끄러운 곡선으로 연결합니다.

예제 1

삼차함수의 그래프의 개형 그리기

교과서 88쪽

함수 $f(x) = x^3 - 3x + 1$의 그래프의 개형을 그리시오.

[풀이]

1) 도함수: $f'(x) = 3x^2 - 3 = 3(x+1)(x-1) = 0 \implies x = -1$ 또는 $x = 1$

2) 증감표:

$x$ $\cdots$ $-1$ $\cdots$ $1$ $\cdots$
$f'(x)$ $+$ $0$ $-$ $0$ $+$
$f(x)$ $\nearrow$ 극대 $3$ $\searrow$ 극소 $-1$ $\nearrow$

3) $y$절편은 $(0, 1)$이므로, 점 $(-1, 3)$, $(0, 1)$, $(1, -1)$을 지나는 매끄러운 곡선으로 개형을 완성합니다.

사차함수의 그래프의 개형

사차함수의 도함수는 삼차방정식이므로 서로 다른 세 실근(W자형), 중근과 한 실근(한쪽 멈춤점), 한 실근(대칭 포물선형)의 다양한 개형이 나타납니다.

예제 2

사차함수의 그래프의 개형 그리기

교과서 89쪽

함수 $f(x) = 3x^4 - 4x^3 - 12x^2 + 1$의 그래프의 개형을 그리시오.

[풀이]

1) 도함수: $f'(x) = 12x^3 - 12x^2 - 24x = 12x(x+1)(x-2) = 0 \implies x = -1, 0, 2$

2) 극값 조사:

  • $x = -1$에서 극솟값 $f(-1) = -4$
  • $x = 0$에서 극댓값 $f(0) = 1$
  • $x = 2$에서 극솟값 $f(2) = -31$

3) 점 $(-1, -4)$, $(0, 1)$, $(2, -31)$을 지나는 비대칭 W자 형태의 매끄러운 곡선으로 개형을 그립니다.

문제 2

사차함수의 그래프의 개형 그리기

교과서 90쪽
(1) $f(x) = x^4 - 8x^2 + 1$

짝수차항만 존재하는 우함수(대칭 W자)입니다. 극댓값과 극솟값을 구하세요.

극댓값: 극솟값:
(2) $f(x) = -3x^4 + 8x^3 - 6x^2 + 1$

$f'(x) = -12x(x-1)^2$일 때, 극값의 존재 특성을 선택하세요.

문제 2 상세 해설

(1) $f(x) = x^4 - 8x^2 + 1$:

$f'(x) = 4x^3 - 16x = 4x(x^2 - 4) = 4x(x-2)(x+2) = 0 \implies x = 0, \pm 2$

$x = 0$에서 극댓값 $f(0) = 1$, $x = \pm 2$에서 극솟값 $f(\pm 2) = 16 - 32 + 1 = -15$로 완벽한 좌우 대칭 W자 개형입니다.

(2) $f(x) = -3x^4 + 8x^3 - 6x^2 + 1$:

$f'(x) = -12x^3 + 24x^2 - 12x = -12x(x^2 - 2x + 1) = -12x(x-1)^2$

$(x-1)^2 \ge 0$이므로 $x = 1$ 좌우에서 부호가 변하지 않아 극값이 아닙니다. 오직 $x = 0$에서만 극댓값 $f(0) = 1$을 가지며, $x = 1$에서는 접선의 기울기가 0이 되며 멈추었다가 계속 감소하는 개형입니다.

교과서 91쪽

📌 최대·최소 정리와 판정법

함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이면 이 구간에서 $f(x)$는 반드시 최댓값과 최솟값을 갖습니다. 이때 최댓값과 최솟값은 다음 후보 값들 중에서 결정됩니다.

후보군: 구간 내의 극댓값, 극솟값 및 양 끝의 함숫값 $f(a), f(b)$

$\implies$ 이 후보 값들 중 가장 큰 값이 최댓값, 가장 작은 값이 최솟값이 됩니다.

예제 3

닫힌구간에서의 최댓값과 최솟값 구하기

교과서 91쪽

닫힌구간 $[-1, 3]$에서 함수 $f(x) = 2x^3 - 3x^2 - 12x + 4$의 최댓값과 최솟값을 구하시오.

[풀이]

1) 도함수: $f'(x) = 6x^2 - 6x - 12 = 6(x+1)(x-2) = 0 \implies x = -1$ 또는 $x = 2$

2) 후보 값 계산 (구간 $[-1, 3]$ 내):

  • $f(-1) = 2(-1) - 3(1) - 12(-1) + 4 = 11$ (구간 끝점 겸 극댓값)
  • $f(2) = 16 - 12 - 24 + 4 = -16$ (극솟값)
  • $f(3) = 54 - 27 - 36 + 4 = -5$ (구간 끝점)

3) 크기 비교: $-16 < -5 < 11$ 이므로, 최댓값은 $11$ ($x = -1$), 최솟값은 $-16$ ($x = 2$)입니다.

실생활 최적화 문제의 해결

도형의 넓이나 부피, 생산 이익 등을 변수 $x$에 대한 함수로 나타내고, 그 정의구역에서 극대 또는 최댓값을 구하여 현실의 최적 조건을 결정합니다.

예제 4

상자의 부피를 최대로 하는 한 변의 길이

교과서 92쪽

한 변의 길이가 $12\text{ cm}$인 정사각형 모양의 철판의 네 귀퉁이에서 같은 크기의 정사각형을 잘라 내어 뚜껑이 없는 직육면체 모양의 상자를 만들려고 한다. 상자의 부피가 최대가 되도록 하는 잘라 낼 정사각형의 한 변의 길이를 구하시오.

[풀이]

잘라 낼 정사각형의 한 변의 길이를 $x\text{ cm}$라 하면 밑면의 가로·세로는 $12 - 2x$, 높이는 $x$입니다.

변수의 범위: $x > 0$, $12 - 2x > 0 \implies 0 < x < 6$

부피 함수: $V(x) = x(12 - 2x)^2 = 4x(6 - x)^2 = 4x^3 - 48x^2 + 144x$

도함수: $V'(x) = 12x^2 - 96x + 144 = 12(x-2)(x-6) = 0 \implies 0 < x < 6$에서 $x = 2$

$0 < x < 6$에서 $V(x)$는 $x = 2$에서 유일한 극대이자 최대가 되므로, 잘라 낼 한 변의 길이는 $2\text{ cm}$ (최대 부피 $128\text{ cm}^3$)입니다.

문제 4

포물선에 내접하는 직사각형 넓이의 최댓값

교과서 92쪽

포물선 $y = -x^2 + 6$과 $x$축으로 둘러싸인 도형에 내접하는 직사각형의 넓이의 최댓값을 구하시오.

문제 4 상세 해설

제1사분면 위의 직사각형 꼭짓점을 $(x, -x^2 + 6)$이라 하면 $0 < x < \sqrt{6}$입니다.

직사각형의 가로 길이는 $2x$, 세로 길이는 $-x^2 + 6$이므로 넓이 함수 $S(x)$는 다음과 같습니다.

$S(x) = 2x(-x^2 + 6) = -2x^3 + 12x$

$S'(x) = -6x^2 + 12 = -6(x^2 - 2) = 0 \implies 0 < x < \sqrt{6}$에서 $x = \sqrt{2}$

따라서 $x = \sqrt{2}$에서 유일한 극대이자 최댓값 $S(\sqrt{2}) = 2\sqrt{2}(6 - 2) = 8\sqrt{2}$를 갖습니다.

01

함수의 그래프를 그리는 증감표 빈칸 채우기

교과서 93쪽

함수 $f(x) = x^3 - 3x^2 + 1$의 도함수 $f'(x) = 3x(x - 2)$의 증감표 빈칸 [1]~[4]를 채우세요.

$x$ $\cdots$ $0$ $\cdots$ [1] $\cdots$
$f'(x)$ $+$ $0$ [2] $0$ $+$
$f(x)$ $\nearrow$ $1$ (극대) [3] [4] (극소) $\nearrow$
[1]:
[2] 부호:
[3] 상태:
[4] 극솟값:

01번 상세 해설

$f'(x) = 3x^2 - 6x = 3x(x - 2) = 0 \implies x = 0$ 또는 $x = 2$

1) [1]은 두 번째 근이므로 $2$입니다.

2) $0 < x < 2$에서 $f'(x) < 0$이므로 [2] 부호는 $-$, [3] 증감 상태는 감소($\searrow$)입니다.

3) [4]는 $x = 2$에서의 함숫값이므로 $f(2) = 8 - 12 + 1 = -3$ (극솟값)입니다.

닫힌구간에서 삼차·사차함수의 최댓값과 최솟값

교과서 93쪽
(1) $f(x) = 2x^3 + 3x^2 - 1$ $[-2, 1]$

$f'(x) = 6x(x+1) = 0 \implies x = -1, 0$

(2) $f(x) = 3x^4 + 8x^3 - 1$ $[-3, -1]$

$f'(x) = 12x^2(x+2) = 0 \implies x = -2$ (구간 내)

최댓값: 최솟값:

03번 상세 해설

(1) $f(x) = 2x^3 + 3x^2 - 1$ in $[-2, 1]$:

$f'(x) = 6x^2 + 6x = 6x(x+1) = 0 \implies x = -1, 0$ (둘 다 구간 내 포함)

후보 값: $f(-2) = -16 + 12 - 1 = -5$, $f(-1) = -2 + 3 - 1 = 0$, $f(0) = -1$, $f(1) = 2 + 3 - 1 = 4$

$\implies$ 최댓값 $4$ ($x = 1$), 최솟값 $-5$ ($x = -2$)

(2) $f(x) = 3x^4 + 8x^3 - 1$ in $[-3, -1]$:

$f'(x) = 12x^3 + 24x^2 = 12x^2(x+2) = 0 \implies x = -2$ (구간 내 포함, $x=0$은 제외)

후보 값: $f(-3) = 243 - 216 - 1 = 26$, $f(-2) = 48 - 64 - 1 = -17$, $f(-1) = 3 - 8 - 1 = -6$

$\implies$ 최댓값 $26$ ($x = -3$), 최솟값 $-17$ ($x = -2$)

04

포물선 위의 점과 정점 사이의 거리의 최솟값

교과서 94쪽

점 $A(3, 0)$과 포물선 $y = x^2$ 위의 임의의 점 $P(t, t^2)$ 사이의 거리 $\overline{AP}$의 최솟값을 선택하세요.

04번 상세 해설

점 $P(t, t^2)$와 점 $A(3, 0)$ 사이의 거리의 제곱을 $L(t)$라 하면:

$L(t) = (t - 3)^2 + (t^2 - 0)^2 = t^4 + t^2 - 6t + 9$

미분: $L'(t) = 4t^3 + 2t - 6 = 2(2t^3 + t - 3) = 2(t - 1)(2t^2 + 2t + 3) = 0$

$2t^2 + 2t + 3 > 0$ (판별식 $D < 0$)이므로 유일한 실근은 $t = 1$입니다.

따라서 $t = 1$에서 거리의 제곱은 최솟값 $L(1) = 1 + 1 - 6 + 9 = 5$를 가지므로, 최단 거리는 $\sqrt{5}$입니다.

05

제품 생산 이익 최대화 실생활 최적화

교과서 94쪽

어느 회사에서 제품 $x\text{ kg}$을 생산할 때의 이익 함수가 $f(x) = -x^3 + 600x^2 - 50000$ ($0 \le x \le 500$)이라고 한다. 이익을 최대로 하기 위한 제품의 생산량 $x$를 구하시오.

최적 생산량: kg

05번 상세 해설

이익 함수: $f(x) = -x^3 + 600x^2 - 50000$ ($0 \le x \le 500$)

미분: $f'(x) = -3x^2 + 1200x = -3x(x - 400) = 0 \implies x = 0$ 또는 $x = 400$

구간 $[0, 500]$에서 증감표를 조사하면 $x = 400$에서 유일한 극대이자 최대가 됩니다.

따라서 최대 이익을 달성하기 위한 생산량은 $400\text{ kg}$입니다.
