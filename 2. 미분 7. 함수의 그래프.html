함수의 그래프의 개형은 어떻게 그릴까?

도함수 $f'(x)=0$인 점, 증감표, 극값, 그리고 좌표축과의 교점을 체계적으로 결합하여 3차·4차 다항함수의 곡선 개형을 완벽히 작도합니다.

다항함수의 그래프 개형 그리는 3단계

교과서 89쪽
1 도함수 $f'(x) = 0$ 풀기

도함수 $f'(x)$를 구하고 인수분해하여 접선의 기울기가 0이 되는 기준점($x$값)들을 모두 구합니다.

2 증감표 작성 및 극값 계산

기준점 좌우에서 $f'(x)$의 부호($+, -$)를 조사하고 원함수에 대입하여 극댓값과 극솟값을 정확히 구합니다.

3 절편 파악 및 매끄러운 작도

$y$축과의 교점($x=0$일 때의 함숫값 $f(0)$)과 필요한 경우 $x$절편을 찍고 매끄러운 곡선으로 연결합니다.

함수의 최댓값과 최솟값 & 실생활 최적화

🏆

28차시 학습 목표

닫힌구간 $[a, b]$에서 연속인 함수의 최댓값과 최솟값을 구하는 3단계 핵심 알고리즘을 완벽히 체화하고, 상자 접기 부피 최적화 및 도형의 넓이 극대화 등 실생활 최적화 문제를 미분을 활용하여 직접 해결합니다.

닫힌구간 $[a, b]$에서의 최대·최소 판정 원리

1

극값 후보 구하기

열린구간 $(a, b)$에서 $f'(x) = 0$을 만족하는 $x$를 찾아 그 점에서의 함숫값(극댓값, 극솟값)을 모두 구합니다.

2

양 끝점 함숫값 구하기

구간의 양 끝점인 $x = a$와 $x = b$에서의 함숫값 $f(a)$와 $f(b)$를 각각 계산합니다.

3

최대·최소 비교 판정

위에서 구한 모든 극값들과 양 끝점 함숫값 중 가장 큰 값이 최댓값, 가장 작은 값이 최솟값이 됩니다!

💡
핵심 팁: 닫힌구간 $[a, b]$에서 연속함수의 최댓값과 최솟값은 반드시 극값 또는 양 끝값 중에서만 나옵니다! 따라서 복잡한 전체 개형을 다 그리지 않더라도, 후보값들의 크기만 비교하면 즉시 답을 얻을 수 있습니다.
예제 3

닫힌구간에서 삼차함수의 최댓값과 최솟값

교과서 91쪽

닫힌구간 $[-1, 1]$에서 함수 $f(x) = 2x^3 - 3x^2 + 2$의 최댓값과 최솟값을 구하시오.

[1단계: 도함수와 극값 후보 찾기]
$f'(x) = 6x^2 - 6x = 6x(x - 1)$
$f'(x) = 0$에서 $x = 0$ 또는 $x = 1$.
열린구간 $(-1, 1)$에 속하는 $x$는 $x = 0$ 하나입니다. (주의: $x = 1$은 끝점!)
[2단계: 후보값 계산 (극값 + 양 끝값)]
  • 왼쪽 끝점: $f(-1) = 2(-1)^3 - 3(-1)^2 + 2 = -2 - 3 + 2 = \mathbf{-3}$
  • 극댓값: $f(0) = 2(0)^3 - 3(0)^2 + 2 = \mathbf{2}$
  • 오른쪽 끝점(극솟값): $f(1) = 2(1)^3 - 3(1)^2 + 2 = 2 - 3 + 2 = \mathbf{1}$
[3단계: 크기 비교 및 결론]
구한 값 $\{-3, 2, 1\}$ 중에서 가장 큰 값은 $2$이고 가장 작은 값은 $-3$입니다.
따라서 닫힌구간 $[-1, 1]$에서 함수 $f(x)$의 최댓값은 2 ($x = 0$), 최솟값은 -3 ($x = -1$)입니다.

문제 3-⑴ 삼차함수의 최대·최소
교과서 91쪽

닫힌구간 $[0, 2]$에서 함수 $f(x) = -2x^3 + 9x^2 - 12x + 7$의 최댓값과 최솟값을 구하시오.

✏️ 미분 및 후보값 계산 연습장
💡 상세 해설:
1) $f'(x) = -6x^2 + 18x - 12 = -6(x^2 - 3x + 2) = -6(x - 1)(x - 2) = 0 \implies x = 1, 2$
2) 닫힌구간 $[0, 2]$ 안의 후보점: $x = 0, 1, 2$
3) 후보 함숫값 계산:
  • $f(0) = 7$ (왼쪽 끝점)
  • $f(1) = -2 + 9 - 12 + 7 = 2$ (극솟값)
  • $f(2) = -16 + 36 - 24 + 7 = 3$ (오른쪽 끝점이자 극댓값)
4) 따라서 최댓값 = 7 ($x = 0$), 최솟값 = 2 ($x = 1$)입니다.
문제 3-⑵ 사차함수의 최대·최소
교과서 91쪽

닫힌구간 $[-1, 2]$에서 함수 $f(x) = 3x^4 - 4x^3 + 1$의 최댓값과 최솟값을 구하시오.

✏️ 미분 및 후보값 계산 연습장
💡 상세 해설:
1) $f'(x) = 12x^3 - 12x^2 = 12x^2(x - 1) = 0 \implies x = 0$ (중근, 극값 아님), $x = 1$ (극소)
2) 닫힌구간 $[-1, 2]$ 안의 후보점: $x = -1, 0, 1, 2$
3) 후보 함숫값 계산:
  • $f(-1) = 3(-1)^4 - 4(-1)^3 + 1 = 3 + 4 + 1 = 8$ (왼쪽 끝점)
  • $f(0) = 1$
  • $f(1) = 3(1)^4 - 4(1)^3 + 1 = 0$ (극솟값)
  • $f(2) = 3(16) - 4(8) + 1 = 48 - 32 + 1 = 17$ (오른쪽 끝점)
4) 따라서 최댓값 = 17 ($x = 2$), 최솟값 = 0 ($x = 1$)입니다.

예제 4

실생활 최적화: 상자의 최대 부피 구하기

교과서 92쪽

오른쪽 그림과 같이 한 변의 길이가 $12\text{ cm}$인 정사각형 모양의 종이의 네 귀퉁이에서 같은 크기의 정사각형을 잘라 내고, 남은 부분을 접어서 뚜껑이 없는 직육면체 모양의 상자를 만들려고 한다. 상자의 부피가 최대가 되도록 하는 잘라 낼 정사각형의 한 변의 길이를 구하시오.

[1단계: 미지수 설정 및 정의역 범위]
잘라 낼 정사각형의 한 변의 길이를 $x\text{ cm}$라 하면,
$x > 0$이고 $12 - 2x > 0$이어야 하므로 $x$의 범위는 $0 < x < 6$입니다.
[2단계: 부피 함수식 $V(x)$ 세우기]
상자의 밑면은 한 변이 $(12 - 2x)\text{ cm}$인 정사각형이고 높이는 $x\text{ cm}$이므로
$V(x) = x(12 - 2x)^2 = x(4x^2 - 48x + 144) = 4x^3 - 48x^2 + 144x$
[3단계: 도함수 계산 및 증감표]
$V'(x) = 12x^2 - 96x + 144 = 12(x^2 - 8x + 12) = 12(x - 2)(x - 6)$
$0 < x < 6$에서 $V'(x) = 0$을 만족하는 $x$는 $x = 2$ 하나뿐입니다.
$0 < x < 2$에서 $V'(x) > 0$ (증가 $\nearrow$), $2 < x < 6$에서 $V'(x) < 0$ (감소 $\searrow$)이므로
$x = 2$에서 극대이자 유일한 최대가 됩니다.
[4단계: 답 작성]
따라서 상자의 부피가 최대가 되도록 하는 잘라 낼 한 변의 길이는 $2\text{ cm}$이며,
(이때 최대 부피는 $V(2) = 2 \times 8^2 = 128\text{ cm}^3$입니다.)

1.41
0 극대점: x = √2 ≈ 1.414 √6 ≈ 2.45
📐 직사각형 실시간 치수 최대 넓이 달성! 🎯
가로 길이 $(2x)$: 2.83
세로 길이 $(-x^2 + 6)$: 4.00
현재 넓이 $S(x)$: 11.31 (8√2)
수학적 원리: $S'(x) = -6x^2 + 12 = -6(x^2 - 2) = 0$에서 $x = \sqrt{2}$일 때 넓이가 최대가 되며, 그 최댓값은 $S(\sqrt{2}) = 2\sqrt{2}(4) = 8\sqrt{2} \approx 11.31$입니다.
문제 4 포물선 내접 직사각형의 넓이의 최댓값
교과서 92쪽

포물선 $y = -x^2 + 6$과 $x$축으로 둘러싸인 도형에 내접하고 한 변이 $x$축 위에 있는 직사각형의 넓이의 최댓값을 구하시오.

✏️ 미분 및 넓이 극대화 계산 연습장
구한 넓이의 최댓값을 선택하세요:
💡 상세 해설:
1) 제1사분면에 있는 직사각형의 꼭짓점 좌표를 $(x, -x^2 + 6)$이라 하면 $0 < x < \sqrt{6}$입니다.
2) 직사각형의 가로는 $2x$, 세로는 $-x^2 + 6$이므로 넓이는 $S(x) = 2x(-x^2 + 6) = -2x^3 + 12x$입니다.
3) $S'(x) = -6x^2 + 12 = -6(x^2 - 2) = 0$에서 $0 < x < \sqrt{6}$이므로 $x = \sqrt{2}$.
4) 증감표에 의해 $x = \sqrt{2}$에서 극대이자 최대이므로 최댓값은
$S(\sqrt{2}) = 2\sqrt{2}(-(\sqrt{2})^2 + 6) = 2\sqrt{2}(4) = \mathbf{8\sqrt{2}}$입니다.

원뿔에 내접하는 원기둥의 부피 최적화

교과서 92쪽

밑면의 반지름의 길이가 $6\text{ cm}$이고 높이가 $18\text{ cm}$인 원뿔에 내접하는 원기둥 중에서 부피가 최대인 원기둥의 밑면의 반지름과 높이, 그리고 최대 부피를 구하는 심화 탐구입니다.

📐 1. 단면의 닮음비로 관계식 세우기

원기둥의 밑면의 반지름을 $x\text{ cm}$ ($0 < x < 6$), 높이를 $h\text{ cm}$라 하자.
원뿔과 원기둥의 축을 지나는 수직 단면을 보면 닮은 직각삼각형에 의해:

$\frac{18 - h}{18} = \frac{x}{6} \implies 18 - h = 3x \implies \mathbf{h = 18 - 3x}$

높이 $h$가 반지름 $x$에 대한 1차식으로 깔끔하게 표현됩니다!

📈 2. 부피 함수 $V(x)$와 미분

원기둥의 부피 $V(x)$는 다음과 같습니다:

$V(x) = \pi x^2 h = \pi x^2(18 - 3x) = 3\pi(6x^2 - x^3)$
$V'(x) = 3\pi(12x - 3x^2) = 9\pi x(4 - x)$

$0 < x < 6$에서 $V'(x) = 0$인 점은 $x = 4$입니다.
따라서 $x = 4$에서 극대이자 최대가 되며:

  • 밑면의 반지름: 4 cm
  • 원기둥의 높이: $h = 18 - 12 =$ 6 cm
  • 최대 부피: $V(4) = \pi(4^2)(6) =$ 96π cm³

삼차·사차함수의 그래프 그리기 실전

교과서 93쪽

다음 함수의 그래프를 그리시오.

⑴ $f(x) = 4x^3 - 6x^2$
✏️ 증감표 및 개형 필기 연습장
• $f'(x) = 12x^2 - 12x = 12x(x - 1) = 0 \implies x = 0, 1$
• $x = 0$에서 극댓값 $f(0) = 0$, $x = 1$에서 극솟값 $f(1) = 4 - 6 = -2$
• $y$절편은 $(0, 0)$이며 원점에서 $x$축에 접하고 $x = \frac{3}{2}$에서 $x$축과 만납니다.
⑵ $f(x) = 2x^4 - 4x^2 - 2$
✏️ 증감표 및 개형 필기 연습장
• $f(-x) = f(x)$이므로 $y$축 대칭(우함수)인 $W$자형 대칭 그래프입니다.
• $f'(x) = 8x^3 - 8x = 8x(x^2 - 1) = 8x(x - 1)(x + 1) = 0 \implies x = -1, 0, 1$
• $x = 0$에서 극댓값 $f(0) = -2$, $x = \pm 1$에서 극솟값 $f(\pm 1) = 2 - 4 - 2 = -4$
• $y$절편 $(0, -2)$를 기준으로 좌우가 완벽히 대칭인 $W$형 곡선입니다.

닫힌구간에서 삼차함수의 최대·최소

교과서 93쪽

닫힌구간 $[-2, 1]$에서 함수 $f(x) = 2x^3 + 3x^2 + 1$의 최댓값과 최솟값을 구하시오.

✏️ 후보값 계산 연습장
💡 상세 풀이:
1) $f'(x) = 6x^2 + 6x = 6x(x + 1) = 0 \implies x = -1, 0$
2) 후보 함숫값:
  • $f(-2) = 2(-8) + 3(4) + 1 = -16 + 12 + 1 = \mathbf{-3}$ (최소)
  • $f(-1) = 2(-1) + 3(1) + 1 = 2$
  • $f(0) = 1$
  • $f(1) = 2 + 3 + 1 = \mathbf{6}$ (최대)
3) 따라서 최댓값 = 6 ($x = 1$), 최솟값 = -3 ($x = -2$)입니다.
스스로 확인 03-⑵

닫힌구간에서 사차함수의 최대·최소

교과서 93쪽

닫힌구간 $[-3, -1]$에서 함수 $f(x) = x^4 + 4x^3 + 4x^2 - 5$의 최댓값과 최솟값을 구하시오.

✏️ 후보값 계산 연습장
💡 상세 풀이:
1) $f'(x) = 4x^3 + 12x^2 + 8x = 4x(x^2 + 3x + 2) = 4x(x + 1)(x + 2) = 0 \implies x = -2, -1, 0$
2) 닫힌구간 $[-3, -1]$ 안의 후보점: $x = -3, -2, -1$ ($x = 0$은 구간 밖!)
3) 후보 함숫값:
  • $f(-3) = 81 - 108 + 36 - 5 = \mathbf{4}$ (최대)
  • $f(-2) = 16 - 32 + 16 - 5 = \mathbf{-5}$ (최소)
  • $f(-1) = 1 - 4 + 4 - 5 = -4$
4) 따라서 최댓값 = 4 ($x = -3$), 최솟값 = -5 ($x = -2$)입니다.
스스로 확인 04

포물선 위의 점과 정점 사이의 거리의 최솟값

교과서 93쪽

포물선 $y = x^2$ 위의 점 $P$와 점 $A(3, 0)$ 사이의 거리의 최솟값을 구하시오.

✏️ 거리 제곱 함수 L(t) 미분 연습장
거리의 최솟값을 선택하세요:
💡 상세 풀이:
1) 점 $P$의 좌표를 $(t, t^2)$이라 하면 점 $A(3, 0)$과의 거리의 제곱 $L(t)$는
$L(t) = (t - 3)^2 + (t^2 - 0)^2 = t^4 + t^2 - 6t + 9$
2) $L'(t) = 4t^3 + 2t - 6 = 2(2t^3 + t - 3) = 2(t - 1)(2t^2 + 2t + 3)$
3) $2t^2 + 2t + 3 = 2(t + \frac{1}{2})^2 + \frac{5}{2} > 0$이므로 실근은 $t = 1$ 하나뿐입니다.
4) $t < 1$에서 $L'(t) < 0$, $t > 1$에서 $L'(t) > 0$이므로 $t = 1$에서 유일한 극소이자 최솟값을 갖습니다.
5) $L(1) = 1 + 1 - 6 + 9 = 5$이므로 구하는 거리의 최솟값은 $\sqrt{5}$입니다.

✏️ 이익 함수 미분 연습장
kg
💡 상세 풀이:

$\implies$ 접선 기울기가 잠시 0이 되며 계속 증가하는 곡선!
