2. 닫힌구간 $[a, b]$에서의 최대·최소 구하기

닫힌구간 $[a, b]$에서 연속함수 $f(x)$의 최댓값과 최솟값은 다음 후보들 중 가장 큰 값과 가장 작은 값입니다:

① 구간 안의 모든 극댓값 ② 구간 안의 모든 극솟값 ③ 양 끝값 $f(a), f(b)$

3차함수 $f(x) = x^3 - 3ax$ 개형 조절기

a 파라미터 조작
a = -1.0 a = 1.0 a = 2.0
도함수: f'(x) = 3x² - 3
개형 상태: 극대/극소 2개 존재

대표 예제 풀이 & 연습장

예제 1 (최댓값과 최솟값)

닫힌구간 $[-1, 3]$에서 함수 $f(x) = 2x^3 - 3x^2 - 12x + 5$ 의 최댓값과 최솟값을 구하시오.

$f'(x) = 6x^2 - 6x - 12 = 6(x+1)(x-2) = 0 \implies x = -1, 2$ (모두 구간 $[-1, 3]$에 포함).

• $f(-1) = 2(-1) - 3(1) - 12(-1) + 5 = 12$ (극대이자 끝값)

• $f(2) = 16 - 12 - 24 + 5 = -15$ (극소)

• $f(3) = 54 - 27 - 36 + 5 = -4$ (끝값)

따라서 최댓값은 $12$, 최솟값은 $-15$ 입니다.

스스로 확인하기 (형성평가)

01. 함수 $f(x) = x^4 - 4x + 1$의 최솟값은?

$f'(x) = 4(x^3 - 1) = 0 \implies x=1$에서 극소이자 최소: $f(1) = -2$

02. 3차함수의 그래프가 $x$축과 서로 다른 세 점에서 만날 조건은 (극댓값) $\times$ (극솟값)의 부호가 어떠해야 하는가?

음수 (극댓값 > 0, 극솟값 < 0 이어야 함)
