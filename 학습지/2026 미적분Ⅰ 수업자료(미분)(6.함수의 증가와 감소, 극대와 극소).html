도함수 $f'(x)$의 부호로 함수의 증가·감소를 어떻게 판정할까?

핵심 개념 | 함수의 증가와 감소의 판정 (p.33)
함수 $f(x)$가 어떤 열린구간에서 미분가능할 때, 이 구간의 모든 $x$에 대하여
1. $f'(x) > 0$이면 $f(x)$는 이 구간에서 증가한다.
2. $f'(x) < 0$이면 $f(x)$는 이 구간에서 감소한다. (단, 역은 성립하지 않는다!)

탐침 $x =$   $\implies$ 도함수 $f'(x) =$

f'(x) > 0 : 접선 기울기가 양수(+)이므로 증가 구간이다!

f'(x) < 0 : 접선 기울기가 음수(-)이므로 감소 구간이다!

f'(x) = 0 : 증가와 감소가 바뀌는 경계점이다!

증명 핵심 (평균값 정리 활용):
구간 안의 $x_1 < x_2$에 대하여 $\frac{f(x_2)-f(x_1)}{x_2-x_1} = f'(c)$인 $c \in (x_1, x_2)$가 존재한다.

$f'(c) > 0$이고 $x_2 - x_1 > 0$이면 $f(x_2) - f(x_1) > 0 \implies f(x_1) < f(x_2)$ (증가)

주의 (역이 성립하지 않는 반례): $f(x) = x^3$은 실수 전체에서 증가하지만 $f'(0) = 0$이다.
따라서 다항함수 $f(x)$가 증가할 필요충분조건은 $f'(x) \ge 0$이다!

극대와 극소란 무엇이고 도함수의 부호는 어떻게 바뀔까?

핵심 개념 | 극대와 극소의 뜻과 판정 (p.34)
• $x=a$를 포함하는 열린구간에서 $f(x) \le f(a)$이면 극대(극댓값 $f(a)$), $f(x) \ge f(b)$이면 극소(극솟값 $f(b)$)라 한다.
• 미분가능한 함수 $f(x)$에서 $f'(a)=0$이고 $x=a$ 좌우에서
① $f'(x)$ 부호가 $(+) \to (-)$이면 극대, ② $(-) \to (+)$이면 극소이다.

탐침 $x =$   ($f(x) =$ ,   $f'(x) =$ )

x = -1 : f'(x)가 (+) → (-)로 바뀌므로 극댓값 2를 갖는다!

x = 1 : f'(x)가 (-) → (+)로 바뀌므로 극솟값 -2를 갖는다!

극값과 미분계수의 정리 (페르마 정리):
미분가능한 함수 $f(x)$가 $x=a$에서 극댓값을 가지면 충분히 작은 $h$에 대하여
$h<0$일 때 $\frac{f(a+h)-f(a)}{h} \ge 0$, $h>0$일 때 $\frac{f(a+h)-f(a)}{h} \le 0$이므로 $f'(a) = 0$이다.

주의: $f'(a) = 0$이라고 해서 반드시 극값을 갖는 것은 아니다!
반드시 $x=a$ 좌우에서 $f'(x)$의 부호가 바뀌는지 확인해야 한다.

기침할 때 빠져나가는 공기 속도가 극대가 되는 반지름은?

교과서 [스스로 확인하기] #6 (p.88)
목구멍의 최대 반지름의 길이가 $1\text{ cm}$인 사람이 기침을 할 때, 목구멍의 반지름의 길이가 $r\text{ cm}$인 순간 빠져나가는 공기의 속도 $v\text{ cm/s}$가 $$v(r) = -cr^3 + cr^2 \quad \left(\frac{1}{2} \le r \le 1\right)$$ 이라고 한다. 공기의 속도의 극댓값을 구하시오. (단, $c$는 양수)

반지름 $r =$ cm   $\implies$ 속도 비율 $v/c =$ (모형)

r = 2/3(≈0.67 cm)일 때 공기 속도가 극대(4/27 c ≈ 0.1481 c)가 된다!

1단계 ($r$에 대하여 미분):
$v'(r) = -3cr^2 + 2cr = -cr(3r - 2) = 0$

2단계 (구간 $\frac{1}{2} \le r \le 1$에서 부호 변화 확인):
$r = \frac{2}{3}$ 좌우에서 $v'(r)$의 부호가 $(+) \to (-)$로 바뀌므로 $r = \frac{2}{3}$에서 극대이다.

3단계 (극댓값 계산):
$v\left(\frac{2}{3}\right) = -c\left(\frac{8}{27}\right) + c\left(\frac{4}{9}\right) = \frac{4}{27}c$   $\therefore$ 정답: $\frac{4}{27}c\text{ (cm/s)}$
