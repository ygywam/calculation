넓이 함수 $S(x) = \int_a^x f(t)\,dt$를 미분하면 왜 $f(x)$가 될까?

핵심 개념 | 정적분과 미분의 관계 (p.48)
$S(x) = \int_a^x f(t)\,dt$일 때, 구간 $[x, x+\Delta x]$에서의 최솟값 $m$, 최댓값 $M$에 대하여 $m\Delta x \le \Delta S \le M\Delta x$가 성립한다.
$$\therefore \frac{d}{dx}\int_a^x f(t)\,dt = f(x)$$

증분 $\Delta x =$ ($x=1$에서 $f(1) = 1.50$, 모형)

$m =$ $\le \frac{\Delta S}{\Delta x} =$ $\le M =$

Δx → 0일 때 모두 f(x) = 1.50에 수렴한다!

1단계 ($\Delta x > 0$): 최대·최소 정리에 의해
$m\Delta x \le \Delta S \le M\Delta x \implies m \le \frac{\Delta S}{\Delta x} \le M$

2단계 ($\Delta x < 0$): 구간 $[x+\Delta x, x]$에서
$m(-\Delta x) \le -\Delta S \le M(-\Delta x) \implies m \le \frac{\Delta S}{\Delta x} \le M$

3단계 (극한): $\lim_{\Delta x \to 0} m = \lim_{\Delta x \to 0} M = f(x)$이므로
$S'(x) = \lim_{\Delta x \to 0}\frac{\Delta S}{\Delta x} = f(x)$   $\therefore \frac{d}{dx}\int_a^x f(t)\,dt = f(x)$

부정적분 $F(x)$로 정적분을 어떻게 계산할까?

핵심 개념 | 미적분학의 기본 정리 (p.49)
함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이고, $f(x)$의 한 부정적분을 $F(x)$라 하면
$$\int_a^b f(x)\,dx = \Big[ F(x) \Big]_a^b = F(b) - F(a)$$

유도 1단계: $S(x) = \int_a^x f(t)\,dt$라 하면 $S'(x) = f(x)$이므로
$S(x) = F(x) + C$ ($C$는 적분상수)

유도 2단계: $x = a$를 대입하면 $S(a) = 0$이므로
$F(a) + C = 0 \implies C = -F(a)$

유도 3단계: $\int_a^x f(t)\,dt = F(x) - F(a)$에 $x=b$ 대입:
$\int_a^b f(x)\,dx = F(b) - F(a)$

보너스 | 극한과 정적분의 결합:
$\lim_{x \to a} \frac{1}{x - a}\int_a^x f(t)\,dt = \lim_{x \to a}\frac{F(x) - F(a)}{x - a} = F'(a) = f(a)$

즉시 확인: $f(x) = 3x^2 - 2x + 5$일 때,
극한값 $\lim_{x \to 2} \frac{1}{x - 2}\int_2^x f(t)\,dt$의 값은?

적분 기호 안에 $x$와 $t$가 섞여 있을 때는 어떻게 분리할까?

핵심 유형 3 | 적분 변수 분리 후 치환 (p.50)
다음 등식을 만족시키는 함수 $f(x)$를 구하시오.
$$f(x) = 3x^2 + \int_0^2 (2x - 1)f(t)\,dt$$

1단계 (적분 변수 $t$에 대하여 $(2x-1)$은 상수 취급!):
$f(x) = 3x^2 + (2x - 1)\int_0^2 f(t)\,dt$

2단계 ($\int_0^2 f(t)\,dt = k$로 치환):
$f(x) = 3x^2 + 2kx - k$를 다시 대입하면
$k = \int_0^2 (3t^2 + 2kt - k)\,dt = \Big[ t^3 + kt^2 - kt \Big]_0^2$
$\implies k = 8 + 4k - 2k$

3단계 ($k$ 결정 및 정답):
$k = 8 + 2k \implies k = -8$
$\therefore$ 정답: $f(x) = 3x^2 - 16x + 8$

즉시 확인: $\int_0^2 (2x - 1)f(t)\,dt$에서 $(2x - 1)$을 적분 기호 밖으로 꺼낼 수 있는 이유는?

「재생」을 누르거나 슬라이더를 $t = 15$초로 옮겨 보자.

1단계 ($t = 15$ 대입 및 정적분 계산):
$\int_0^{15}\left(\frac{1}{10}x - 2\right)\,dx = \Big[ \frac{1}{20}x^2 - 2x \Big]_0^{15}$
$= \frac{225}{20} - 30 = \frac{45}{4} - 30 = -\frac{75}{4}$

2단계 ($h(15)$ 구하기):
$h(15) = 6 \times \left(-\frac{75}{4}\right) + 120 = -\frac{225}{2} + \frac{240}{2} = \frac{15}{2}$
정답: $\frac{15}{2}\text{ cm}$ ($7.5\text{ cm}$)
