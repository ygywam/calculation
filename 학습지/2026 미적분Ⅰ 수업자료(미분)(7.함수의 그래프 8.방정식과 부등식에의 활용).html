극댓값과 극솟값의 곱 $f(\alpha)f(\beta)$의 부호로 실근 개수를 판별하자

교과서 [활동] #1 (p.100 / 자료 p.41)
삼차함수 $f(x)$가 극댓값 $f(\alpha)$, 극솟값 $f(\beta)$를 가질 때:
① $f(\alpha)f(\beta) < 0 \implies$ 실근 $3$개, ② $f(\alpha)f(\beta) = 0 \implies$ 실근 $2$개, ③ $f(\alpha)f(\beta) > 0 \implies$ 실근 $1$개
방정식 $x^3 - 3x^2 - 9x + k = 0$의 실근의 개수를 조사해 보자.

상수 $k =$ (극댓값 $k+5 =$ , 극솟값 $k-27 =$ )

-5 < k < 27 : f(-1)f(3) < 0이므로 서로 다른 세 실근!

k = -5 또는 k = 27 : f(-1)f(3) = 0이므로 실근 2개!

k < -5 또는 k > 27 : f(-1)f(3) > 0이므로 실근 1개!

1단계 (극댓값과 극솟값 구하기):
$f'(x) = 3(x+1)(x-3) = 0 \implies$ 극댓값 $f(-1) = k + 5$, 극솟값 $f(3) = k - 27$

2단계 ($f(-1)f(3) = (k+5)(k-27)$의 부호 판별):
① $(k+5)(k-27) < 0 \iff$ $-5 < k < 27$일 때: $3$개
② $(k+5)(k-27) = 0 \iff$ $k = -5 \text{ 또는 } k = 27$일 때: $2$개
③ $(k+5)(k-27) > 0 \iff$ $k < -5 \text{ 또는 } k > 27$일 때: $1$개
