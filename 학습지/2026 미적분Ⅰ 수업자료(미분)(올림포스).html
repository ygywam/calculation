$x = 0$에서 극솟값 $0$, 극댓값이 $4$인 삼차함수에서 $f(1)$은?

올림포스 [유형확인] #18 (p.50 / 자료 p.46)
최고차항의 계수가 $1$인 삼차함수 $f(x)$가 $x = 0$에서 극솟값 $0$을 갖고 함수 $f(x)$의 극댓값이 $4$일 때, $f(1)$의 값은?

[비율 관계 팁] 극대(-2) : 변곡(-1) : 극소(0) : 교점(1)이 1:1:1 등간격이므로 f(1) = f(-2) = 4이다!

1단계 ($f(0)=0, f'(0)=0$으로 식 세우기):
$x=0$에서 $x$축에 접하므로 $f(x) = x^3 + ax^2$ ($a > 0$)이라 놓는다.

2단계 (극댓값 $4$를 이용해 $a$ 구하기):
$f'(x) = 3x^2 + 2ax = x(3x + 2a) = 0 \implies x = -\frac{2a}{3}$에서 극대
$f\left(-\frac{2a}{3}\right) = \frac{4a^3}{27} = 4 \implies a^3 = 27 \implies a = 3$

3단계 ($f(1)$ 계산):
$f(x) = x^3 + 3x^2 \implies f(1) = 1 + 3 = 4$   (정답: $4$)

올림포스 [유형확인] #24 (p.51 / 자료 p.46)
닫힌구간 $[0, 3a]$에서 함수 $f(x) = x^3 - 12a^2x + b$의 최댓값이 $12$, 최솟값이 $-4$일 때, 두 양수 $a, b$에 대하여 $a + b$의 값은?

1단계 (도함수와 극점 구하기):
$f'(x) = 3x^2 - 12a^2 = 3(x + 2a)(x - 2a) = 0$
$a > 0$이므로 구간 $[0, 3a]$ 안에서 $x = 2a$일 때 극소이자 최소이다.

• $f(0) = b$ (최댓값)
• $f(2a) = 8a^3 - 24a^3 + b = -16a^3 + b$ (최솟값)
• $f(3a) = 27a^3 - 36a^3 + b = -9a^3 + b$

3단계 ($a, b$ 계산 및 정답):
최댓값 $f(0) = b = 12$, 최솟값 $-16a^3 + 12 = -4 \implies a^3 = 1 \implies a = 1$
$\therefore a + b = 1 + 12 = 13$   (정답: $13$)

원뿔에 내접하는 원기둥의 부피가 최대가 될 때는?

올림포스 [유형확인] #27 (p.52 / 자료 p.46)
밑면의 반지름의 길이가 $4$, 높이가 $6$인 원뿔에 내접하는 원기둥이 있다. 이 원기둥의 부피의 최댓값은?

원기둥 반지름 $r =$ (높이 $h =$ )   $\implies V(r) =$ $\pi$

r = 8/3(밑면 반지름의 2/3)일 때 부피가 최대(128/9 π)가 된다!

1단계 (닮음비로 높이 $h$를 $r$로 나타내기):
원기둥 밑면 반지름을 $r$ ($0 < r < 4$), 높이를 $h$라 하면
$(6 - h) : r = 6 : 4 = 3 : 2 \implies h = 6 - \frac{3}{2}r$

2단계 (부피 함수 $V(r)$ 미분):

$V'(r) = -\frac{3}{2}\pi r(3r - 8) = 0 \implies r = \frac{8}{3}$에서 극대이자 최대

3단계 (최댓값 계산): $V\left(\frac{8}{3}\right) = \pi \times \frac{64}{9} \times 2 = \frac{128}{9}\pi$   (정답: $\frac{128}{9}\pi$)

$h'(x) = 3x^2 - 2x = x(3x - 2) = 0 \implies x = 0, \frac{2}{3}$
$h(-2) = -8 - 4 = -12, \; h\left(\frac{2}{3}\right) = -\frac{4}{27}$이므로 최솟값은 $-12$이다.

3단계 ($k$의 범위 및 $a$ 결정):
$k \le -12$이어야 하므로 $a = -12$   (정답: $-12$)

점 $(a, 0)$에서 곡선 $y = x^2 + 1$에 그은 두 접선의 접점의 $x$좌표를 각각 $x_1, x_2$ ($x_1 < x_2$)라 하자. $x_2 - x_1 = 2\sqrt{10}$일 때, 양수 $a$의 값을 구하시오.

1단계 (접점 $(t, t^2+1)$에서의 접선의 방정식):
$y' = 2x$이므로 접선의 방정식은 $y - (t^2 + 1) = 2t(x - t) \implies y = 2tx - t^2 + 1$

2단계 (점 $(a, 0)$ 대입 및 근과 계수의 관계):
$0 = 2at - t^2 + 1 \implies t^2 - 2at - 1 = 0$
이 방정식의 두 실근이 $x_1, x_2$이므로 $x_1 + x_2 = 2a, \quad x_1 x_2 = -1$

3단계 ($x_2 - x_1 = 2\sqrt{10}$ 이용):
$(x_2 - x_1)^2 = (x_1 + x_2)^2 - 4x_1 x_2 = 4a^2 + 4 = (2\sqrt{10})^2 = 40$
$4a^2 = 36 \implies a^2 = 9$ ($a > 0$)   $\therefore$ 정답: $a = 3$

도함수 $y = f'(x)$의 그래프에서 극값과 감소 구간을 판별하자

올림포스 [대단원종합문제] #12 (p.57 / 자료 p.48)
다항함수 $f(x)$에 대하여 도함수 $y = f'(x)$의 그래프가 그림과 같을 때, 보기에서 옳은 것만을 있는 대로 고른 것은?
ㄱ. 함수 $f(x)$는 $x = 0$에서 극소이다.
ㄴ. 함수 $f(x)$는 열린구간 $(1, 3)$에서 감소한다.
ㄷ. 함수 $f(x)$가 $x = n$에서 극값을 갖는 $3$ 이하의 자연수 $n$의 값의 합은 $6$이다.

x = 2에서는 f'(2) = 0이지만 좌우 부호가 (-) → (-)로 유지된다!

ㄱ (참): $x = 0$ 좌우에서 $f'(x)$의 부호가 $(-) \to (+)$로 바뀌므로 $x = 0$에서 극소이다.

ㄴ (참): 열린구간 $(1, 3)$에서 $x = 2$일 때만 $f'(2) = 0$이고 나머지 점에서 $f'(x) < 0$이므로 구간 $(1, 3)$에서 계속 감소한다.

ㄷ (거짓): $x = 2$에서는 부호가 바뀌지 않아 극값을 갖지 않는다!
극값을 갖는 $3$ 이하의 자연수는 $n = 1, 3$뿐이므로 합은 $1 + 3 = 4 \ne 6$
정답: ㄱ, ㄴ

원점을 출발하여 수직으로 멀어지는 두 점 사이의 거리 변화율은?

올림포스 [대단원종합문제] #15 (p.58 / 자료 p.48)
좌표평면 위의 원점 O를 동시에 출발하여 $y$축의 양의 방향으로 매초 $1$의 속력으로 움직이는 점 P와 $x$축의 양의 방향으로 매초 $2$의 속력으로 움직이는 점 Q가 있을 때, 선분 $PQ$의 길이의 변화율은?

시각 $t =$ 초 ($P(0, t), \; Q(2t, 0)$)   $\implies \overline{PQ} = \sqrt{5}t \approx$

선분 PQ의 길이가 매초 √5씩 일정하게 늘어나므로 변화율은 √5이다!

1단계 ($t$초 후 점 P, Q의 좌표):
$P(0, t), \quad Q(2t, 0)$ ($t > 0$)

2단계 (선분 $PQ$의 길이 $l$을 $t$에 대한 식으로 나타내기):
$l = \overline{PQ} = \sqrt{(2t)^2 + t^2} = \sqrt{5t^2} = \sqrt{5}t$

3단계 (시각 $t$에 대하여 미분):
$\frac{dl}{dt} = \sqrt{5}$   $\therefore$ 정답: $\sqrt{5}$

$y = |2x^3 + 3x^2 - 12x + k|$가 극값을 갖는 실수가 $5$개이려면?

올림포스 [대단원종합문제] #18 (p.58 / 자료 p.49)
함수 $f(x) = 2x^3 + 3x^2 - 12x + k$에 대하여 함수 $y = |f(x)|$가 $x = a$에서 극값을 갖도록 하는 실수 $a$의 개수가 $5$일 때, 이를 만족시키는 정수 $k$의 개수를 구하시오.

정수 $k =$ (극댓값 $f(-2) = k+20 =$ , 극솟값 $f(1) = k-7 =$ )

-20 < k < 7 : x축과 서로 다른 세 점에서 만나 접어 올리면 극값이 5개다!

교점이 1개 또는 2개뿐이어서 $|f(x)|$의 극값이 3개이다.

1단계 ($y = |f(x)|$가 극값 $5$개를 가질 조건):
원래 삼차함수의 극점 $2$개에 더해, $x$축을 뚫고 지나가며 꺾이는 점(극소점)이 $3$개 생겨야 하므로 방정식 $f(x) = 0$이 서로 다른 세 실근을 가져야 한다!

2단계 (극댓값 $\times$ 극솟값 $< 0$):
$f'(x) = 6(x+2)(x-1) = 0 \implies$ 극댓값 $f(-2) = k + 20$, 극솟값 $f(1) = k - 7$
$(k + 20)(k - 7) < 0 \implies -20 < k < 7$

3단계 (정수 $k$의 개수):
$7 - (-20) - 1 = 26$   $\therefore$ 정답: $26$개

점 $(1, 0)$에서 곡선 $y = x^3 + 3x^2$에 그은 세 접선의 기울기의 합은?

올림포스 [대단원종합문제] #23 (p.59 / 자료 p.49)
점 $(1, 0)$에서 곡선 $y = x^3 + 3x^2$에 그은 세 접선의 기울기를 각각 $m_1, m_2, m_3$ ($m_1 < m_2 < m_3$)이라 할 때, $m_1 + m_2 + m_3$의 값을 구하시오.

1단계 (접점 $(t, t^3+3t^2)$에서의 접선의 방정식 세우기):
$y' = 3x^2 + 6x$이므로 접선의 방정식은
$y - (t^3 + 3t^2) = (3t^2 + 6t)(x - t)$

2단계 (점 $(1, 0)$을 대입하여 접점의 $x$좌표 $t$ 구하기):
$-t^3 - 3t^2 = (3t^2 + 6t)(1 - t) = -3t^3 - 3t^2 + 6t$
$\implies 2t^3 - 6t = 2t(t^2 - 3) = 0 \implies t = 0 \text{ 또는 } t = \pm\sqrt{3}$

3단계 (세 접선의 기울기 $f'(t) = 3t^2 + 6t$의 합):
• $t = 0 \implies m = 0$
• $t = -\sqrt{3} \implies m_1 = 9 - 6\sqrt{3}$,  $t = \sqrt{3} \implies m_3 = 9 + 6\sqrt{3}$
$\therefore m_1 + m_2 + m_3 = (9 - 6\sqrt{3}) + 0 + (9 + 6\sqrt{3}) = 18$   (정답: $18$)

즉시 확인: 세 접점의 $x$좌표 $t_1, t_2, t_3$이 $2t^3 - 6t = 0$의 세 근일 때, 근과 계수의 관계($t_1+t_2+t_3=0, \sum t_i^2 = 6$)를 이용하면 $\sum (3t_i^2 + 6t_i)$는 얼마인가?
