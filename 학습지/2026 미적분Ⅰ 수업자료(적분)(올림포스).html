적분 후 미분 관계에서 다항함수 $f(x)$의 최솟값은?

올림포스 [유형확인] #3 (p.66 / 자료 p.63)
다항함수 $f(x)$가 모든 실수 $x$에 대하여
$$(x-1)f(x) = \frac{d}{dx}\left\{\int (x^3+x^2+x-3)\,dx\right\}$$ 를 만족시킬 때, 함수 $f(x)$의 최솟값은?

1단계 (부정적분 후 미분):
우변은 적분한 뒤 다시 $x$에 대하여 미분하므로 피적분함수 그대로 나온다.
$(x-1)f(x) = x^3 + x^2 + x - 3$

2단계 (조립제법으로 우변 인수분해):
$x^3 + x^2 + x - 3 = (x-1)(x^2 + 2x + 3)$
다항함수 $f(x)$는 실수 전체에서 연속이므로 $f(x) = x^2 + 2x + 3$

3단계 (완전제곱식 변형 및 최솟값):
$f(x) = (x+1)^2 + 2 \ge 2$ ($x = -1$일 때 최소)
정답: $2$

정적분에서 적분 변수 $t$를 $x$로 바꾸고 두 적분 구간을 이으면

곡선 밖의 점 $(1, 4)$에서 그은 두 접선과 곡선 사이의 넓이는?

올림포스 [대단원종합문제] #28 (p.88 / 자료 p.69)
그림과 같이 점 $(1, 4)$에서 곡선 $y = -x^2 + x + 3$에 그은 두 접선을 $l, m$이라 할 때, 곡선 $y = -x^2 + x + 3$과 두 접선 $l, m$으로 둘러싸인 부분의 넓이를 $S$라 하자. $12S$의 값을 구하시오.

[보너스 공식] 포물선과 두 접선 사이 넓이 S = |a|/12 · (β - α)³ = (1/12)·2³ = 2/3

1단계 (접점 $(t, -t^2+t+3)$에서의 접선이 $(1, 4)$를 지남):
$y' = -2x + 1$이므로 접선 $y - (-t^2+t+3) = (-2t+1)(x - t)$에 $(1, 4)$ 대입:
$4 = (-2t+1)(1 - t) - t^2 + t + 3 \implies t^2 - 2t = t(t - 2) = 0 \implies t = 0, 2$

2단계 (두 접선 $l, m$을 경계 $x = 1$로 나누어 정적분):
• $t = 0$일 때 접선 $l$: $y = x + 3$   ($\implies (x+3) - (-x^2+x+3) = x^2$)
• $t = 2$일 때 접선 $m$: $y = -3x + 7$   ($\implies (-3x+7) - (-x^2+x+3) = (x-2)^2$)

3단계 ($S$ 및 $12S$ 계산):
$S = \int_0^1 x^2\,dx + \int_1^2 (x-2)^2\,dx = \frac{1}{3} + \frac{1}{3} = \frac{2}{3} \implies$ 정답: $12S = 8$
