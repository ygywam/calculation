Ⅱ. 미분 대단원 핵심 개념 총정리

🧠

35차시 단원 전체 구조화 마인드맵

미분계수와 도함수의 정의부터 접선의 방정식, 평균값 정리, 함수의 증가·감소와 극대·극소, 삼차·사차함수의 그래프, 방정식과 부등식의 활용, 속도와 가속도까지 Ⅱ. 미분 대단원의 모든 핵심 원리를 한눈에 입체적으로 정리합니다.

1 미분계수와 순간변화율 1차시
• 평균변화율: $\frac{\Delta y}{\Delta x} = \frac{f(b) - f(a)}{b - a}$
• 미분계수: $f'(a) = \lim_{\Delta x \to 0} \frac{f(a + \Delta x) - f(a)}{\Delta x} = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$
• 기하적 의미: 곡선 $y = f(x)$ 위의 점 $(a, f(a))$에서의 접선의 기울기
2 미분가능성과 연속성 2차시
• 미분가능 $\implies$ 연속 (참)
• 연속 $\implies$ 미분가능 (거짓! 예: 뾰족점 $f(x) = |x|$)
• $x = a$에서 미분가능하려면 좌미분계수와 우미분계수가 모두 존재하고 서로 같아야 함!
3 도함수와 기본 미분법 3차시
• 도함수: $f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}$
• 거듭제곱: $(x^n)' = n x^{n-1}$, $(c)' = 0$
• 곱의 미분법: $\{f(x)g(x)\}' = f'(x)g(x) + f(x)g'(x)$
4 접선의 방정식 3유형 4차시
• 기본 공식: $y - f(t) = f'(t)(x - t)$
• 유형 1: 접점 $(t, f(t))$ 주어짐 $\implies$ 기울기 $f'(t)$ 계산
• 유형 2: 기울기 $m$ 주어짐 $\implies f'(t) = m$으로 접점 $t$ 역추적
• 유형 3: 외부의 점 $(x_1, y_1)$ $\implies$ 접선식에 대입하여 $t$ 풀기
5 롤의 정리 & 평균값 정리 5차시
• 롤의 정리: $f(a) = f(b) \implies f'(c) = 0$ ($a < c < b$)
• 평균값 정리: $\frac{f(b) - f(a)}{b - a} = f'(c)$ ($a < c < b$)
• 기하적 직관: 할선의 기울기와 평행한 접선이 적어도 하나 존재!
6 증가·감소와 극대·극소 6차시
• 증가: $f'(x) > 0$ ($\nearrow$), 감소: $f'(x) < 0$ ($\searrow$)
• 극대: $f'(x)$ 부호가 $+$에서 $-$로 전환 (봉우리)
• 극소: $f'(x)$ 부호가 $-$에서 $+$로 전환 (골짜기)
7 그래프 개형 & 최대·최소 7차시
• 개형 3단계: $f'(x) = 0$ $\to$ 증감표 및 극값 $\to$ $y$절편 연결
• 삼차함수: $N$자형 ($D > 0$), 변곡 멈춤 ($D = 0$), 단조증가 ($D < 0$)
• 닫힌구간 $[a, b]$ 최대·최소 후보: 극값과 양 끝값 $f(a), f(b)$
8 방정식·부등식 & 속도·가속도 8~9차시
• 실근 개수: $y = f(x)$와 $y = a$의 교점 개수
• 부등식 $f(x) \ge 0$ 증명: 최솟값 $\ge 0$ 보이기
• 속도: $v = \frac{dx}{dt} = f'(t)$, 가속도: $a = \frac{dv}{dt}$
• 방향 전환: $v = 0$이고 부호 전환!
⚡ 35차시 개념 자가진단 퀵 퀴즈
1. 함수 $f(x)$가 $x=a$에서 연속이면 $x=a$에서 반드시 미분가능하다. (O/X)
2. 닫힌구간 $[a, b]$에서 연속함수의 최댓값과 최솟값은 반드시 극값 또는 양 끝값에서만 나온다. (O/X)
3. 수직선 위를 움직이는 물체가 운동 방향을 바꿀 때의 순간속도 $v$는 항상 0이다. (O/X)

36차시 실전 평가 및 오답 클리닉

기본 연산부터 고난도 킬러 문항까지 16문항을 개별 연습장과 함께 직접 풀어보고, 즉각적인 실시간 채점 및 정밀 정석 해설을 통해 취약점을 완벽하게 보완합니다.

01번 교과서 107쪽 / 기본

함수 $f(x) = x^2 - x + 2$에 대하여 $x$의 값이 $1$에서 $1 + a$까지 변할 때의 평균변화율이 $5$이다. 상수 $a$의 값을 구하시오.

✏️ 풀이 연습장
[해설] $\frac{f(1+a) - f(1)}{a} = \frac{(1+a)^2 - (1+a) + 2 - 2}{a} = \frac{a^2 + a}{a} = a + 1 = 5 \implies \mathbf{a = 4}$
02번 교과서 107쪽 / 기본

미분가능한 함수 $f(x)$에 대하여 $\lim_{h \to 0} \frac{f(a) - f(a - 3h)}{h}$를 $f'(a)$를 이용하여 나타낸 것은?

✏️ 미분계수의 정의 식 변형 풀이 연습장
[해설] $\lim_{h \to 0} \frac{-(f(a-3h) - f(a))}{h} = \lim_{h \to 0} \frac{f(a-3h) - f(a)}{-3h} \times 3 = \mathbf{3f'(a)}$ (정답: ⑤)
03번 교과서 107쪽 / 기본

함수 $f(x) = (1 + x - x^2)(1 - x + x^2)$에 대하여 $f'(2)$의 값을 구하시오.

✏️ 치환 전개 또는 곱의 미분법 연습장
[해설] $f(x) = 1 - (x - x^2)^2 = -x^4 + 2x^3 - x^2 + 1 \implies f'(x) = -4x^3 + 6x^2 - 2x$. $f'(2) = -32 + 24 - 4 = \mathbf{-12}$
04번 교과서 107쪽 / 표준

점 $(0, -2)$를 지나는 곡선 $y = ax^3 + bx + c$ 위의 점 $(1, 2)$에서의 접선의 기울기가 $6$일 때, $a - b - c$의 값은?

✏️ 함수의 극한과 도함수 미정계수 풀이 연습장
[해설] $(0, -2)$ 지나므로 $c = -2$. $(1, 2)$ 지나므로 $a + b - 2 = 2 \implies a + b = 4$. 접선 기울기 $3a + b = 6 \implies a = 1, b = 3$. $a - b - c = 1 - 3 - (-2) = \mathbf{0}$ (정답: ③)
05번 교과서 107쪽 / 표준

함수 $y = f(x)$의 그래프가 아래와 같을 때 $\frac{f(b) - f(a)}{b - a} = f'(c)$를 만족시키는 상수 $c$의 개수를 구하시오. (단, $a < c < b$)

✏️ 구간 [0, 4] 평균값 정리 기하학적 접선 풀이 연습장
개
[해설] 두 점 $(a, f(a))$와 $(b, f(b))$를 잇는 직선의 기울기와 같은 평행한 접선은 곡선의 진동 구간 사이에서 총 3개 존재합니다.
06번 교과서 107쪽 / 표준

닫힌구간 $[0, 4]$에서 함수 $f(x) = x^4 - 4x^3 - 2x^2 + 12x + a$의 최댓값과 최솟값의 합이 $11$일 때, 상수 $a$의 값은?

✏️ 사차함수 극값 및 닫힌구간 최대·최소 풀이 연습장
[해설] $f'(x) = 4(x-3)(x-1)(x+1) = 0 \implies x \in [0, 4]$ 후보 $\{0, 1, 3, 4\}$. 최댓값 $f(4) = 16 + a$, 최솟값 $f(3) = -9 + a$. 합: $7 + 2a = 11 \implies \mathbf{a = 2}$ (정답: ②)
07번 교과서 108쪽 / 표준

곡선 $y = 2x^3 + 1$ ($x > 0$) 위를 움직이는 점 P와 직선 $y = 6x - 12$ 사이의 거리가 최소가 되도록 하는 점 P의 좌표를 $(a, b)$라고 할 때, $a + b$의 값은?

✏️ 곡선 위의 점 접선의 방정식 풀이 연습장
[해설] 접선 기울기 $y' = 6x^2 = 6 \implies x = 1$ ($x > 0$). $P(1, 3) \implies a=1, b=3$. $a + b = \mathbf{4}$ (정답: ④)
08번 교과서 108쪽 / 발전

삼차함수 $f(x)$가 다음을 모두 만족시킬 때, 함수 $f(x)$의 극댓값을 구하시오.
㈎ $\lim_{x \to 0} \frac{f(x)}{x} = -15$
㈏ 함수 $f(x)$가 $x = 1$에서 극솟값 $-8$을 갖는다.

✏️ 삼차함수 계수 결정 및 극댓값 계산 연습장
[해설] $f(0)=0, f'(0)=-15 \implies f(x) = ax^3 + bx^2 - 15x$. $f'(1) = 3a + 2b - 15 = 0, f(1) = a + b - 15 = -8 \implies a = 1, b = 6$. $f'(x) = 3(x+5)(x-1) = 0 \implies x = -5$에서 극댓값 $f(-5) = \mathbf{100}$
09번 교과서 108쪽 / 발전

곡선 $y = 9 - x^2$과 $x$축으로 둘러싸인 부분에 내접하는 사다리꼴의 넓이의 최댓값을 구하시오.

✏️ 사다리꼴 넓이의 최댓값 삼차함수 활용 풀이 연습장
[해설] 밑변 $6$, 윗변 $2x$, 높이 $9 - x^2 \implies S(x) = (x + 3)(9 - x^2)$. $S'(x) = -3(x + 3)(x - 1) = 0 \implies x = 1$일 때 최댓값 $S(1) = 4 \times 8 = \mathbf{32}$
10번 교과서 108쪽 / 발전

삼차함수 $y = f(x)$의 도함수 $y = f'(x)$의 그래프가 아래와 같다. $f(-1) = 2, f(2) = -4$일 때, 방정식 $2f(x) - k = 0$이 서로 다른 두 실근을 갖도록 하는 실수 $k$의 값의 합을 구하시오.

✏️ 도함수 부호와 삼차방정식 실근 개수 풀이 연습장
[해설] $f(x) = \frac{k}{2}$가 두 실근을 가지려면 극값이어야 함: $\frac{k}{2} = 2 \implies k = 4$, $\frac{k}{2} = -4 \implies k = -8$. 합: $4 + (-8) = \mathbf{-4}$
11번 교과서 108쪽 / 발전

모든 실수 $x$에 대하여 부등식 $x^4 - 4k^3x + 3 \ge 0$이 성립하도록 하는 정수 $k$의 개수를 구하시오.

✏️ 사차부등식이 항상 성립할 조건 풀이 연습장
개
[해설] $f'(x) = 4(x^3 - k^3) = 0 \implies x = k$에서 최솟값 $f(k) = -3k^4 + 3 \ge 0 \implies k^4 \le 1 \implies k \in \{-1, 0, 1\}$ (총 3개)
12번 교과서 108쪽 / 발전

원점을 출발하여 수직선 위를 움직이는 점 P의 시각 $t$에서의 위치 $x$가 $x = 2t^3 - 7t^2 + 8t$일 때, 옳은 것만을 보기에서 있는 대로 고르시오.

ㄱ. 점 P가 원점을 출발할 때의 속도는 $8$이다.
ㄴ. 점 P는 움직이는 동안 운동 방향을 두 번 바꾼다.
ㄷ. 점 P의 $t = \frac{4}{3}$에서의 가속도는 $-2$이다.
✏️ 속도 $v(t)$와 가속도 $a(t)$ 판정 풀이 연습장
[해설] $v(t) = 6t^2 - 14t + 8, a(t) = 12t - 14$. ㄱ: $v(0) = 8$ (참), ㄴ: $v = 2(3t-4)(t-1) = 0 \implies t=1, 4/3$에서 2번 바꿈 (참), ㄷ: $a(4/3) = 16 - 14 = 2 \neq -2$ (거짓). 정답: ㄱ, ㄴ
13번 교과서 109쪽 / 심화

모든 실수 $x$에 대하여 함수 $f(x) = \begin{cases} x^3 + 1 & (x < 1) \\ ax^2 - bx + 1 & (x \ge 1) \end{cases}$ 이 미분가능할 때, $a + b$의 값을 구하시오. (단, $a, b$는 상수이다.)

✏️ 두 곡선이 접할 조건과 공통접선 풀이 연습장
[해설] 연속: $a - b + 1 = 2 \implies a - b = 1$. 미분가능: $2a - b = 3 \implies a = 2, b = 1$. $a + b = \mathbf{3}$
14번 교과서 109쪽 / 심화

함수 $f(x) = x^3 - x^2 - ax + 2$가 닫힌구간 $[1, 2]$에서 감소하도록 하는 실수 $a$의 값의 범위를 구하시오.

✏️ 삼차함수의 감소 구간과 일차부등식 풀이 연습장
[해설] $f'(x) = 3x^2 - 2x - a \le 0 \implies a \ge 3x^2 - 2x$. 구간 $[1, 2]$에서 $3x^2 - 2x$의 최댓값은 $x=2$일 때 $12 - 4 = 8$이므로 $a \ge 8$
15번 교과서 109쪽 / 심화

다항함수 $f(x)$가 다음을 모두 만족시킬 때, $f(2)$의 값을 구하시오.
㈎ 모든 실수 $x$에 대하여 $\{f'(x)\}^2 = 4f(x) + 9$
㈏ $f'(1) = 1$

✏️ 관계식을 만족하는 다항함수 결정 풀이 연습장
[해설] 차수 비교: $f(x)$는 최고차항 계수 1인 이차함수. $f'(x) = 2x - 1 \implies f(x) = x^2 - x - 2$. $f(2) = 4 - 2 - 2 = \mathbf{0}$
16번 교과서 109쪽 / 최고난도

$x > 1$일 때, $2$ 이상의 자연수 $n$에 대하여 부등식 $x^n + n(n - 3) > nx + 1$이 성립하도록 하는 자연수 $n$의 최솟값을 구하시오.

✏️ 자연수 n과 부등식 성립 조건 풀이 연습장
[해설] $g(x) = x^n - nx + n^2 - 3n - 1$이라 하면 $x > 1$에서 $g'(x) = n(x^{n-1} - 1) > 0$이므로 증가함수. $x \to 1$일 때 $g(1) = 1 - n + n^2 - 3n - 1 = n^2 - 4n \ge 0 \implies n \ge 4$. 따라서 자연수 $n$의 최솟값은 4입니다.

수학의 눈으로 세상 보기

미분은 왜 첨단 과학과 현대 사회의 핵심 언어인가?

수학의 눈으로 바라보면 세상의 모든 현상은 끊임없이 변화하고 있습니다. 미분은 "어느 한순간의 변화율(순간변화율)"을 정확하게 측정하고 예측하는 강력한 도구입니다. 인공지능의 딥러닝 최적화부터 고속도로 과속 단속의 법적 근거까지, 실생활 속 미분의 비밀을 탐구해 봅시다.

탐구 사례 1 (110쪽) 인공지능 & 데이터과학

🤖 똑똑한 인공지능을 만들기 위한 최적화 (경사하강법)

인공지능이 사물을 인식하거나 언어를 번역할 때, 모델의 예측값과 실젯값 사이의 오차(손실, Loss)를 최소화해야 합니다. 손실 함수 $L(w)$의 함숫값이 최소가 되는 최적의 파라미터(가중치 $w$)를 찾기 위해 미분(접선의 기울기)을 사용합니다.

📉 경사하강법 시뮬레이터: $L(w) = (w - 3)^2 + 1$ Step: 0 | w = 0.50
학습률 $\alpha$:
💡 미분계수가 작동하는 원리: $w \leftarrow w - \alpha \cdot \frac{dL}{dw}$
• 접선의 기울기 $\frac{dL}{dw} > 0$ (오르막): $w$를 감소시켜 왼쪽(최솟값 방향)으로 이동
• 접선의 기울기 $\frac{dL}{dw} < 0$ (내리막): $w$를 증가시켜 오른쪽(최솟값 방향)으로 이동
• 극소점(최적점 $w=3$)에 도달하면 접선의 기울기 $L'(3) = 0$이 되어 학습이 수렴 완료!
자율 작성 후 확인
[모범 답변 예시] 인공지능 신경망의 가중치(파라미터)는 수억~수천억 개에 달합니다. 무작위로 값을 바꿔가며 오차를 줄이는 것은 불가능하지만, 미분을 통해 각 파라미터가 오차에 미치는 순간변화율(기울기)을 계산하면 오차가 가장 빠르게 감소하는 수학적 방향(경사의 반대 방향)을 즉시 찾아내어 효율적으로 학습시킬 수 있습니다.
탐구 사례 2 (110~111쪽) 교통 안전 & 실생활 수학

🚗 과속 차량을 단속하는 카메라의 원리: 순간속도 vs 평균값 정리

고속도로에서 마주치는 과속 카메라는 두 종류가 있습니다. 카메라 앞을 지날 때만 찍는 고정식(지점) 단속과 수 km 구간 전체를 측정하는 구간 단속입니다. 두 단속 방식의 이면에는 각각 미분계수(극한)와 평균값 정리라는 명쾌한 수학이 숨어 있습니다.

구분 고정식 지점 단속 (110쪽) 구간 단속 (111쪽 심화)
원리 도로 바닥 2개 감지선 사이 통과 시간 측정 수 km(예: 10km) 시작점과 종점 통과 시간 측정
수학 공식 $v \approx \frac{\Delta L}{\Delta t} \xrightarrow{\Delta t \to 0} \lim_{\Delta t \to 0} \frac{\Delta L}{\Delta t}$ $V_{avg} = \frac{L_{total}}{\Delta T}$
적용 이론 순간변화율 (미분계수) 평균값 정리 (MVT)
⚖️ 법적 효력을 갖는 '평균값 정리'의 완벽한 수학적 논증

자동차의 위치 함수 $s(t)$는 연속이고 미분가능합니다. 구간 단속 거리 $10\text{km}$를 $5\text{분}$($\frac{1}{12}\text{시간}$) 만에 주파했다면, 평균속도는 $\mathbf{120\text{km/h}}$입니다.

평균값 정리에 의해: $$\frac{s(T) - s(0)}{T - 0} = s'(c) = 120\text{km/h}$$ 를 만족하는 순간 $c$가 구간 내에 반드시 적어도 한 번 이상 존재합니다!

→ "단속 카메라 앞에서만 브레이크를 밟았다"고 항변해도, 수학적으로 운전자가 $120\text{km/h}$로 과속했던 순간이 100% 증명되므로 과태료가 합법적으로 부과됩니다.
자율 작성 후 확인
[모범 답변 예시] 지점 단속은 카메라 감지선 통과 순간($\Delta t \to 0$)만 회피하면 되지만, 구간 단속은 전체 이동 시간과 거리로 계산되는 평균속도를 기준으로 합니다. 평균값 정리에 의해 구간 평균속도가 제한속도를 넘으면 그 사이 반드시 순간 과속을 한 시점이 입증되므로, 카메라 앞 일시 감속(캥거루 운전)이 불가능해져 도로 전체의 정속 주행을 유도합니다.
