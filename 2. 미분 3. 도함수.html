성취기준

함수 $y=x^n$의 도함수를 구할 수 있고, 함수의 실수배, 합, 차, 곱의 미분법을 안다

💡 생각 열기 : 매번 극한 계산을 하지 않고 접선의 기울기를 알 수 있을까?

$x=1, 2, 3$에서의 미분계수를 구할 때마다 극한 식을 세우지 않고, 임의의 $x$에 대하여 미분계수를 대응시키는 새로운 함수를 만들면 한 번에 계산할 수 있습니다!

이 새로운 함수가 바로 도함수 $f'(x)$입니다!

1. 도함수의 정의 & 거듭제곱 미분법

📌 도함수 정의

정의역의 각 $x$에 미분계수 $f'(x)$를 대응시키는 함수:

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

⚡ 거듭제곱과 상수의 미분법

1. $y = c$ (상수함수) $\implies y' = 0$
2. $y = x^n$ ($n$은 양의 정수) $\implies y' = n x^{n-1}$

2. 함수의 곱의 미분법 공식

📌 두 함수의 곱의 미분법

$$\{f(x)g(x)\}' = f'(x)g(x) + f(x)g'(x)$$

"앞 미분 뒤 그대로 + 앞 그대로 뒤 미분"

📌 세 함수의 곱의 미분법

$$\{f(x)g(x)h(x)\}' = f'gh + fg'h + fgh'$$

원래 함수 $f(x)$와 도함수 $f'(x)$의 실시간 비교

f(x) = x² - 2x
x = -0.5 x = 1.0 x = 2.5
함숫값 $f(x)$: -1.00
도함숫값 $f'(x) = 2x - 2$: 0.00 (수평 접선)

대표 예제 풀이 & 연습장

예제 1 (곱의 미분법)

함수 $f(x) = (2x + 1)(x^2 - 3x + 2)$ 에 대하여 $f'(1)$의 값을 구하시오.

곱의 미분법을 적용합니다:

$$f'(x) = (2x+1)'(x^2 - 3x + 2) + (2x+1)(x^2 - 3x + 2)'$$

$$= 2(x^2 - 3x + 2) + (2x + 1)(2x - 3)$$

$x=1$을 대입하면:

$$f'(1) = 2(1 - 3 + 2) + (2 + 1)(2 - 3) = 2(0) + 3(-1) = -3$$

문제 풀이 연습장

스스로 확인하기 (형성평가)

01. $f(x) = 4x^3 - 5x^2 + 7$ 의 도함수 $f'(x)$는?

$12x^2 - 10x$

02. $f(x) = (x^2 + 1)^2$ 의 $x=1$에서의 미분계수는?

$f(x) = x^4 + 2x^2 + 1 \implies f'(x) = 4x^3 + 4x \implies f'(1) = 8$
