01. 도함수의 뜻 (The Derivative Function)

특정 한 지점에서의 순간변화율(미분계수)을 매번 극한으로 구하는 번거로움에서 벗어나, 정의역의 임의의 점 \(x\)에 그 점에서의 접선 기울기 \(f'(x)\)를 대응시키는 '새로운 함수(도함수)'의 개념을 정립합니다.

🎯 핵심 성취기준: 도함수의 뜻을 알고, 정의를 이용하여 간단한 함수의 도함수를 구할 수 있다.

• '값'에서 '함수'로의 질적 도약: 미분계수 \(f'(a)\)는 특정 상수 \(a\)에서의 '하나의 값(수치)'이지만, 도함수 \(f'(x)\)는 변수 \(x\)에 따라 기울기 값이 변하는 '함수(Function)'입니다. 이 개념적 차이를 명확히 인식시키는 것이 단원 학습의 성패를 가릅니다.

• 라이프니츠 기호 \(\frac{dy}{dx}\) 지도: 분수처럼 보이지만 분수가 아닌 하나의 연산자 기호이며, '디와이 디엑스'라고 읽음을 정확히 지도합니다. 훗날 적분 치환적분이나 연쇄법칙(합성함수 미분)에서 라이프니츠 표기법이 갖는 강력한 편의성을 안내합니다.

💡

생각 열기: 지후의 공책 풀이와 발견

다음은 지후가 함수 \(f(x) = x^2\)에서 \(f'(1), f'(2)\)의 값을 구하는 과정을 공책에 작성한 것입니다.

\(f'(1) = \lim_{\Delta x \to 0} \frac{f(1+\Delta x)-f(1)}{\Delta x} = \lim_{\Delta x \to 0} \frac{(1+\Delta x)^2 - 1^2}{\Delta x} = \lim_{\Delta x \to 0} (2 + \Delta x) = \mathbf{2}\)
\(f'(2) = \lim_{\Delta x \to 0} \frac{f(2+\Delta x)-f(2)}{\Delta x} = \lim_{\Delta x \to 0} \frac{(2+\Delta x)^2 - 2^2}{\Delta x} = \lim_{\Delta x \to 0} (4 + \Delta x) = \mathbf{4}\)
👦
지후의 탄식: "으.... 풀이 과정이 너무 긴데? \(f'(3)\), \(f'(4)\)도 이렇게 매번 일일이 극한을 계산해야 하나? 임의의 \(x\)에 대해 한 번에 기울기를 알려주는 공식은 없을까?"
🔍 탐구 질문: 지후의 풀이 규칙성을 보고 다음을 추측해 보자!
\(f'(1) = 2 = 2 \times 1\)
\(f'(2) = 4 = 2 \times 2\)
\(f'(3) = \mathbf{6 = 2 \times 3}\)
임의의 실수 \(x\)에서의 접선 기울기:
\(f'(x) = \mathbf{2x}\)
1

개념 정립: 도함수(Derivative)의 정의와 표기법

일반적으로 함수 \(y=f(x)\)가 정의역 \(X\)에 속하는 모든 \(x\)에서 미분가능할 때, 정의역의 각 원소 \(x\)에 미분계수 \(f'(x)\)를 대응시키는 새로운 함수

\(f' : X \to \mathbb{R}, \quad x \mapsto f'(x)\)

를 얻을 수 있습니다. 이 새로운 함수를 함수 \(y=f(x)\)의 도함수(Derivative Function)라고 합니다.

핵심 정의 교과서 65쪽

도함수의 정의 공식

\(f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x} = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}\)

함수 \(f(x)\)로부터 도함수 \(f'(x)\)를 구하는 과정을 "\(f(x)\)를 \(x\)에 대하여 미분한다"고 하며, 그 계산법을 미분법(Differentiation)이라고 합니다.

도함수의 다양한 기호 표기법:
\(f'(x)\)
\(y'\)
\(\frac{dy}{dx}\)
\(\frac{d}{dx}f(x)\)

💡 기호 \(\frac{dy}{dx}\)는 독일의 수학자 라이프니츠(Leibniz)가 처음 고안한 것으로, '디와이 디엑스'라고 읽습니다.

슬라이더로 x의 위치를 옮기면 접선의 기울기가 도함수 그래프로 실시간 사상됩니다
현재 접선 기울기 = f'(x) 함숫값

예제 1

도함수의 정의를 이용한 도함수 계산

교과서 65쪽
함수 \(f(x) = x^2 - 2x\)의 도함수를 정의를 이용하여 구하시오.

도함수의 정의 \(f'(x) = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h}\)에 대입합니다:

\(f'(x) = \lim_{h \to 0} \frac{\{(x+h)^2 - 2(x+h)\} - (x^2 - 2x)}{h}\)
\(= \lim_{h \to 0} \frac{(x^2 + 2xh + h^2 - 2x - 2h) - (x^2 - 2x)}{h}\)
\(= \lim_{h \to 0} \frac{2xh + h^2 - 2h}{h}\)
\(= \lim_{h \to 0} (2x + h - 2) = \mathbf{2x - 2}\)
정답: 따라서 함수 \(f(x)\)의 도함수는 \(f'(x) = \mathbf{2x - 2}\)입니다.

02. 미분법의 공식과 곱의 미분법 (Differentiation Rules)

다항함수를 극한 계산 없이 단 몇 초 만에 미분할 수 있게 해주는 거듭제곱 공식 \((x^n)' = n x^{n-1}\)과 실수배, 합, 차, 그리고 두 함수가 곱해진 형태를 미분하는 강력한 곱의 미분법(Product Rule)을 정립합니다.

🎯 핵심 성취기준: 함수의 실수배, 합, 차, 곱의 미분법을 알고, 다항함수의 도함수를 빠르고 정확하게 구할 수 있다.
2

거듭제곱 함수 \(y = x^n\)과 상수함수의 도함수

도함수의 정의를 이용하여 함수 \(y = x^n\) (단, \(n\)은 \(2\) 이상의 자연수)의 도함수를 유도해 봅시다.

📐 인수분해 공식을 이용한 엄밀 증명:

곱셈공식 \(A^n - B^n = (A - B)(A^{n-1} + A^{n-2}B + \dots + B^{n-1})\)에서 \(A = x+h, B = x\)를 대입하면:

\(y' = \lim_{h \to 0} \frac{(x+h)^n - x^n}{h}\)
\(= \lim_{h \to 0} \frac{\{(x+h)-x\}\{(x+h)^{n-1} + (x+h)^{n-2}x + \dots + x^{n-1}\}}{h}\)
\(= \lim_{h \to 0} \left\{ (x+h)^{n-1} + (x+h)^{n-2}x + \dots + x^{n-1} \right\}\)
\(= \underbrace{x^{n-1} + x^{n-1} + \dots + x^{n-1}}_{n\text{개}} = \mathbf{n x^{n-1}}\)
핵심 정리

함수 \(y = x^n\) 및 상수함수의 도함수

\(n \ge 2\)인 자연수
\((x^n)' = n x^{n-1}\)
\(n = 1\) (일차함수)
\((x)' = 1\)
상수함수 (\(c\)는 상수)
\((c)' = 0\)

💡 직관적 이해: 지수 \(n\)이 앞으로 뚝 떨어져 곱해지고, 차수는 1만큼 줄어듭니다! 상수함수는 기울기가 항상 0인 수평선이므로 미분하면 0이 됩니다.

함수의 실수배, 합, 차의 미분법 (선형성)

두 함수 \(f(x), g(x)\)가 미분가능할 때, 극한의 선형성에 의해 다음 미분 공식들이 성립합니다:

[실수배]
\(\{c f(x)\}' = c f'(x)\)
상수는 그대로 곱해짐
[합의 미분]
\(\{f(x) + g(x)\}' = f'(x) + g'(x)\)
각각 미분하여 더함
[차의 미분]
\(\{f(x) - g(x)\}' = f'(x) - g'(x)\)
각각 미분하여 뺌
4

함수의 곱의 미분법 (Product Rule)

⚠️ 절대 금지 오개념: 두 함수의 곱을 미분할 때 \(\{f(x)g(x)\}' \ne f'(x)g'(x)\) 입니다! 곱의 미분은 특별한 규칙을 따릅니다.
핵심 정리 교과서 68쪽

함수의 곱의 미분법

두 함수 \(f(x), g(x)\)가 미분가능할 때:

\(\{f(x)g(x)\}' = f'(x)g(x) + f(x)g'(x)\)

💡 암기 비법: "앞에 거 미분하고 뒤에 거 곱하고, 앞에 거 두고 뒤에 거 미분해서 더한다!" (미그그미)

📐 도함수 정의에 의한 엄밀 증명:

분자에 \(f(x)g(x+h)\)를 빼고 더하는 기교를 적용합니다:

\(\{f(x)g(x)\}' = \lim_{h \to 0} \frac{f(x+h)g(x+h) - f(x)g(x)}{h}\)
\(= \lim_{h \to 0} \frac{\{f(x+h)g(x+h) - f(x)g(x+h)\} + \{f(x)g(x+h) - f(x)g(x)\}}{h}\)
\(= \lim_{h \to 0} \left\{ \frac{f(x+h)-f(x)}{h} \times g(x+h) \right\} + \lim_{h \to 0} \left\{ f(x) \times \frac{g(x+h)-g(x)}{h} \right\}\)
\(= \lim_{h \to 0} \frac{f(x+h)-f(x)}{h} \times \lim_{h \to 0} g(x+h) + f(x) \times \lim_{h \to 0} \frac{g(x+h)-g(x)}{h}\)
\(= \mathbf{f'(x)g(x) + f(x)g'(x)}\) (단, \(g(x)\)가 미분가능하므로 연속이어서 \(\lim_{h \to 0} g(x+h) = g(x)\))

도함수 함숫값의 계산

교과서 70쪽
두 함수 \(f(x) = 4x^2 + 2x + 1\), \(g(x) = -5x^3 + 2x^2 + 5\)에 대하여 \(f'(1) + g'(-1)\)의 값을 구하시오.
미분 및 대입 계산장
• \(f'(x) = 8x + 2 \implies f'(1) = 8(1) + 2 = 10\)
• \(g'(x) = -15x^2 + 4x \implies g'(-1) = -15(-1)^2 + 4(-1) = -15 - 4 = -19\)
따라서 \(f'(1) + g'(-1) = 10 + (-19) = \mathbf{-9}\)입니다.

곱의 미분 공식 적용 연습장
• \(f(1) = 2(1)^2 + 2 = 4\), \(f'(x) = 4x \implies f'(1) = 4\)
• \(g(1) = -3(1)^3 + 1 + 1 = -1\), \(g'(x) = -9x^2 + 1 \implies g'(1) = -9 + 1 = -8\)
• \(h'(x) = f'(x)g(x) + f(x)g'(x)\)이므로:
\(h'(1) = f'(1)g(1) + f(1)g'(1) = 4(-1) + 4(-8) = -4 - 32 = \mathbf{-36}\)

함수 \(f(x) = x^2 + ax + b\)에 대하여 \(f(2) = 1\), \(f'(1) = 0\)일 때, \(f(4)\)의 값을 구하시오. (단, \(a, b\)는 상수이다.)
연립방정식 전개 연습장
• \(f'(x) = 2x + a\)이므로 \(f'(1) = 2(1) + a = 0 \implies \mathbf{a = -2}\)
• \(f(x) = x^2 - 2x + b\)에 \(f(2) = 1\) 대입: \(2^2 - 2(2) + b = 1 \implies \mathbf{b = 1}\)
• 따라서 완성된 함수식은 \(f(x) = x^2 - 2x + 1\)입니다.
\(f(4) = 4^2 - 2(4) + 1 = 16 - 8 + 1 = \mathbf{9}\)

건물의 연간 난방 부하와 순간변화율 예측

교과서 70쪽

건물의 냉난방 에너지를 효율적으로 사용하기 위해서는 설계 단계에서부터 건물의 정확한 연간 열 출입량을 계산하여 연간 난방 부하를 예측할 수 있어야 합니다. 연중 최대 난방 부하가 걸리는 날을 1월 3일이라고 할 때, 1월 1일 0시로부터 \(t\)시간 후 어느 건물의 연간 난방 부하를 \(f(t)\,\text{kW}\)라고 하면:

\(f(t) = (t - 49)^2 (t + 8711)^2 \quad (1 \le t \le 8760,\; 1\text{년}=8760\text{시간})\)
⑴ 도함수 \(f'(t)\)를 구하시오.
⑵ \(t=50\)일 때, 연간 난방 부하의 순간변화율을 구하시오.
SIMULATOR 6: 연간 8,760시간 난방 부하 프로파일 & 순간변화율 분석기 시간 슬라이더를 움직여 특정 시각의 접선 기울기(부하 급증율)를 관찰하세요
순간변화율 \(f'(t)\)
1.54 × 10⁸ kW/h
거듭제곱 미분 및 대입 계산장

⑴ \(f'(t)\) 전개:
곱의 미분법과 거듭제곱 미분법을 적용하면:
\(\begin{aligned} f'(t) &= 2(t-49)(t+8711)^2 + (t-49)^2 \cdot 2(t+8711) \\[4pt] &= 2(t-49)(t+8711)\{(t+8711) + (t-49)\} \\[4pt] &= 2(t-49)(t+8711)(2t + 8662) = \mathbf{4(t-49)(t+8711)(t + 4331)} \end{aligned}\)

⑵ \(t=50\) 대입:
\(f'(50) = 4(50-49)(50+8711)(50+4331) = 4 \times 1 \times 8761 \times 4381 = \mathbf{153,527,764}\)
