수학적 정의

함수의 증가와 감소

교과서 81쪽

함수 $f(x)$가 어떤 구간에 속하는 임의의 두 실수 $x_1, x_2$에 대하여

증가 (Increasing)
$$x_1 < x_2 \implies f(x_1) < f(x_2)$$

$x$값이 커질수록 함숫값도 함께 커지는 상태

감소 (Decreasing)
$$x_1 < x_2 \implies f(x_1) > f(x_2)$$

$x$값이 커질수록 함숫값은 반대로 작아지는 상태

보기: $f(x) = x^2$의 증감 분석

$0 \le x_1 < x_2$일 때 $f(x_2) - f(x_1) = x_2^2 - x_1^2 = (x_2 + x_1)(x_2 - x_1) > 0 \implies f(x_1) < f(x_2)$. 따라서 $f(x) = x^2$은 구간 $[0, \infty)$에서 증가하고, 마찬가지로 $(-\infty, 0]$에서 감소합니다.

문제 1

3차 단조함수 $f(x) = x^3$의 증가 증명

함수 $f(x) = x^3$이 구간 $(-\infty, \infty)$에서 증가함을 보이시오.

대수적 인수분해 증명:

임의의 두 실수 $x_1 < x_2$에 대하여 차를 계산하면:

$$f(x_2) - f(x_1) = x_2^3 - x_1^3 = (x_2 - x_1)\left(x_2^2 + x_1 x_2 + x_1^2\right)$$

이때 $x_2 - x_1 > 0$이고, 이차식 부분은 완전제곱꼴로 묶으면 다음과 같습니다:

$$x_2^2 + x_1 x_2 + x_1^2 = \left(x_2 + \frac{x_1}{2}\right)^2 + \frac{3}{4}x_1^2 > 0 \quad ( ext{두 실수가 동시에 0이 아닐 때})$$

따라서 $f(x_2) - f(x_1) > 0 \iff f(x_1) < f(x_2)$이므로 함수 $f(x) = x^3$은 실수 전체 구간 $(-\infty, \infty)$에서 증가합니다. (증명 완료)

핵심 판정법

도함수의 부호에 의한 증가와 감소의 판정

교과서 82쪽

함수 $f(x)$가 어떤 열린구간에서 미분가능하고, 이 구간에 속하는 모든 $x$에 대하여

$$f'(x) > 0$$ 이 구간에서 증가
$$f'(x) < 0$$ 이 구간에서 감소
평균값 정리를 이용한 판정법의 증명 (교과서 82쪽)

임의의 두 실수 $x_1 < x_2$에 대하여 닫힌구간 $[x_1, x_2]$에서 평균값 정리를 적용하면:

$$\frac{f(x_2) - f(x_1)}{x_2 - x_1} = f'(c) \quad (x_1 < c < x_2)$$

이때 $x_2 - x_1 > 0$이므로, $f'(c) > 0$이면 분자 $f(x_2) - f(x_1) > 0 \implies f(x_1) < f(x_2)$가 되어 함수 $f(x)$는 증가합니다. $f'(c) < 0$이면 마찬가지로 감소합니다.

주의: 역은 일반적으로 성립하지 않습니다! (수능 필수 함정)

함수 $f(x) = x^3$은 실수 전체에서 항상 증가하지만, $x = 0$에서의 도함수는 $f'(0) = 0$입니다. 즉, "증가한다고 해서 모든 점에서 $f'(x) > 0$인 것은 아니며, $f'(x) \ge 0$이 성립합니다."

예제 1

증감표를 이용한 함수의 증가와 감소 조사

교과서 83쪽
(1) $f(x) = x^3 - 3x^2$

1) 도함수 구하기: $f'(x) = 3x^2 - 6x = 3x(x - 2)$

2) $f'(x) = 0$이 되는 기준점: $x = 0$ 또는 $x = 2$

$x$ $\cdots$ $0$ $\cdots$ $2$ $\cdots$
$f'(x)$ $+$ $0$ $-$ $0$ $+$
$f(x)$ $\nearrow$ $0$ $\searrow$ $-4$ $\nearrow$

$\implies$ 함수 $f(x)$는 구간 $(-\infty, 0], [2, \infty)$에서 증가하고, 닫힌구간 $[0, 2]$에서 감소합니다.

(2) $f(x) = -x^3 + 6x^2 - 12x$

1) 도함수 구하기: $f'(x) = -3x^2 + 12x - 12 = -3(x - 2)^2$

2) $x \neq 2$인 모든 실수에서 $f'(x) < 0$이고 $f'(2) = 0$입니다.

$\implies$ 따라서 함수 $f(x)$는 실수 전체 구간 $(-\infty, \infty)$에서 항상 감소합니다.

함수의 증가와 감소 조사하기

교과서 83쪽
(1) $f(x) = -x^3 + 12x + 1$

$f'(x) = -3(x^2 - 4) = 0$의 두 근을 구하고 증가하는 구간 $[-a, a]$의 $a$를 구하세요.

증가 구간: [- , 2]
(2) $f(x) = 2x^3 - 6x^2 + 7x + 3$

도함수 $f'(x) = 6x^2 - 12x + 7$의 판별식 $D/4$를 조사하여 전체 증감을 선택하세요.

문제 2 상세 해설

(1) $f(x) = -x^3 + 12x + 1$:

$f'(x) = -3x^2 + 12 = -3(x^2 - 4) = -3(x+2)(x-2)$

$f'(x) \ge 0 \iff -2 \le x \le 2$ 이므로 증가하는 닫힌구간은 $[-2, 2]$ (즉, $a = 2$)입니다. (감소 구간: $(-\infty, -2], [2, \infty)$)

(2) $f(x) = 2x^3 - 6x^2 + 7x + 3$:

$f'(x) = 6x^2 - 12x + 7$의 판별식 $D/4 = (-3)^2 - 6 \times 7 = 9 - 42 = -33 < 0$

모든 실수 $x$에 대해 $f'(x) > 0$이므로 전 구간 항상 증가합니다.

삼차함수 $y = f(x)$의 도함수 $y = f'(x)$의 그래프가 아래 3가지 형태일 때, $f(x)$의 증가와 감소 특성을 비교해 보세요.

(1) $x$절편 $1, 3$ 통과 ($D > 0$)
$(-\infty, 1], [3, \infty)$ 증가
$[1, 3]$ 감소
(2) $x = 2$ 접함 ($D = 0$)
전체 구간 $(-\infty, \infty)$에서
항상 증가 ($f' \ge 0$)
(3) $x$축 붕 뜸 ($D < 0$)
전체 구간 $(-\infty, \infty)$에서

문제 3 추론 해설

(1) $D > 0$ ($x$절편 $1, 3$ 통과):

$x < 1$ 또는 $x > 3$에서 $f'(x) > 0$이므로 $(-\infty, 1], [3, \infty)$에서 증가하고, $1 < x < 3$에서 $f'(x) < 0$이므로 $[1, 3]$에서 감소합니다.

(2) $D = 0$ ($x = 2$ 접함):

$x = 2$에서 $f'(2) = 0$이고 그 외 모든 실수에서 $f'(x) > 0$입니다. 도함수가 0이 되는 점이 순간적(한 점)이므로 실수 전체 구간 $(-\infty, \infty)$에서 항상 증가합니다.

(3) $D < 0$ ($x$축과 만나지 않고 붕 뜸):

모든 실수 $x$에 대해 항상 $f'(x) > 0$이므로 실수 전체 구간 $(-\infty, \infty)$에서 항상 증가합니다.

함수의 극대와 극소는 무엇일까?

어떤 열린구간 안에서 가장 높거나 낮은 상태를 뜻하는 국소적 극대·극소의 정의와, 미분계수와의 관계인 페르마의 정리($f'(a)=0$)를 살펴봅니다.

생각 열기 해설

(1) 6시에서 12시 사이에 전력 사용량이 가장 많은 시각: 9시 (극대 피크)

(2) 9시에서 15시 사이에 전력 사용량이 가장 적은 시각: 12시 (극소 저점)

핵심 정의

극대와 극소 (Local Extrema)

교과서 84쪽
극대 (Local Maximum) f(x) ≤ f(a)

$x = a$를 포함하는 어떤 열린구간에 속하는 모든 $x$에 대하여 $f(x) \le f(a)$일 때, $f(x)$는 $x = a$에서 극대라 하고, 함숫값 $f(a)$를 극댓값이라고 합니다.

극소 (Local Minimum) f(x) ≥ f(b)

$x = b$를 포함하는 어떤 열린구간에 속하는 모든 $x$에 대하여 $f(x) \ge f(b)$일 때, $f(x)$는 $x = b$에서 극소라 하고, 함숫값 $f(b)$를 극솟값이라고 합니다.

Q

극댓값은 항상 극솟값보다 큰가요?

아닙니다! 극값은 그 주변(국소적 열린구간)에서만 비교하는 국소적 성질이므로, 왼쪽의 극댓값이 오른쪽 멀리 있는 극솟값보다 작을 수도 있습니다.

극댓값:
극솟값:
극댓점 (0, 1), 극솟점 (2, -3)

문제 4 상세 해설

$f(x) = x^3 - 3x^2 + 1 \implies f'(x) = 3x^2 - 6x = 3x(x-2) = 0 \implies x = 0 \text{ 또는 } x = 2$

$x=0$ 좌우에서 $f'(x)$가 $(+) \to (-)$로 바뀌므로 극댓값 $f(0) = 1$

$x=2$ 좌우에서 $f'(x)$가 $(-) \to (+)$로 바뀌므로 극솟값 $f(2) = 8 - 12 + 1 = -3$

페르마의 정리

극값과 미분계수 ($f'(a) = 0$)

교과서 85쪽

미분가능한 함수 $f(x)$가 $x = a$에서 극값을 가지면

$$f'(a) = 0$$

극점에서는 접선이 완벽히 수평을 이룹니다.

⚠️ 역은 성립하지 않는다! ($f'=0$이어도 극값 아님)

$f(x) = x^3$은 $f'(0) = 0$이지만, $x=0$ 좌우에서 계속 증가하므로 극값이 아닙니다.

⚠️ 극값이어도 미분불가능할 수 있다! (첨점)

$f(x) = |x|$는 $x=0$에서 극솟값 $0$을 갖지만, 뾰족점이므로 $f'(0)$은 존재하지 않습니다.
