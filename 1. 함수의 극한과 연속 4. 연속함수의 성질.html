💡 생각 열기 : 흔들리지 않고 강을 건너는 다리?

어떤 물체가 영하 $5^\circ\text{C}$에서 영상 $15^\circ\text{C}$로 온도가 변했습니다. 온도는 연속적으로 변하므로 도중에 반드시 $0^\circ\text{C}$가 되는 순간이 존재할까요?

네! 온도는 연속함수이므로 사잇값 정리에 의해 $-5$와 $15$ 사이의 $0$을 반드시 거쳐 지나갑니다.

1. 최대·최소 정리 (Extreme Value Theorem)

📌 정리 내용

함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이면, $f(x)$는 이 구간에서 반드시 최댓값과 최솟값을 갖는다.

전제 조건 필수: 닫힌구간이 아니거나(열린구간), 연속이 아니면 최댓값 또는 최솟값이 존재하지 않을 수 있습니다.

2. 사잇값 정리 & 방정식의 실근의 존재

📌 사잇값 정리

함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이고 $f(a) \ne f(b)$일 때, $f(a)$와 $f(b)$ 사이의 임의의 값 $k$에 대하여 $$f(c) = k$$ 인 $c$가 열린구간 $(a, b)$에 적어도 하나 존재한다.

🎯 실근의 존재 판정 (k = 0 인 경우)

함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이고 $f(a)f(b) < 0$ (부호가 반대)이면, 방정식 $f(x) = 0$은 열린구간 $(a, b)$에서 적어도 하나의 실근을 갖는다.

사잇값 정리 실근 탐색 실험실

f(x) = x³ - 3x - 1
b = 1.2 b = 2.00 b = 2.5
f(a) = f(1.0): -3.00 (음수)
f(b): 1.00 (양수)
실근 존재 여부: 실근 존재 (f(a)·f(b) < 0)

대표 예제 풀이 & 연습장

예제 1 (사잇값 정리와 실근 증명)

방정식 $x^3 - 3x - 1 = 0$ 이 열린구간 $(1, 2)$에서 적어도 하나의 실근을 가짐을 보이시오.

$f(x) = x^3 - 3x - 1$이라 두면 $f(x)$는 다항함수이므로 닫힌구간 $[1, 2]$에서 연속입니다.

$$f(1) = 1 - 3 - 1 = -3 < 0$$

$$f(2) = 8 - 6 - 1 = 1 > 0$$

$f(1)$과 $f(2)$의 부호가 서로 다르므로($f(1)f(2) < 0$), 사잇값 정리에 의해 $f(c) = 0$인 $c$가 열린구간 $(1, 2)$에 적어도 하나 존재합니다.

문제 풀이 연습장

스스로 확인하기 (형성평가)

01. 함수 $f(x) = -x^2 + 2x + 3$의 닫힌구간 $[0, 3]$에서의 최댓값과 최솟값은?

최댓값 $4$ ($x=1$), 최솟값 $0$ ($x=3$)

02. 방정식 $x^3 + 2x - 5 = 0$은 구간 $(1, 2)$에서 실근을 갖는가?

갖는다 ($f(1) = -2 < 0$, $f(2) = 7 > 0$)
