연속함수의 성질과 최대·최소 정리

연속인 두 함수를 더하고, 빼고, 곱하고, 나누어도 연속성을 유지하는 사칙연산 성질을 학습하고, 닫힌구간에서 정의된 연속함수가 반드시 가지는 강력한 성질인 최대·최소 정리를 탐구합니다.

1. 극한의 기본 성질과의 논리적 연결

두 함수 $f(x), g(x)$가 $x=a$에서 연속일 때, $\lim f(x) = f(a)$ 및 $\lim g(x) = g(a)$가 성립합니다. 따라서 함수의 극한에 대한 사칙연산 성질이 곧바로 연속함수의 사칙연산 성질로 자연스럽게 귀결됨을 논리적으로 연결 지도합니다.

2. 최대·최소 정리의 2대 필수 전제 조건

최대·최소 정리는 ① 닫힌구간 $[a, b]$, ② 구간 내 연속성이라는 두 조건이 모두 충족될 때만 성립합니다. 열린구간이거나 불연속점이 하나라도 존재할 때 최댓값 또는 최솟값이 사라지는 반례를 반드시 시각적으로 비교 체험하도록 합니다.

연속함수의 성질 (교과서 36쪽)

핵심 정리

두 함수 $f(x), g(x)$가 $x = a$에서 연속이면 다음 함수도 $x = a$에서 연속이다:

1. 상수배

$c f(x)$ (단, $c$는 상수)

2. 덧셈과 뺄셈

$f(x) + g(x), \ f(x) - g(x)$

3. 곱셈

$f(x)g(x)$

4. 나눗셈

$ rac{f(x)}{g(x)}$ (단, $g(a) e 0$)

다항함수의 연속성

상수함수 $f(x)=c$와 항등함수 $f(x)=x$는 모든 실수에서 연속입니다. 곱셈 성질에 의해 $x^2, x^3, \dots, x^n$도 연속이며, 상수배와 덧셈 성질에 의해 모든 다항함수 $f(x) = a_n x^n + \dots + a_0$는 실수 전체의 구간 $(-\infty, \infty)$에서 항상 연속입니다.

유리함수의 연속성

다항함수 $f(x), g(x)$에 대하여 유리함수 $ rac{f(x)}{g(x)}$는 나눗셈 성질에 의해 분모 $g(x) e 0$인 모든 실수에서 연속입니다.

• $f(1) = |1-3| = 2$

• $f(3) = |3-3| = 0$ (최솟값)

• $f(4) = |4-3| = 1$

$ herefore$ 최댓값: 2, 최솟값: 0

사잇값 정리 (Intermediate Value Theorem, IVT)

미적분학 핵심 정리

사잇값 정리

함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이고 $f(a) e f(b)$ 이면, $f(a)$와 $f(b)$ 사이의 임의의 값 $k$에 대하여

$f(c) = k$

인 $c$가 열린구간 $(a, b)$에 적어도 하나 존재한다.

★ 방정식의 실근 존재성 판정법 (가장 중요한 응용!)

함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속이고 $f(a)$와 $f(b)$의 부호가 서로 다르면 ($f(a)f(b) < 0$), 사잇값 정리에 의하여 ($k=0$ 대입)

$f(c) = 0$ 인 $c$가 열린구간 $(a, b)$에 적어도 하나 존재한다.

$\implies$ 방정식 $f(x) = 0$ 은 열린구간 $(a, b)$에서 적어도 하나의 실근을 갖는다!

사잇값 정리 실근 시각화 (Root Existence Canvas)
양 끝점 부호: f(a) > 0, f(b) < 0 (부호 반대)
함수 형태:
x축 교차 실근 c: 1개 감지됨

4개 소문항
$f(x) = x - 2, \quad g(x) = x^2 - 4x + 3 = (x-1)(x-3)$
⑴ $f(x) + g(x)$
다항함수끼리의 합은 다항함수이므로 실수 전체 $(-\infty, \infty)$에서 연속입니다.
⑵ $f(x)g(x)$
다항함수의 곱도 다항함수이므로 실수 전체 $(-\infty, \infty)$에서 연속입니다.
⑶ $ rac{f(x)}{g(x)}$ (분모 $g(x)=x^2-4x+3$)
분모 $g(x) = (x-1)(x-3) e 0 \iff x e 1, x e 3$ 이므로 구간은 $(-\infty, 1), (1, 3), (3, \infty)$ 입니다.
⑷ $ rac{g(x)}{f(x)}$ (분모 $f(x)=x-2$)
분모 $f(x) = x-2 e 0 \iff x e 2$ 이므로 구간은 $(-\infty, 2), (2, \infty)$ 입니다.
03

주어진 구간에서 최댓값과 최솟값 (교과서 40쪽)

2개 소문항
⑴ 무리함수 $f(x) = \sqrt{2x + 5}$ on $[-1, 3]$

• $f(x)$는 증가함수이므로 양 끝점에서 최대/최소를 갖습니다.

• 최댓값: $f(3) = \sqrt{2(3)+5} = \mathbf{\sqrt{11}}$

• 최솟값: $f(-1) = \sqrt{2(-1)+5} = \mathbf{\sqrt{3}}$

⑵ 유리함수 $f(x) = rac{2x}{x + 3}$ on $[-2, 0]$

• $f(x) = rac{2(x+3)-6}{x+3} = 2 - rac{6}{x+3}$ 는 구간 $[-2, 0]$에서 증가함수입니다.

• 최댓값: $f(0) = rac{0}{3} = \mathbf{0}$

• 최솟값: $f(-2) = rac{2(-2)}{-2+3} = rac{-4}{1} = \mathbf{-4}$

부호 판정

방정식 $x^4 - 3x^3 + 1 = 0$ 이 열린구간 $(1, 3)$에서 적어도 하나의 실근을 가짐을 보이시오.

$f(1) =$ $f(3) =$

[정답 해설]

• $f(x) = x^4 - 3x^3 + 1$ 은 닫힌구간 $[1, 3]$에서 연속입니다.

• $f(1) = 1 - 3 + 1 = -1 < 0$

• $f(3) = 81 - 81 + 1 = 1 > 0$

• 따라서 $f(1)f(3) < 0$ 이므로 사잇값 정리에 의해 $f(c)=0$ 인 $c$가 열린구간 $(1, 3)$에 적어도 하나 존재합니다.

05

부호 변화를 이용한 최소 실근 개수 추론 (교과서 40쪽)

수능 킬러 기초

모든 실수에서 연속인 함수 $f(x)$에 대하여

$f(0) = -1, \quad f(1) = 2, \quad f(2) = -2, \quad f(3) = 3, \quad f(4) = 1, \quad f(5) = -1$

일 때, 방정식 $f(x) = 0$ 은 열린구간 $(0, 5)$에서 적어도 몇 개의 실근을 갖는지 구하시오.

개

[부호 변화 추적 해설]

• 구간 $(0, 1)$ : $f(0)=-1 < 0, \ f(1)=2 > 0$ $\implies$ 실근 적어도 1개

• 구간 $(1, 2)$ : $f(1)=2 > 0, \ f(2)=-2 < 0$ $\implies$ 실근 적어도 1개

• 구간 $(2, 3)$ : $f(2)=-2 < 0, \ f(3)=3 > 0$ $\implies$ 실근 적어도 1개

• 구간 $(3, 4)$ : $f(3)=3 > 0, \ f(4)=1 > 0$ $\implies$ 부호 변화 없음 (보장 불가)

• 구간 $(4, 5)$ : $f(4)=1 > 0, \ f(5)=-1 < 0$ $\implies$ 실근 적어도 1개

$ herefore$ 총 4개의 구간에서 각각 적어도 하나의 실근을 가지므로 적어도 4개입니다.

생각을 키우는 문제 : 등산 해발 고도와 사잇값 정리 (교과서 40쪽)

수학적 모델링

정상의 높이가 해발 $1000 ext{ m}$ 인 어느 산의 $500 ext{ m}$ 지점에 A 산장, $800 ext{ m}$ 지점에 B 산장이 있다.

선아의 이동 ($f(t)$)

아침 7시: 입구 $100 ext{ m}$ 출발 $\implies f(7) = 100$

정오 12시: 정상 $1000 ext{ m}$ 도착 $\implies f(12) = 1000$

경수의 이동 ($g(t)$)

아침 7시: A 산장 $500 ext{ m}$ 출발 $\implies g(7) = 500$

정오 12시: B 산장 $800 ext{ m}$ 도착 $\implies g(12) = 800$

⑴ 함수 $h(t) = f(t) - g(t)$ 의 연속성

시각 $t$ ($7 \le t \le 12$)에서 두 사람의 고도 차이 함수 $h(t)$는 연속인가 불연속인가?

• 사람의 이동에 따른 해발 고도는 시간에 따라 연속적으로 변하므로 $f(t)$와 $g(t)$는 모두 연속함수입니다.

• 연속함수의 뺄셈 성질에 의해 $h(t) = f(t) - g(t)$ 도 닫힌구간 $[7, 12]$에서 연속입니다.

⑵ 고도가 일치하는 순간의 존재 ($f(c)=g(c)$)

7시부터 12시까지 같은 시각에 두 사람의 고도가 같은 순간이 반드시 있었는가?

• $h(7) = f(7) - g(7) = 100 - 500 = -400 < 0$

• $h(12) = f(12) - g(12) = 1000 - 800 = 200 > 0$

• $h(7)h(12) < 0$ 이고 $h(t)$는 연속이므로, 사잇값 정리에 의해 $h(c) = 0 \iff f(c) = g(c)$ 인 시각 $c$가 $7 < c < 12$ 사이에 반드시 적어도 한 번 존재합니다!
