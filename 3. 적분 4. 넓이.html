04. 넓이 (Area between Curves)

곡선과 $x$축 사이의 실제 기하학적 면적을 계산하기 위해 부호 분할 적분 $S = \int_a^b |f(x)|\,dx$을 마스터하고, 두 곡선 사이의 넓이 $S = \int_a^b |f(x) - g(x)|\,dx$ 및 경제학의 소득 불평등 지표인 로렌츠 곡선과 지니 계수(Gini Coefficient)까지 탐구해 봅시다.

곡선과 $x$축 사이의 넓이 $S = \int_a^b |f(x)|\,dx$
두 곡선 사이의 넓이 $S = \int_a^b |f(x) - g(x)|\,dx$
로렌츠 곡선과 지니 계수 $G = 2\int_0^1 \{x - L(x)\}dx$
45차시

01. 곡선과 $x$축 사이의 넓이 ($S = \int_a^b |f(x)|\,dx$)

교과서 138~140쪽 · 함숫값의 부호 판정과 구간 분할 적분의 원리

📐 기하학적 넓이(양수)를 구하기 위한 절댓값의 필연성

정적분은 부호가 있는 값이지만, 기하학적 넓이 $S$는 항상 $0$ 이상의 양수이어야 합니다. 따라서 곡선이 $x$축 아래에 있는 구간에서는 마이너스 부호를 붙여 양수로 전환하여 적분합니다.

$$S = \mathbf{\int_a^b |f(x)|\,dx}$$
Case 1: $f(x) \ge 0$ ($x$축 위쪽)
$$S = \int_a^b f(x)\,dx$$

함숫값이 양수이므로 정적분 값이 곧 넓이입니다.

Case 2: $f(x) \le 0$ ($x$축 아래쪽)
$$S = \int_a^b -f(x)\,dx = -\int_a^b f(x)\,dx$$

함숫값이 음수이므로 부호를 반대로 뒤집어 양수로 만듭니다.

📊 $y = x^2 - 4x + 3$의 넓이 분할: 구간 $[0, 4]$ 교점: x=1, 3

⚡ [시험 꿀팁] 이차함수와 $x$축으로 둘러싸인 넓이 쾌속 공식

이차방정식 $a(x - \alpha)(x - \beta) = 0$의 두 실근 $\alpha, \beta$ ($\alpha < \beta$)에 대하여:

$$S = \frac{|a|}{6}(\beta - \alpha)^3$$

※ 객관식이나 검산 시 위 공식을 사용하면 복잡한 분수 전개 없이 단 3초 만에 넓이를 계산할 수 있습니다!

46차시

02. 두 곡선 사이의 넓이 ($S = \int_a^b |f(x)-g(x)|\,dx$)

교과서 141~142쪽 · 위쪽 곡선에서 아래쪽 곡선을 빼는 표준 알고리즘

🎯 핵심 원리: "(위쪽 곡선) - (아래쪽 곡선)" 적분

두 함수 $y = f(x)$와 $y = g(x)$가 구간 $[a, b]$에서 연속이고 $f(x) \ge g(x)$일 때, 두 곡선 사이의 넓이는 다음과 같습니다:

$$S = \int_a^b \{f(x) - g(x)\}\,dx = \mathbf{\int_a^b (\text{위쪽 식} - \text{아래쪽 식})\,dx}$$
📋 두 곡선 사이의 넓이를 구하는 3단계 알고리즘:
1단계: 교점 구하기 — 방정식 $f(x) - g(x) = 0$을 풀어 적분 구간의 양 끝값(또는 교점)을 찾는다.
2단계: 상하 관계 판정 — 각 구간 내부의 한 점을 대입하여 어느 곡선이 더 위에 있는지 확인한다.
3단계: 정적분 계산 — $\int_{\text{교점}}^{\text{교점}} (\text{위쪽} - \text{아래쪽})\,dx$를 계산한다.

🎯 45~46차시 개념 자가진단 (O/X 퀴즈)

1. 구간 $[a, b]$에서 항상 $f(x) \le 0$일 때, 곡선과 $x$축 사이의 넓이는 $-\int_a^b f(x)\,dx$ 이다. (O/X)
2. 두 곡선 $y=f(x), y=g(x)$ 사이의 넓이는 두 곡선이 $x$축보다 아래에 있더라도 위쪽 식에서 아래쪽 식을 빼면 항상 양수로 올바르게 구해진다. (O/X)
3. 이차함수 $y = -(x - 1)(x - 4)$와 $x$축 사이의 넓이는 $\frac{1}{6}(4 - 1)^3 = \frac{27}{6} = \frac{9}{2}$ 이다. (O/X)

03. 스스로 확인하기 (01 ~ 06번)

교과서 143~144쪽 · 곡선과 x축 넓이, 두 곡선 사이의 교점 적분, 두 영역의 넓이가 같을 조건, 대칭 그늘막

01번 교과서 144쪽 / 공식 확인

다음 네모 안에 알맞은 정적분 식을 완성하시오.

(1) 닫힌구간 $[a, b]$에서 곡선 $y=f(x)$와 $x$축 및 두 직선 $x=a, x=b$로 둘러싸인 도형의 넓이:
(2) 닫힌구간 $[a, b]$에서 두 곡선 $y=f(x), y=g(x)$ 및 두 직선 $x=a, x=b$로 둘러싸인 도형의 넓이:
✏️ 01번 공식 정리 메모장
[정답 및 해설] (1) $\int_a^b |f(x)|\,dx$  |  (2) $\int_a^b |f(x)-g(x)|\,dx$
02번 교과서 144쪽 / 곡선과 x축 사이의 넓이

다음 곡선과 $x$축 및 주어진 직선으로 둘러싸인 도형의 넓이를 구하시오.

(1) $y = 3x^2 - 6x - 9$, $x = 1, x = 3$

(2) $y = -x^2 + 8x - 7$, $x = 0, x = 2$
넓이 $S =$
✏️ 02번 x절편 및 부호 판정 계산 연습장
[정답 및 해설]
• (1) $3x^2 - 6x - 9 = 3(x+1)(x-3) \le 0$ on $[1, 3]$. $S = \int_1^3 (-3x^2+6x+9)\,dx = [-x^3+3x^2+9x]_1^3 = 27 - 11 = \mathbf{16}$.
• (2) $-x^2+8x-7 = -(x-1)(x-7) = 0 \implies x=1$에서 부호 변화. $[0, 1]$ 음수, $[1, 2]$ 양수:
$S = \int_0^1 (x^2-8x+7)\,dx + \int_1^2 (-x^2+8x-7)\,dx = \frac{10}{3} + \frac{2}{3} = \mathbf{4}$.

다음 두 곡선으로 둘러싸인 도형의 넓이를 구하시오.

(1) $y = -x^2 + 2x - 1$과 $y = x^2 - 5$
넓이 $S =$
(2) $y = x^3 - 2x^2 - x + 2$와 $y = x^2 - 1$
넓이 $S =$
✏️ 03번 두 곡선 교점 연립 및 적분 연습장
[정답 및 해설]
• (1) $-x^2+2x-1 = x^2-5 \implies 2(x+1)(x-2)=0$. 교점 $x=-1, 2$. 포물선 넓이 공식: $\frac{|-2|}{6}(2-(-1))^3 = \frac{1}{3}(27) = \mathbf{9}$.
• (2) $(x^3-2x^2-x+2) - (x^2-1) = x^3-3x^2-x+3 = (x+1)(x-1)(x-3) = 0$. 교점 $x=-1, 1, 3$:
$S = \int_{-1}^1 (x^3-3x^2-x+3)\,dx + \int_1^3 (-x^3+3x^2+x-3)\,dx = 4 + 4 = \mathbf{8}$.
04번 교과서 144쪽 / 넓이 조건을 만족시키는 미정계수

곡선 $y = x^3$과 $x$축 및 두 직선 $x = a, x = 2$로 둘러싸인 도형의 넓이가 $\frac{17}{4}$일 때, 상수 $a$ ($a < 0$)의 값을 구하시오.

✏️ 04번 x=0 기준 구간 분할 및 a^4=1 풀이 연습장
[정답 및 해설] $a < 0$이므로 $[a, 0]$에서 $x^3 \le 0$, $[0, 2]$에서 $x^3 \ge 0$입니다:
$S = \int_a^0 (-x^3)\,dx + \int_0^2 x^3\,dx = \left[-\frac{1}{4}x^4\right]_a^0 + \left[\frac{1}{4}x^4\right]_0^2 = \frac{1}{4}a^4 + 4 = \frac{17}{4}$.
$\frac{1}{4}a^4 = \frac{1}{4} \implies a^4 = 1$. $a < 0$이므로 $\mathbf{a = -1}$ 입니다.
05번 익스플로라그램 ⑤
두 영역 넓이 일치: ∫_0^a f(x)dx = 0

곡선 $y = x^2 - 3x$와 $x$축 및 직선 $x = a$로 둘러싸인 두 도형 $A, B$의 넓이가 서로 같을 때, 상수 $a$의 값을 구하시오. (단, $a > 3$)

a = 4.50
정적분 $\int_0^a f(x)dx = 0.00$ (A = B 일치!)
✏️ 05번 -A + B = 0 정적분 식 세우기 연습장
[정답 및 해설] $[0, 3]$에서 정적분은 $-A$, $[3, a]$에서 정적분은 $+B$이므로, $A=B$이면:
$\int_0^a (x^2 - 3x)\,dx = -A + B = 0 \implies \left[\frac{1}{3}x^3 - \frac{3}{2}x^2\right]_0^a = a^2\left(\frac{1}{3}a - \frac{3}{2}\right) = 0$.
$a > 3$이므로 $\frac{1}{3}a = \frac{3}{2} \implies \mathbf{a = \frac{9}{2}}$ (또는 $\mathbf{4.5}$) 입니다.
06번 생각을 키우는 문제 (144쪽)
익스플로라그램 ⑥ 세 포물선 대칭 그늘막

어떤 그늘막의 경계선이 각각 이차함수 $y = \frac{1}{2}x^2 - \frac{5}{2}x + 2$ ($x \ge 0$), $y = \frac{1}{2}x^2 + \frac{5}{2}x + 2$ ($x \le 0$), $y = -\frac{1}{8}x^2 - \frac{1}{2}$ 의 그래프의 일부와 같다고 할 때, 이 그늘막의 넓이를 구하시오.

🎪 대칭 그늘막 영역 시각화 ($y$축 좌우 대칭) 교점: A(-2, -1), B(2, -1)
✏️ 06번 교점 연립 및 y축 대칭 2배 적분 연습장
[정답 및 해설] $x \ge 0$에서 두 식을 연립하면:
$\frac{1}{2}x^2 - \frac{5}{2}x + 2 = -\frac{1}{8}x^2 - \frac{1}{2} \implies \frac{5}{8}(x - 2)^2 = 0 \implies x = 2, y = -1$.
$y$축 대칭이므로 오른쪽 절반 영역($x \in [0, 2]$)의 2배를 계산합니다:
$S = 2\int_0^2 \frac{5}{8}(x - 2)^2\,dx = \frac{5}{4}\left[\frac{1}{3}(x - 2)^3\right]_0^2 = \frac{5}{4}\left(0 - \left(-\frac{8}{3}\right)\right) = \mathbf{\frac{10}{3}}$ 입니다.

04. 소득 불평등을 수치화하는 로렌츠 곡선과 지니 계수

교과서 145쪽 · 완전 평등선 $y=x$와 로렌츠 곡선 $y=L(x)$ 사이의 넓이와 경제적 의미

📊 정적분으로 계산하는 소득 분배의 불평등 지표: 지니 계수 (Gini Coefficient)

어떤 사회의 하위 $100x\%$의 인구가 전체 소득의 $100y\%$를 차지할 때, $x$와 $y$의 관계를 나타낸 곡선을 로렌츠 곡선 $y = L(x)$라 합니다. 소득이 완전히 균등하다면 $y = x$가 되며, 불평등할수록 곡선은 아래로 더 깊게 처지게 됩니다.

완전 평등선 $y=x$와 로렌츠 곡선 $y=L(x)$ 사이의 불평등 면적 $A$
지니 계수 $G$의 수학적 정의 공식:
$$G = \frac{A}{1/2} = \mathbf{2\int_0^1 \{x - L(x)\}\,dx}$$

$0 \le G \le 1$ 범위를 가지며, 0에 가까울수록 평등한 사회, 1에 가까울수록 극단적으로 불평등한 사회를 뜻합니다.

07번 교과서 145쪽 / 탐구 문제

어떤 사회의 로렌츠 곡선이 $L(x) = \frac{3}{4}x^2 + \frac{1}{4}x$일 때, 이 사회의 지니 계수 $G$를 구하시오.

✏️ 07번 G = 2∫[x - L(x)]dx 적분 계산 연습장
[정답 및 해설] $x - L(x) = x - \left(\frac{3}{4}x^2 + \frac{1}{4}x\right) = \frac{3}{4}x - \frac{3}{4}x^2 = \frac{3}{4}(x - x^2)$.
$G = 2\int_0^1 \frac{3}{4}(x - x^2)\,dx = \frac{3}{2}\left[\frac{1}{2}x^2 - \frac{1}{3}x^3\right]_0^1 = \frac{3}{2}\left(\frac{1}{2} - \frac{1}{3}\right) = \frac{3}{2}\left(\frac{1}{6}\right) = \mathbf{\frac{1}{4}}$ (또는 $\mathbf{0.25}$) 입니다.
08번 심화 / 삼차 로렌츠 곡선 지니 계수

어떤 가상의 사회의 로렌츠 곡선이 $L(x) = x^3$ ($0 \le x \le 1$)로 주어질 때, 이 사회의 지니 계수 $G$를 구하시오.

✏️ 08번 삼차함수 지니 계수 적분 연습장
[정답 및 해설] $G = 2\int_0^1 (x - x^3)\,dx = 2\left[\frac{1}{2}x^2 - \frac{1}{4}x^4\right]_0^1 = 2\left(\frac{1}{2} - \frac{1}{4}\right) = 2\left(\frac{1}{4}\right) = \mathbf{\frac{1}{2}}$ (또는 $\mathbf{0.5}$) 입니다.
