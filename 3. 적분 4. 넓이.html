04. 곡선과 도형의 넓이

정적분의 부호($\pm$)를 기하학적 크기로 해석하고, 두 곡선으로 둘러싸인 면적을 $\int_a^b (\text{위쪽} - \text{아래쪽})\,dx$의 원리로 정복합니다. 이차함수 공식 꿀팁과 소득 불평등 지표인 지니 계수까지 실생활 적분의 힘을 탐구해 봅시다.

1. 곡선과 $x$축 사이의 넓이

교과서 138~140쪽 · 정적분의 부호와 넓이 공식, $S = \int_a^b |f(x)|\,dx$의 원리

생각 열기: 정적분은 음수가 나올 수 있지만, 넓이는 항상 양수다!

닫힌구간 $[0, 1]$에서 두 함수 $y=x^2$과 $y=-x^2$의 정적분을 구해 봅시다:

• $x$축 위쪽: $\int_0^1 x^2\,dx = \left[\frac{1}{3}x^3\right]_0^1 = \mathbf{+\frac{1}{3}}$ (정적분 양수)
• $x$축 아래쪽: $\int_0^1 (-x^2)\,dx = \left[-\frac{1}{3}x^3\right]_0^1 = \mathbf{-\frac{1}{3}}$ (정적분 음수)

💡 기하학적 넓이는 크기(크기 $\ge 0$)이므로 음수가 될 수 없습니다!
따라서 $x$축 아래쪽에 있는 영역은 함수에 마이너스 부호($-$)를 붙여 양수로 바꾸어 적분해야 합니다.

대칭성과 넓이의 관계 대칭 곡선
$S_1 = \int_0^1 x^2\,dx = \frac{1}{3}$,   $S_2 = -\int_0^1 (-x^2)\,dx = \frac{1}{3}$ (넓이는 동일!)

곡선과 $x$축 사이의 넓이 공식

기본 정리 (교과서 139쪽)
$$S = \int_a^b |f(x)|\,dx$$

함수 $f(x)$가 닫힌구간 $[a, b]$에서 연속일 때, 곡선과 $x$축 및 두 직선 $x=a, x=b$로 둘러싸인 넓이

(i) 항상 위쪽 $f(x) \ge 0$

구간 전체에서 함숫값이 $0$ 이상이므로 정적분 값이 곧 넓이입니다.

$$S = \int_a^b f(x)\,dx$$
(ii) 항상 아래쪽 $f(x) \le 0$

구간 전체에서 음수이므로 마이너스 부호를 붙여 양수로 전환합니다.

$$S = -\int_a^b f(x)\,dx = \int_a^b \{-f(x)\}\,dx$$
(iii) 부호 교차 교점 $x=c$

$x$축과의 교점 $c$를 찾아 양수 구간과 음수 구간으로 분할 적분합니다.

$$S = \int_a^c f(x)\,dx + \int_c^b \{-f(x)\}\,dx$$
수능·내신 계산 시간 90% 단축! 포물선과 $x$축 사이의 넓이 공식

이차곡선 $y = a(x-\alpha)(x-\beta)$와 $x$축의 두 교점이 $\alpha, \beta$일 때, 둘러싸인 넓이는 복잡한 부정적분 계산 없이 공식으로 즉시 구합니다:

$$S = \frac{|a|}{6}(\beta - \alpha)^3$$

• 증명: $\int_\alpha^\beta -a(x-\alpha)(x-\beta)\,dx = \frac{|a|}{6}(\beta-\alpha)^3$ (예제 1, 문제 1에서 바로 적용 가능!)

인터랙티브 실험실: $y = x^2 - 2x$ 정적분 vs 실제 넓이 탐구

실시간 계산기

구간의 끝값 $b$ 슬라이더를 움직여 보세요. 정적분 값(알짜 면적)과 실제 넓이 $S = \int_0^b |x^2-2x|\,dx$가 어떻게 갈라지는지 눈으로 직접 확인합니다.

적분 구간: $[0, b]$
정적분 $\int_0^b f(x)\,dx$: -1.33 실제 넓이 $S$: 1.33
구간 끝점 $b$: 2.00

예제 1

포물선과 $x$축 사이의 넓이 구하기

곡선 $y = -x^2 + 2x$와 $x$축으로 둘러싸인 도형의 넓이를 구하시오.

직접 계산해 보기:
단계별 상세 풀이

1단계 (교점 찾기): 곡선과 $x$축의 교점의 $x$좌표는 방정식 $-x^2 + 2x = 0$의 해이므로

$$-x(x - 2) = 0 \implies x = 0 \text{ 또는 } x = 2$$

2단계 (함수 부호 판별): 닫힌구간 $[0, 2]$에서 $-x^2 + 2x \ge 0$이므로 곡선이 $x$축 위쪽에 있습니다.

3단계 (정적분 계산): 따라서 구하는 넓이 $S$는

$$S = \int_0^2 (-x^2 + 2x)\,dx = \left[-\frac{1}{3}x^3 + x^2\right]_0^2 = -\frac{8}{3} + 4 = \mathbf{\frac{4}{3}}$$
⚡ 공식 검산: $a = -1, \alpha = 0, \beta = 2$이므로 $S = \frac{|-1|}{6}(2 - 0)^3 = \frac{8}{6} = \mathbf{\frac{4}{3}}$ (100% 일치!)
문제 1

다음 곡선과 $x$축으로 둘러싸인 도형의 넓이를 구하시오.

⑴ $y = -x^2 + 4$
답:
[단계별 해설]
• 교점: $-x^2+4 = 0 \implies x = \pm 2$. 구간 $[-2, 2]$에서 $-x^2+4 \ge 0$.
• 우함수 성질 활용: $S = \int_{-2}^2 (-x^2+4)\,dx = 2\int_0^2 (-x^2+4)\,dx = 2\left[-\frac{1}{3}x^3 + 4x\right]_0^2 = 2\left(-\frac{8}{3} + 8\right) = \mathbf{\frac{16}{3}}$
• 공식 적용: $S = \frac{1}{6}(2 - (-2))^3 = \frac{64}{6} = \mathbf{\frac{16}{3}}$
⑵ $y = x^2 - 3x + 2$
답:
[단계별 해설]
• 교점: $x^2-3x+2 = (x-1)(x-2) = 0 \implies x = 1, 2$.
• 닫힌구간 $[1, 2]$에서 곡선이 $x$축 아래에 있으므로 ($f(x) \le 0$):
$$S = \int_1^2 -(x^2-3x+2)\,dx = \left[-\frac{1}{3}x^3 + \frac{3}{2}x^2 - 2x\right]_1^2 = \mathbf{\frac{1}{6}}$$
• 공식 적용: $S = \frac{1}{6}(2 - 1)^3 = \mathbf{\frac{1}{6}}$
예제 2

부호가 바뀌는 곡선과 $x$축 사이의 넓이

곡선 $y = x^2 - x - 2$와 $x$축 및 두 직선 $x=0, x=3$으로 둘러싸인 도형의 넓이를 구하시오.

직접 구해 보기:
단계별 상세 풀이

1단계 (교점과 부호 확인): $x^2 - x - 2 = (x+1)(x-2) = 0 \implies x = -1 \text{ 또는 } x = 2$.

구간 $[0, 3]$ 사이에 교점 $x=2$가 포함되므로:

• $[0, 2]$에서 $f(x) \le 0$  |  • $[2, 3]$에서 $f(x) \ge 0$

2단계 (구간 분할 적분):

$$S = \int_0^2 -(x^2-x-2)\,dx + \int_2^3 (x^2-x-2)\,dx$$
$$= \left[-\frac{1}{3}x^3 + \frac{1}{2}x^2 + 2x\right]_0^2 + \left[\frac{1}{3}x^3 - \frac{1}{2}x^2 - 2x\right]_2^3$$
$$= \left(-\frac{8}{3} + 2 + 4\right) + \left\{\left(9 - \frac{9}{2} - 6\right) - \left(\frac{8}{3} - 2 - 4\right)\right\} = \frac{10}{3} + \frac{11}{6} = \mathbf{\frac{31}{6}}$$

답: $\mathbf{\frac{31}{6}}$

다음 도형의 넓이를 구하시오.

⑴ 곡선 $y = x^2 + 2x + 1$과 $x$축 및 두 직선 $x=0, x=3$으로 둘러싸인 도형
답:
[단계별 해설]
• $y = (x+1)^2 \ge 0$이므로 닫힌구간 $[0, 3]$ 전체에서 항상 $x$축 위쪽에 있습니다.
$$S = \int_0^3 (x^2+2x+1)\,dx = \left[\frac{1}{3}x^3 + x^2 + x\right]_0^3 = (9 + 9 + 3) - 0 = \mathbf{21}$$
⑵ 곡선 $y = x^2 - 4x - 2$와 $x$축 및 두 직선 $x=1, x=2$로 둘러싸인 도형
답:
[단계별 해설]
• 닫힌구간 $[1, 2]$에서 $f(1) = 1 - 4 - 2 = -5 < 0$, $f(2) = 4 - 8 - 2 = -6 < 0$이므로 항상 $x$축 아래쪽($f(x) \le 0$)입니다.
$$S = \int_1^2 -(x^2-4x-2)\,dx = \left[-\frac{1}{3}x^3 + 2x^2 + 2x\right]_1^2 = \left(-\frac{8}{3} + 8 + 4\right) - \left(-\frac{1}{3} + 2 + 2\right) = \frac{28}{3} - \frac{11}{3} = \mathbf{\frac{17}{3}}$$

2. 두 곡선 사이의 넓이

교과서 141~143쪽 · 교점 구하기와 위쪽$-$아래쪽 적분 원리, 삼차함수와 접선의 넓이

원리 탐구: 곡선의 위치에 상관없이 항상 '위쪽 함수 $-$ 아래쪽 함수'!

닫힌구간 $[a, b]$에서 연속인 두 함수 $f(x), g(x)$에 대해 $f(x) \ge g(x)$일 때:

1. $g(x) \ge 0$일 때: $S = \int_a^b f(x)\,dx - \int_a^b g(x)\,dx$
2. $g(x) < 0$일 때: 두 곡선을 $y$축 방향으로 $+k$만큼 들어 올려도 둘러싸인 면적은 불변!
$$S = \int_a^b \{(f(x)+k) - (g(x)+k)\}\,dx = \int_a^b \{f(x) - g(x)\}\,dx$$

💡 핵심 요약: 두 곡선이 $x$축 위쪽에 있든 아래쪽에 있든 상관없이, 언제나 $\int_a^b (\text{위쪽 함수} - \text{아래쪽 함수})\,dx$ 하나로 모두 해결됩니다!

두 곡선 사이의 영역 S = ∫ (f - g) dx
$$S = \int_a^b |f(x) - g(x)|\,dx$$

인터랙티브 실험실: 포물선 $y = -x^2+2x$와 직선 $y = mx$ 사이의 넓이

실시간 면적 계산

직선의 기울기 $m$을 조절해 보세요. 포물선과 직선이 만나는 두 교점 $\alpha, \beta$가 자동으로 계산되고, 둘러싸인 넓이 $S = \frac{1}{6}(\beta-\alpha)^3$가 실시간으로 색칠되어 표시됩니다.

기울기: m = -1.0
교점: x = 0, 3 둘러싸인 넓이 $S$: 4.50 (9/2)
직선의 기울기 $m$: -1.00
포물선 $y=-x^2+2x$와 직선 $y=mx$ 사이 둘러싸인 넓이
예제 3

곡선과 직선 사이의 넓이 구하기

곡선 $y = -x^2 + 2x$와 직선 $y = -x$로 둘러싸인 도형의 넓이를 구하시오.

직접 구해 보기:
단계별 상세 풀이

1단계 (교점 찾기): 곡선과 직선의 교점의 $x$좌표는 $-x^2+2x = -x$의 해입니다:

$$x^2 - 3x = 0 \implies x(x - 3) = 0 \implies x = 0 \text{ 또는 } x = 3$$

2단계 (상하 위치 판별): 닫힌구간 $[0, 3]$에서 곡선이 직선보다 위쪽에 있습니다: $-x^2+2x \ge -x$.

3단계 (정적분 계산):

$$S = \int_0^3 \{(-x^2+2x) - (-x)\}\,dx = \int_0^3 (-x^2+3x)\,dx$$
$$= \left[-\frac{1}{3}x^3 + \frac{3}{2}x^2\right]_0^3 = -9 + \frac{27}{2} = \mathbf{\frac{9}{2}}$$
⚡ 공식 꿀팁: 포물선과 직선이 만나 생기는 넓이도 동일하게 적용됩니다:
$$S = \frac{|a|}{6}(\beta - \alpha)^3 = \frac{1}{6}(3 - 0)^3 = \frac{27}{6} = \mathbf{\frac{9}{2}}$$
문제 3

다음 곡선과 직선 또는 두 곡선으로 둘러싸인 도형의 넓이를 구하시오.

⑴ $y = x^2 - 2x$ 와 $y = -x^2 + 4$
답:
[단계별 해설]
• 교점: $x^2-2x = -x^2+4 \implies 2x^2-2x-4 = 2(x+1)(x-2) = 0 \implies x = -1, 2$.
• $[-1, 2]$에서 위쪽: $-x^2+4$, 아래쪽: $x^2-2x$.
$$S = \int_{-1}^2 \{(-x^2+4) - (x^2-2x)\}\,dx = \int_{-1}^2 (-2x^2+2x+4)\,dx = 2 \cdot \frac{1}{6}(2 - (-1))^3 = 2 \cdot \frac{27}{6} = \mathbf{9}$$
⑵ $y = x^3 - 3x$ 와 $y = x$
답:
[단계별 해설]
• 교점: $x^3-3x = x \implies x^3-4x = x(x+2)(x-2) = 0 \implies x = -2, 0, 2$.
• 원점 대칭인 두 영역의 넓이는 서로 같으므로 2배를 계산합니다:
$$S = 2\int_0^2 \{x - (x^3-3x)\}\,dx = 2\int_0^2 (-x^3+4x)\,dx = 2\left[-\frac{1}{4}x^4 + 2x^2\right]_0^2 = 2(-4 + 8) = \mathbf{8}$$
예제 4

삼차곡선과 이차곡선 사이의 넓이

곡선 $y = x^3 - x$와 곡선 $y = x^2 + x$로 둘러싸인 도형의 넓이를 구하시오.

직접 계산해 보기:
단계별 상세 풀이

1단계 (교점 찾기): $x^3 - x = x^2 + x \implies x^3 - x^2 - 2x = 0$

$$x(x + 1)(x - 2) = 0 \implies x = -1, 0, 2$$

2단계 (상하 위치 판별):

• 닫힌구간 $[-1, 0]$: 삼차곡선이 위쪽 ($x^3-x \ge x^2+x$)

• 닫힌구간 $[0, 2]$: 이차곡선이 위쪽 ($x^2+x \ge x^3-x$)

3단계 (2구간 분할 적분):

$$S_1 = \int_{-1}^0 (x^3-x^2-2x)\,dx = \left[\frac{1}{4}x^4 - \frac{1}{3}x^3 - x^2\right]_{-1}^0 = 0 - \left(\frac{1}{4} + \frac{1}{3} - 1\right) = \frac{5}{12}$$
$$S_2 = \int_0^2 (-x^3+x^2+2x)\,dx = \left[-\frac{1}{4}x^4 + \frac{1}{3}x^3 + x^2\right]_0^2 = -4 + \frac{8}{3} + 4 = \frac{8}{3} = \frac{32}{12}$$
$$S = S_1 + S_2 = \frac{5}{12} + \frac{32}{12} = \mathbf{\frac{37}{12}}$$
문제 4

곡선 $y = x^3 - 2x^2 - x + 2$와 직선 $y = -x + 2$로 둘러싸인 도형의 넓이

답:
[단계별 상세 해설]
• 교점: $x^3-2x^2-x+2 = -x+2 \implies x^3-2x^2 = 0 \implies x^2(x-2) = 0$.
• $x=0$에서 접하고(중근), $x=2$에서 교차합니다. 닫힌구간 $[0, 2]$에서 직선이 곡선 위쪽에 있습니다.
$$S = \int_0^2 \{(-x+2) - (x^3-2x^2-x+2)\}\,dx = \int_0^2 (-x^3+2x^2)\,dx = \left[-\frac{1}{4}x^4 + \frac{2}{3}x^3\right]_0^2 = -4 + \frac{16}{3} = \mathbf{\frac{4}{3}}$$
⚡ 삼차곡선과 접선 공식: $S = \frac{|a|}{12}(\beta - \alpha)^4 = \frac{1}{12}(2 - 0)^4 = \frac{16}{12} = \mathbf{\frac{4}{3}}$ (즉시 검산!)

한 변의 길이가 $60\,\text{cm}$인 정사각형 모양의 타일 3장이 나란히 붙어 있습니다. 3장의 타일에는 각각 평행사변형 2개를 붙인 무늬, 직사각형 무늬, 폭이 일정한 물결 모양 무늬가 그려져 있습니다. 3장의 타일에 그려진 무늬의 가로 폭이 항상 일정할 때, 무늬 넓이의 합을 구해 봅시다.

[수학적 논증 및 해설]
• 카발리에리의 원리(Cavalieri's Principle): 두 평면도형을 평행선으로 잘랐을 때 생기는 선분의 길이가 항상 같으면, 두 도형의 넓이는 서로 같습니다.
• 3장의 타일 무늬는 임의의 높이 $y$에서 자른 가로 선분의 길이(폭)가 모두 같으므로, 곡선 모양이 물결치더라도 넓이는 단순 직사각형 무늬의 넓이와 완벽히 같습니다!
• 따라서 무늬의 넓이는 높이와 폭의 곱(정적분 $\int_0^{60} w(y)\,dy$)으로 간단히 계산할 수 있습니다.
47차시

스스로 확인하기 (01~05)

교과서 144쪽 · 성취 기준 달성도 점검 및 전 문항 단계별 상세 토글 해설

01

학습 목표 되새기기 (넓이 기본 공식)

두 함수 $f(x), g(x)$가 닫힌구간 $[a, b]$에서 연속일 때, 다음 빈칸에 알맞은 식을 채워 넣으시오.

⑴ 곡선 $y=f(x)$와 $x$축 및 $x=a, x=b$ 사이 넓이: $S = \int_a^b$ $dx$
⑵ 두 곡선 $y=f(x), y=g(x)$ 및 $x=a, x=b$ 사이 넓이: $S = \int_a^b$ $dx$
[정답 및 해설]
• ⑴ $|f(x)|$  |  ⑵ $|f(x) - g(x)|$
넓이는 부호가 항상 양수이어야 하므로 피적분함수에 절댓값을 씌워 표현합니다.
02

곡선과 $x$축 사이의 넓이

곡선 $y = x^2 - 5x + 4$와 $x$축으로 둘러싸인 도형의 넓이를 구하시오.

답:
[단계별 상세 해설]
• 1단계 (교점): $x^2 - 5x + 4 = (x - 1)(x - 4) = 0 \implies x = 1 \text{ 또는 } x = 4$.
• 2단계 (부호): 닫힌구간 $[1, 4]$에서 곡선이 $x$축 아래에 있으므로 ($f(x) \le 0$):
$$S = \int_1^4 -(x^2-5x+4)\,dx = \left[-\frac{1}{3}x^3 + \frac{5}{2}x^2 - 4x\right]_1^4 = \left(-\frac{64}{3} + 40 - 16\right) - \left(-\frac{1}{3} + \frac{5}{2} - 4\right) = \mathbf{\frac{9}{2}}$$
• 공식 적용: $S = \frac{1}{6}(4 - 1)^3 = \frac{27}{6} = \mathbf{\frac{9}{2}}$ (답: $\mathbf{\frac{9}{2}}$)
03

곡선과 직선 사이의 넓이

곡선 $y = -x^2 + 3x$와 직선 $y = x$로 둘러싸인 도형의 넓이를 구하시오.

답:
[단계별 상세 해설]
• 1단계 (교점): $-x^2 + 3x = x \implies x^2 - 2x = x(x - 2) = 0 \implies x = 0, 2$.
• 2단계 (위치 판별): 닫힌구간 $[0, 2]$에서 포물선이 직선 위쪽에 있습니다.
$$S = \int_0^2 \{(-x^2+3x) - x\}\,dx = \int_0^2 (-x^2+2x)\,dx = \left[-\frac{1}{3}x^3 + x^2\right]_0^2 = -\frac{8}{3} + 4 = \mathbf{\frac{4}{3}}$$
• 공식 적용: $S = \frac{1}{6}(2 - 0)^3 = \frac{8}{6} = \mathbf{\frac{4}{3}}$ (답: $\mathbf{\frac{4}{3}}$)
04

삼차곡선과 이차곡선 사이의 넓이 (2구간 분할)

두 곡선 $y = x^3 - 3x^2$과 $y = -x^2 + 3x$로 둘러싸인 도형의 넓이를 구하시오.

답:
[단계별 상세 해설]
• 1단계 (교점): $x^3 - 3x^2 = -x^2 + 3x \implies x^3 - 2x^2 - 3x = x(x+1)(x-3) = 0 \implies x = -1, 0, 3$.
• 2단계 (구간 분할):
• $[-1, 0]$: 삼차곡선 위 $\to S_1 = \int_{-1}^0 (x^3-2x^2-3x)\,dx = \left[\frac{1}{4}x^4-\frac{2}{3}x^3-\frac{3}{2}x^2\right]_{-1}^0 = \frac{7}{12}$
• $[0, 3]$: 이차곡선 위 $\to S_2 = \int_0^3 (-x^3+2x^2+3x)\,dx = \left[-\frac{1}{4}x^4+\frac{2}{3}x^3+\frac{3}{2}x^2\right]_0^3 = \frac{45}{4} = \frac{135}{12}$
$$S = S_1 + S_2 = \frac{7}{12} + \frac{135}{12} = \frac{142}{12} = \mathbf{\frac{71}{6}}$$

답: $\mathbf{\frac{71}{6}}$

05

발전 문제: 직선에 의한 넓이의 이등분

곡선 $y = -x^2 + 4x$와 $x$축으로 둘러싸인 도형의 넓이를 원점을 지나는 직선 $y = ax$ ($0 < a < 4$)가 이등분할 때, $(4 - a)^3$의 값을 구하시오.

답:
[단계별 심화 해설]
• 1단계 (전체 넓이 $S_0$): 곡선과 $x$축의 교점은 $x = 0, 4$이므로 $$S_0 = \frac{1}{6}(4 - 0)^3 = \frac{64}{6} = \frac{32}{3}$$
• 2단계 (곡선과 직선 $y=ax$ 사이 넓이 $S_1$): $$-x^2 + 4x = ax \implies x^2 + (a - 4)x = 0 \implies x\{x - (4 - a)\} = 0$$ 두 교점은 $x = 0$과 $x = 4 - a$입니다.
• 3단계 (공식 적용): 직선 위쪽 포물선과의 둘러싸인 넓이는 $$S_1 = \frac{1}{6}\{(4 - a) - 0\}^3 = \frac{1}{6}(4 - a)^3$$
• 4단계 (이등분 조건): $S_1 = \frac{1}{2}S_0$이어야 하므로 $$\frac{1}{6}(4 - a)^3 = \frac{1}{2} \times \frac{32}{3} = \frac{16}{3} \implies (4 - a)^3 = \mathbf{32}$$

답: $\mathbf{32}$

수학으로 세상 보기: 소득 분배의 평등을 측정하는 지니 계수

교과서 145쪽 · 정적분으로 계산하는 로렌츠 곡선과 국가 소득 불평등 지표

로렌츠 곡선과 지니 계수(Gini Coefficient)의 수학적 원리

로렌츠 곡선 $y = L(x)$는 인구 누적 비율 $x$ ($0 \le x \le 1$)에 대한 소득 누적 비율 $y$를 나타내는 곡선입니다.

• 완전 평등선 ($y = x$): 모든 사람이 똑같이 분배받을 때의 직선
• 불평등 영역 면적 $A$: 직선 $y = x$와 로렌츠 곡선 $y = L(x)$ 사이의 넓이
• 삼각형 $OBC$ 전체 넓이: $\frac{1}{2} \times 1 \times 1 = \mathbf{\frac{1}{2}}$
$$G = \frac{A}{A + B} = \frac{A}{1/2} = 2A = 2\int_0^1 (x - L(x))\,dx$$

• $G = 0$에 가까울수록 완전 평등, $G = 1$에 가까울수록 완전 불평등을 나타냅니다.

인터랙티브 로렌츠 곡선: $L(x) = x^k$ Gini: 0.33
불평등 지수 파라미터 $k$: k = 2.0
