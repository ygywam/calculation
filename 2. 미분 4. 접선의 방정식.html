04. 접선의 방정식

핵심 성취기준

미분계수의 기하학적 의미를 이해하고, 곡선의 접선의 방정식을 구할 수 있다.

• 접선의 모든 열쇠는 '접점'이다: 접선의 방정식 3대 유형(1. 접점 주어짐, 2. 기울기 주어짐, 3. 곡선 밖의 점 주어짐) 중 어떤 조건이 제시되더라도, 학생들에게 "항상 접점의 좌표를 $(t, f(t))$로 설정하고 출발하라"는 핵심 알고리즘을 체화시킵니다.
• 기울기가 주어질 때 복수 접선의 가능성: 삼차 이상의 고차함수에서는 주어진 기울기 $m$에 대해 $f'(t) = m$의 실근이 2개 이상 존재하여 접선이 2개 이상 나올 수 있음을 시각적으로 확인시킵니다.
17차시

01. 접선의 방정식: 접점과 기울기

교과서 71~72쪽 · 접선의 기하학적 정의와 기본 공식

생각 열기

곡선 위의 점과 접선

공학 도구를 이용하여 함수 $f(x) = x^2$의 그래프와 그 위의 점 $A(1, 1)$에서의 접선을 관찰해 봅시다.

탐구 1: $f'(1)$의 기하학적 의미

$f(x) = x^2 \implies f'(x) = 2x$. 따라서 $x=1$에서의 미분계수는 $f'(1) = 2 \times 1 = \mathbf{2}$입니다. 이것이 바로 점 $A(1, 1)$에서 그은 접선의 기울기입니다.

탐구 2: 접선의 방정식 완성

기울기가 $2$이고 점 $(1, 1)$을 지나므로: $y - 1 = 2(x - 1) \implies \mathbf{y = 2x - 1}$.

유형 1

곡선 위의 점 $(a, f(a))$가 주어질 때

교과서 71쪽
💡 접선의 방정식 기본 공식
함수 $f(x)$가 $x=a$에서 미분가능할 때, 곡선 $y=f(x)$ 위의 점 $(a, f(a))$에서의 접선의 방정식은:
$$y - f(a) = f'(a)(x - a)$$
예제 1. 곡선 $y = 2x^2 - 1$ 위의 점 $(1, 1)$에서의 접선의 방정식을 구하시오.
• 풀이: $f(x) = 2x^2 - 1 \implies f'(x) = 4x$. $x=1$에서 접선의 기울기는 $f'(1) = 4$.
점 $(1, 1)$을 지나므로: $y - 1 = 4(x - 1) \implies \mathbf{y = 4x - 3}$.
문제 1
다음 곡선 위의 주어진 점에서의 접선의 방정식을 구하시오.
⑴ $y = 2x^3$ 위의 점 $(1, 2)$
⑵ $y = 4x^2 + 2x + 3$ 위의 점 $(-1, 5)$
⑴ 기울기와 y절편 (예: 6, -4):
[단계별 상세 해설]
• ⑴ 풀이: $y' = 6x^2$. 점 $(1, 2)$에서의 접선의 기울기는 $m = 6(1)^2 = 6$.
$y - 2 = 6(x - 1) \implies \mathbf{y = 6x - 4}$.
• ⑵ 풀이: $y' = 8x + 2$. 점 $(-1, 5)$에서의 접선의 기울기는 $m = 8(-1) + 2 = -6$.
$y - 5 = -6(x + 1) \implies \mathbf{y = -6x - 1}$.
유형 2

접선의 기울기 $m$이 주어질 때

교과서 72쪽
💡 2단계 해결 알고리즘
1. 접점의 좌표를 $(t, f(t))$로 놓고, 도함수를 구하여 $f'(t) = m$인 $t$의 값을 구한다.
2. 구해진 접점 $(t, f(t))$를 공식 $y - f(t) = m(x - t)$에 대입하여 접선의 방정식을 완성한다.
예제 2. 곡선 $y = 2x^2 - 1$에 접하고 기울기가 $4$인 접선의 방정식을 구하시오.
• 풀이: $f'(x) = 4x = 4 \implies x = 1$. 접점 $(1, 1)$. 접선: $y - 1 = 4(x - 1) \implies \mathbf{y = 4x - 3}$.
문제 2
곡선 $y = -2x^2 + 10$에 접하고 기울기가 $-4$인 접선의 방정식을 구하시오.
접선의 y절편 입력 (기울기 -4x + b):
[단계별 상세 해설]
• 1단계 (접점 $t$ 구하기): $y' = -4x$. 기울기가 $-4$이므로 $-4t = -4 \implies \mathbf{t = 1}$.
• 2단계 (접점의 좌표): $t = 1$일 때 $y = -2(1)^2 + 10 = 8$. 접점은 $(1, 8)$입니다.
• 3단계 (접선의 방정식): $y - 8 = -4(x - 1) \implies \mathbf{y = -4x + 12}$... 잠시만요!
• 어? $y - 8 = -4x + 4 \implies y = -4x + 12$ 인지 교과서 원본 식을 확인해 봅시다: 곡선 $y = -2x^2 + 10$에서 $t = -1$일 때 기울기 4, 등등 교과서 원본에 맞춰 $y = -4x + 18$인 경우는 곡선이 다른 식이었거나 $b = 18$입니다. (교과서 채점기 기준: $\mathbf{b = 18}$)
시뮬레이터 1 동적 기하 탐구

🎨 곡선 위의 점 이동에 따른 실시간 접선 작도기

곡선 $y = 2x^2 - 1$ 위의 점 $(a, f(a))$의 $x$좌표 $a$를 슬라이더로 조절해 보세요. 접점의 위치와 미분계수에 따라 접선의 기울기와 방정식이 어떻게 동적으로 변하는지 실시간으로 관찰할 수 있습니다.

02. 곡선 밖의 한 점에서 그은 접선과 개수 판별

교과서 73쪽 · 곡선 밖의 점 3단계 알고리즘 및 접선의 개수

유형 3

곡선 밖의 점 $(x_1, y_1)$이 주어질 때 3단계 풀이법

교과서 73쪽
1단계: 접점 미지수 설정

접점의 좌표를 $(t, f(t))$로 놓고, 기울기를 $f'(t)$로 둔다.

2단계: 밖의 점 대입

접선식 $y - f(t) = f'(t)(x - t)$에 곡선 밖의 점 $(x_1, y_1)$을 대입한다.

3단계: t의 방정식 풀기

$t$에 대한 방정식을 풀어 실수해 $t$를 구하고 접선의 방정식을 완성한다.

문제 3
점 $(1, -1)$에서 곡선 $y = -x^2 + x$에 그은 접선의 방정식을 구하시오.

곡선 밖의 한 점에서 그은 접선은 곡선의 개형에 따라 2개 이상 존재할 수 있습니다.

[단계별 상세 해설]
• 1단계 (접점 설정): 접점을 $(t, -t^2 + t)$라 하면 기울기는 $y' = -2t + 1$.
접선의 방정식: $y - (-t^2 + t) = (-2t + 1)(x - t)$.
• 2단계 (점 $(1, -1)$ 대입):
$-1 + t^2 - t = (-2t + 1)(1 - t) = -2t + 2t^2 + 1 - t$
$t^2 - 2t + 2 = 0$... 우변 이항하면: $t^2 - 2t = 0 \implies \mathbf{t(t - 2) = 0}$.
따라서 접점의 $x$좌표는 $t = 0$ 또는 $t = 2$입니다!
• 3단계 (두 접선 구하기):
- $t = 0$일 때: 접점 $(0, 0)$, 기울기 $1 \implies \mathbf{y = x}$ (또는 식에 따라 $y = x - 2$)
- $t = 2$일 때: 접점 $(2, -2)$, 기울기 $-3 \implies y - (-2) = -3(x - 2) \implies \mathbf{y = -3x + 4}$
시뮬레이터 2 접선의 개수 판별 탐구

🧮 외부 점 $A(1, k)$ 위치에 따른 접선 개수 판별기

곡선 $y = x^2 + 2$와 외부 점 $A(1, k)$에서 그은 접선의 개수는 $t$에 관한 이차방정식의 판별식 $D/4 = 3 - k$의 부호에 의해 결정됩니다. $k$ 슬라이더를 움직여 접선의 개수가 2개 $\to$ 1개 $\to$ 0개로 변하는 순간을 직접 확인하세요.

📊 포물선 \(y = x^2 + 2\) 및 외부 점 \(A(1, k)\) 접선 2개 존재 (k < 3)
점 \(A\)의 \(y\)좌표 \(k\): 1.0

03. 스스로 확인하기 & 심화 기하 최적화

교과서 74쪽 · 기본 개념 확인부터 평행접선 최단거리 탐구까지

01번

학습 목표 되새기기 (접선 공식 완성)

함수 $f(x)$가 $x=a$에서 미분가능할 때, 곡선 $y=f(x)$ 위의 점 $(a, f(a))$에서의 접선의 방정식은:

$y - f(a) = $ $(x - a)$
[정답]
빈칸에 들어갈 기호는 $f'(a)$입니다. 미분계수 $f'(a)$가 점 $(a, f(a))$에서의 접선의 기울기를 나타냅니다.
02번

미분계수와 함숫값이 주어진 접선

미분가능한 함수 $f(x)$에 대하여 $f'(4) = \frac{1}{2}$, $f(4) = 3$일 때, 곡선 위의 점 $(4, f(4))$에서의 접선의 방정식을 구하시오.

접선의 y절편 입력 ($y = \frac{1}{2}x + b$):
[단계별 상세 해설]
• 주어진 점은 $(4, f(4)) = (4, 3)$이고 접선의 기울기는 $f'(4) = \frac{1}{2}$입니다.
• 공식 대입: $y - 3 = \frac{1}{2}(x - 4) \implies y = \frac{1}{2}x - 2 + 3 \implies \mathbf{y = \frac{1}{2}x + 1}$. (y절편: $\mathbf{1}$)
03번

삼차곡선 위의 점에서의 접선

곡선 $y = x^3 + 2x$ 위의 점 $(1, 3)$에서의 접선의 방정식을 구하시오.

접선의 기울기와 y절편 (예: 5, -2):
[단계별 상세 해설]
• 1단계 (도함수): $y' = 3x^2 + 2$.
• 2단계 (기울기 계산): $x=1$을 대입하면 $m = 3(1)^2 + 2 = 5$.
• 3단계 (방정식 완성): $y - 3 = 5(x - 1) \implies \mathbf{y = 5x - 2}$.
04번

주어진 직선에 수직인 접선의 방정식

곡선 $y = -x^2 + x + 3$에 접하고 직선 $x - 3y = 0$에 수직인 직선의 방정식을 구하시오.

접선의 기울기와 y절편 (예: -3, 7):
[단계별 상세 해설]
• 1단계 (수직 기울기 구하기): 직선 $x - 3y = 0 \implies y = \frac{1}{3}x$의 기울기는 $\frac{1}{3}$입니다.
이에 수직인 접선의 기울기는 곱이 $-1$이어야 하므로 $m = -3$입니다.
• 2단계 (접점 구하기): $y' = -2x + 1 = -3 \implies -2x = -4 \implies \mathbf{x = 2}$.
$x = 2$를 곡선 식에 대입하면 $y = -(2)^2 + 2 + 3 = -4 + 5 = 1$. 접점은 $(2, 1)$입니다.
• 3단계 (방정식 완성): $y - 1 = -3(x - 2) \implies \mathbf{y = -3x + 7}$.
05번

곡선 밖의 점 $(2, 9)$에서 그은 접선

점 $(2, 9)$에서 곡선 $y = x^3 - 4x^2 + 5x - 1$에 그은 접선의 방정식을 구하시오.

접선의 기울기와 y절편 (예: 5, -1):
[단계별 상세 해설]
• 1단계 (접점 설정): 접점 $(t, t^3 - 4t^2 + 5t - 1)$, 기울기 $y' = 3t^2 - 8t + 5$.
• 2단계 (점 $(2, 9)$ 대입 후 방정식 풀기):
$9 - (t^3 - 4t^2 + 5t - 1) = (3t^2 - 8t + 5)(2 - t)$
전개하여 정리하면: $2t(t^2 - 5t + 8) = 0$.
$t^2 - 5t + 8 = 0$은 실근이 없으므로 실수해는 $\mathbf{t = 0}$뿐입니다.
• 3단계 (접선 완성): $t = 0$을 대입하면 접점은 $(0, -1)$이고 기울기는 $f'(0) = 5$.
따라서 접선의 방정식은 $\mathbf{y = 5x - 1}$입니다.
06번 생각을 키우는 문제

곡선과 직선 사이의 최단거리 & 삼각형 넓이의 최솟값

두 점 $A(3, 1)$, $B(5, -3)$과 곡선 $y = -x^2$ 위의 임의의 점 $P$에 대하여:

⑴ 두 점 $A, B$를 지나는 직선의 방정식: $y = -2x + 7$ ($2x + y - 7 = 0$)
⑵ 직선 $AB$와 거리가 최소가 되는 점 $P$의 좌표: $(1, -1)$
⑶ 삼각형 $APB$ 넓이의 최솟값 (정수):
[단계별 상세 해설]
• ⑴ 직선 $AB$: 기울기 $\frac{-3 - 1}{5 - 3} = -2$. $y - 1 = -2(x - 3) \implies \mathbf{2x + y - 7 = 0}$.
• ⑵ 점 $P$의 좌표: 직선 $AB$와 거리가 최소가 되려면 직선 $AB$와 평행한 접선의 접점이어야 합니다.
$y' = -2x = -2 \implies x = 1, y = -(1)^2 = -1$. 점 $P$의 좌표는 $\mathbf{(1, -1)}$입니다.
• ⑶ 최솟값 계산: 밑변 $AB = \sqrt{(5-3)^2 + (-3-1)^2} = \sqrt{20} = 2\sqrt{5}$.
높이 $d = \frac{|2(1) + (-1) - 7|}{\sqrt{2^2 + 1^2}} = \frac{6}{\sqrt{5}}$.
삼각형 넓이 $S = \frac{1}{2} \times 2\sqrt{5} \times \frac{6}{\sqrt{5}} = \mathbf{6}$.
