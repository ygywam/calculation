01. 접선의 방정식: 접점과 기울기 (Equation of Tangent Line)

미분계수의 기하학적 의미인 '접선의 기울기'를 고등학교 1학년의 직선의 방정식 공식과 융합하여, 곡선에 스치는 접선의 방정식을 구하는 핵심 3대 유형 중 [유형 1: 접점이 주어질 때]와 [유형 2: 기울기가 주어질 때]를 완벽히 정복합니다.

🎯 핵심 성취기준: 미분계수와 접선의 기울기의 관계를 이해하고, 접선의 방정식을 구할 수 있다.

• 접선의 모든 열쇠는 '접점'이다: 접선의 방정식의 3대 유형(1. 접점 주어짐, 2. 기울기 주어짐, 3. 곡선 밖의 점 주어짐) 중 어떤 조건이 제시되더라도, 학생들에게 "항상 접점의 좌표를 $(t, f(t))$로 설정하고 출발하라"는 핵심 알고리즘을 체화시킵니다.

• 기울기가 주어질 때 복수 접선의 가능성: 삼차 이상의 고차함수에서는 주어진 기울기 $m$에 대해 $f'(t) = m$의 실근이 2개 이상 존재하여 접선이 2개 이상 나올 수 있음을 시각적으로 확인시킵니다.

💡

생각 열기: 곡선 위의 점과 접선

다음 그림은 공학 도구를 이용하여 함수 \(f(x) = x^2\)의 그래프와 그 위의 점 \(A(1, 1)\)에서의 접선을 그린 것입니다.

탐구 ➊ \(f'(1)\)의 값

함수 \(f(x) = x^2\)을 미분하면 \(f'(x) = 2x\)이므로, \(x=1\)에서의 미분계수는:

\(f'(1) = 2 \times 1 = \mathbf{2}\)
탐구 ➋ 점 A에서의 접선의 방정식

점 \((1, 1)\)을 지나고 기울기가 \(2\)인 직선의 방정식:

\(y - 1 = 2(x - 1) \implies \mathbf{y = 2x - 1}\)
1

개념 정립: 접선의 방정식 공식

함수 \(f(x)\)가 \(x=a\)에서 미분가능할 때, 곡선 \(y=f(x)\) 위의 점 \(P(a, f(a))\)에서의 접선의 기울기는 \(x=a\)에서의 미분계수 \(f'(a)\)입니다. 따라서 점 \(P(a, f(a))\)를 지나고 기울기가 \(f'(a)\)인 직선의 방정식은 다음과 같습니다:

핵심 공식 교과서 71쪽

곡선 위의 점 \((a, f(a))\)에서의 접선의 방정식

\(y - f(a) = f'(a)(x - a)\)
💡 점 \((x_1, y_1)\)을 지나고 기울기가 \(m\)인 직선의 방정식 \(y - y_1 = m(x - x_1)\)에서 기울기 자리에 미분계수 \(f'(a)\)를 대입한 것입니다!
유형 1

곡선 위의 한 점에서의 접선의 방정식

교과서 72쪽 예제 1
곡선 \(y = x^2 + 2x\) 위의 점 \((-2, 0)\)에서의 접선의 방정식을 구하시오.
\(f(x) = x^2 + 2x\)라고 하면 \(f'(x) = 2x + 2\)
점 \((-2, 0)\)에서의 접선의 기울기는 \(f'(-2) = 2(-2) + 2 = \mathbf{-2}\)
따라서 구하는 접선의 방정식은:
\(y - 0 = -2\{x - (-2)\} \implies \mathbf{y = -2x - 4}\)
문제 1

다음 곡선 위의 주어진 점에서의 접선의 방정식을 구하시오.

⑴ \(y = 2x^3\) 위의 점 \((1, 2)\)
⑵ \(y = 4x^2 + 2x + 3\) 위의 점 \((-1, 5)\)
풀이 연습장
⑴ 정답: \(y' = 6x^2 \implies f'(1) = 6\), \(y - 2 = 6(x - 1) \implies \mathbf{y = 6x - 4}\)
⑵ 정답: \(y' = 8x + 2 \implies f'(-1) = -6\), \(y - 5 = -6(x + 1) \implies \mathbf{y = -6x - 1}\)
유형 2

기울기가 주어질 때의 접선의 방정식

교과서 72쪽 예제 2
곡선 \(y = 2x^2 - 1\)에 접하고 기울기가 \(4\)인 접선의 방정식을 구하시오.
\(f(x) = 2x^2 - 1\)이라고 하면 \(f'(x) = 4x\)
접점의 좌표를 \((a, 2a^2 - 1)\)이라고 하면, 이 접점에서의 접선의 기울기가 \(4\)이므로:
\(f'(a) = 4a = 4 \implies \mathbf{a = 1}\)
따라서 접점의 좌표는 \((1, 2(1)^2 - 1) = (1, 1)\)입니다.
구하는 접선의 방정식은 \(y - 1 = 4(x - 1) \implies \mathbf{y = 4x - 3}\)
문제 2

다음 곡선에 접하고 기울기가 \(-4\)인 접선의 방정식을 구하시오.

⑴ \(y = -2x^2 + 8x\)
⑵ \(y = -x^3 + 8x\)
접점 좌표 계산장
⑴ 풀이: \(y' = -4x + 8 = -4 \implies -4x = -12 \implies x = 3\). 접점 \((3, 6)\).
\(y - 6 = -4(x - 3) \implies \mathbf{y = -4x + 18}\)
⑵ 풀이 (접선 2개!): \(y' = -3x^2 + 8 = -4 \implies 3x^2 = 12 \implies x = \pm 2\)
• \(x = 2\): 접점 \((2, 8) \implies y - 8 = -4(x - 2) \implies \mathbf{y = -4x + 16}\)
• \(x = -2\): 접점 \((-2, -8) \implies y - (-8) = -4(x - (-2)) \implies \mathbf{y = -4x - 16}\)

02. 곡선 밖의 점에서 그은 접선과 접선의 개수 (Tangents from External Point)

곡선 위에 있지 않은 외부 점에서 곡선을 향해 쏘아 올린 접선을 구하는 가장 정교한 유형입니다. 미지수 접점 \(t\)를 설정하고 방정식을 풀어 접점의 개수와 접선의 개수가 완벽히 일치함을 대수적으로 증명합니다.

🎯 핵심 성취기준: 곡선 밖의 한 점에서 그은 접선의 방정식을 3단계로 구하고, 실근의 개수로 접선의 개수를 판별할 수 있다.
유형 3

곡선 밖의 한 점에서 그은 접선 3단계 풀이법

교과서 73쪽 예제 3
원점 \((0, 0)\)에서 곡선 \(y = x^2 + 4\)에 그은 접선의 방정식을 구하시오.
[단계 ➊] 접선의 식 세우기

접점을 \((a, a^2+4)\)라 하면 기울기 \(f'(a) = 2a\).
\(y - (a^2+4) = 2a(x - a)\)
\(\implies y = 2ax - a^2 + 4\) ⋯ ㉠

[단계 ➋] 외부 점 대입 & a 구하기

접선 ㉠이 원점 \((0, 0)\)을 지나므로:
\(0 = -a^2 + 4 \implies a^2 = 4\)
\(\mathbf{a = -2 \text{ 또는 } a = 2}\)

[단계 ➌] 접선의 방정식 완성

\(a\)의 값을 ㉠에 대입하면:
\(a = -2 \implies \mathbf{y = -4x}\)
\(a = 2 \implies \mathbf{y = 4x}\)

💡 시각적 통찰: 원점에서 포물선을 올려다보며 왼쪽과 오른쪽에 각각 1개씩 총 2개의 접선(\(\pm 4x\))이 대칭적으로 그어집니다!
문제 3

다음 주어진 점에서 곡선에 그은 접선의 방정식을 구하시오.

교과서 73쪽
⑴ \(y = x^2 + x\), 점 \((-1, -1)\)
⑵ \(y = -x^3 + 3x^2 - x - 1\), 점 \((1, -2)\)
외부 점 접선 계산장
접점 \((t, t^2+t)\), 접선 \(y = (2t+1)x - t^2\)
점 \((-1, -1)\) 대입: \(-1 = -(2t+1) - t^2 \implies t^2 + 2t = 0 \implies t = 0\text{ 또는 } -2\)
정답: \(\mathbf{y = x}\) 또는 \(\mathbf{y = -3x - 4}\)
접선에 \((1, -2)\) 대입하면 \(2t(t^2 - 3t + 3) = 0\). 이차식 판별식 \(D < 0\)이므로 실근은 \(t = 0\) 오직 하나!
\(t=0\) 대입: 기울기 \(-1\), 접점 \((0, -1)\)
정답: \(\mathbf{y = -x - 1}\)
문제해결 탐구

외부 점 A(1, k)에서 곡선에 그은 접선의 개수

교과서 73쪽

곡선 \(y = x^2 + 2\)와 점 \(A(1, k)\)에 대하여 점 \(A\)에서 곡선에 그을 수 있는 접선의 개수를 \(k\)의 값의 범위에 따라 분류해 봅시다.

1. 접점의 좌표를 \((t, t^2+2)\)라 하면 접선: \(y - (t^2+2) = 2t(x - t) \implies y = 2tx - t^2 + 2\)
2. 점 \(A(1, k)\) 대입: \(k = 2t - t^2 + 2 \implies \mathbf{t^2 - 2t + k - 2 = 0}\)
3. 판별식 \(D/4 = (-1)^2 - (k - 2) = \mathbf{3 - k}\)
\(k < 3\) 일 때
접선 2개 (D > 0)
\(k = 3\) 일 때
접선 1개 (D = 0, 곡선 위)
\(k > 3\) 일 때
접선 0개 (D < 0, 곡선 안쪽)

03. 스스로 확인하기 & 최단거리 기하 탐구

접선의 방정식의 3대 유형을 총망라하여 해결력을 다지고, 곡선과 직선 사이의 최단거리를 평행접선의 접점으로 파악하여 기하학적 도형의 넓이 최솟값을 구하는 심화 최적화 문제를 탐구합니다.

01

학습 목표 되새기기 (접선 공식 완성)

교과서 74쪽

함수 \(f(x)\)가 \(x=a\)에서 미분가능할 때, 곡선 \(y=f(x)\) 위의 점 \((a, f(a))\)에서의 접선의 방정식은:

\(y - f(a) = \) \((x - a)\)
02

미분계수와 함숫값이 주어진 접선

교과서 74쪽
미분가능한 함수 \(f(x)\)에 대하여 \(f'(4) = \frac{1}{2}\), \(f(4) = 3\)일 때, 곡선 위의 점 \((4, f(4))\)에서의 접선의 방정식을 구하시오.
\(y - 3 = \frac{1}{2}(x - 4) \implies y = \frac{1}{2}x - 2 + 3 \implies \mathbf{y = \frac{1}{2}x + 1}\)
03

삼차곡선 위의 점에서의 접선

교과서 74쪽
곡선 \(y = x^3 + 2x\) 위의 점 \((1, 3)\)에서의 접선의 방정식을 구하시오.
미분 및 접선 계산장
\(y' = 3x^2 + 2 \implies f'(1) = 3(1)^2 + 2 = 5\)
\(y - 3 = 5(x - 1) \implies \mathbf{y = 5x - 2}\)
04

주어진 직선에 수직인 접선의 방정식

교과서 74쪽
곡선 \(y = -x^2 + x + 3\)에 접하고 직선 \(x - 3y = 0\)에 수직인 직선의 방정식을 구하시오.
수직 기울기 & 접점 계산장
• 직선 \(x - 3y = 0 \iff y = \frac{1}{3}x\)이므로, 수직인 직선의 기울기는 \(m = \mathbf{-3}\)
• \(y' = -2x + 1 = -3 \implies -2x = -4 \implies \mathbf{x = 2}\)
• 접점: \((2, -(2)^2 + 2 + 3) = (2, 1)\)
\(y - 1 = -3(x - 2) \implies \mathbf{y = -3x + 7}\)
05

곡선 밖의 점 (2, 9)에서 그은 접선

교과서 74쪽
점 \((2, 9)\)에서 곡선 \(y = x^3 - 4x^2 + 5x - 1\)에 그은 접선의 방정식을 구하시오.
접점 방정식 풀이장
• 접점 \((t, t^3-4t^2+5t-1)\), 접선 \(y - (t^3-4t^2+5t-1) = (3t^2-8t+5)(x - t)\)
• 점 \((2, 9)\) 대입하여 정리하면 \(2t(t^2 - 5t + 8) = 0\)
• 이차식 판별식 \(D = 25 - 32 < 0\)이므로 유일한 실근은 \(\mathbf{t = 0}\)
\(t=0\) 대입: 기울기 5, 점 (0, -1) \(\implies \mathbf{y = 5x - 1}\)
06 생각을 키우는 문제 · 기하 최적화

곡선과 직선 사이의 최단거리 & 삼각형 넓이의 최솟값

두 점 \(A(3, 1)\), \(B(5, -3)\)과 곡선 \(y = -x^2\) 위의 임의의 점 \(P\)에 대하여 다음 물음에 답하시오.

⑴ 두 점 A, B를 지나는 직선의 방정식
⑵ 곡선 위의 점 P와 직선 AB 사이 거리가 최소가 되는 점 P의 좌표
⑶ 삼각형 APB의 넓이의 최솟값
SIMULATOR 3: 평행접선과 삼각형 APB의 최소 면적 시각화 점 P의 x좌표를 슬라이더로 움직여 삼각형 넓이의 변화를 확인하세요
삼각형 APB의 넓이
최솟값: 6.00
평행 조건 및 점과 직선 거리 계산장
