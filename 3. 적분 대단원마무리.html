01. 배운 내용 정리하기 (Ⅲ. 적분 핵심 공식 총정리)

교과서 150~151쪽 · 부정적분, 정적분, 넓이, 속도와 거리의 4대 핵심 체계 마인드맵

분야 1

부정적분의 뜻과 계산법

  • • 정의: $F'(x) = f(x) \iff \displaystyle\int f(x)\,dx = F(x) + C$
  • • 거듭제곱 적분: $\displaystyle\int x^n\,dx = \frac{1}{n+1}x^{n+1} + C$, $\displaystyle\int 1\,dx = x + C$
  • • 선형성: $\displaystyle\int kf\,dx = k\int f\,dx$, $\displaystyle\int (f \pm g)\,dx = \int f\,dx \pm \int g\,dx$
  • • 연산 순서: $\dfrac{d}{dx}\displaystyle\int f\,dx = f(x)$, $\displaystyle\int \frac{df}{dx}\,dx = f(x) + C$
분야 2

정적분과 미적분의 기본정리

  • • 미적분의 기본정리(FTC): $\displaystyle\int_a^b f(x)\,dx = [F(x)]_a^b = F(b) - F(a)$
  • • 정적분과 미분: $\dfrac{d}{dx}\displaystyle\int_a^x f(t)\,dt = f(x)$, $\displaystyle\int_a^a f(t)\,dt = 0$
  • • 구간 연결: $\displaystyle\int_a^c f\,dx + \int_c^b f\,dx = \int_a^b f\,dx$
  • • 대칭 구간 $[-a, a]$: 기함수(홀수) $= 0$, 우함수(짝수) $= 2\displaystyle\int_0^a$
분야 3

곡선과 도형의 넓이

  • • 곡선과 $x$축: $S = \displaystyle\int_a^b |f(x)|\,dx$ ($x$축 아래는 $-f(x)$ 적분)
  • • 두 곡선 사이: $S = \displaystyle\int_a^b |f(x) - g(x)|\,dx = \displaystyle\int_a^b (\text{위쪽} - \text{아래쪽})\,dx$
  • • 포물선 쾌속 공식: $S = \dfrac{|a|}{6}(\beta - \alpha)^3$
  • • 두 영역 $A, B$ 넓이 일치: $\displaystyle\int_0^a f(x)\,dx = 0$
분야 4

속도와 거리의 물리적 의미

  • • 시각 $t$에서의 위치: $x(t) = x(t_0) + \displaystyle\int_{t_0}^t v(t)\,dt$
  • • 위치의 변화량(변위): $\Delta x = \displaystyle\int_{t_1}^{t_2} v(t)\,dt$
  • • 움직인 실제 거리: $s = \displaystyle\int_{t_1}^{t_2} |v(t)|\,dt$ ($v-t$ 그래프와 $t$축 넓이)
  • • 운동 방향 전환: $v(t) = 0$이 되는 순간을 기준으로 판정

🎯 50차시 핵심 개념 자가진단 (O/X 퀴즈)

1. 속도 $v(t)$를 $[t_1, t_2]$에서 정적분한 값은 항상 물체가 움직인 실제 거리이다. (O/X)
2. 대칭 구간 $[-a, a]$에서 홀수 차수 항(기함수)의 정적분 값은 항상 0이다. (O/X)
3. $\frac{d}{dx} \left(\int_a^x f(t)\,dt\right) = f(x)$ 이다. (O/X)

곡선 $y = f(x)$ 위의 점 $(x, f(x))$에서의 접선의 기울기가 $6x + 2$이다. 이 곡선이 점 $(1, 6)$을 지날 때, $f(2)$의 값은?

✏️ 03번 적분상수 C 결정 연습장

$f(2) = 3(4) + 2(2) + 1 = 12 + 4 + 1 = \mathbf{17}$ (정답: ③)

$\int_3^5 |x^2 - 4x|\,dx$의 값을 구하시오.

✏️ 05번 x=4 기준 구간 분할 풀이 연습장
[정답 및 해설] $x^2 - 4x = x(x-4) = 0 \implies x = 4$. $[3, 4]$에서 음수, $[4, 5]$에서 양수:
$\int_3^4 (-x^2+4x)\,dx + \int_4^5 (x^2-4x)\,dx = \frac{5}{3} + \frac{7}{3} = \frac{12}{3} = \mathbf{4}$ 입니다.
06번 교과서 153쪽 / 삼차곡선과 포물선 사이 넓이

두 곡선 $y = x^3 - 2x^2 + x + 1$과 $y = x^2 - x + 1$로 둘러싸인 도형의 넓이는?

✏️ 06번 3개 교점 연립 및 구간 적분 연습장
[정답 및 해설] 교점: $x^3-3x^2+2x = x(x-1)(x-2) = 0 \implies x = 0, 1, 2$.
$[0, 1]$ 삼차곡선 위, $[1, 2]$ 이차곡선 위: $S = \int_0^1 (x^3-3x^2+2x)\,dx + \int_1^2 (-x^3+3x^2-2x)\,dx = \frac{1}{4} + \frac{1}{4} = \mathbf{\frac{1}{2}}$ (정답: ①)
07번 교과서 154쪽 / 정적분과 곱의 미분법

다항함수 $f(x)$가 모든 실수 $x$에 대하여 $2xf(x) = x^2 + 2\int_1^x f(t)\,dt$를 만족시킬 때, $f(3)$의 값을 구하시오.

✏️ 07번 x=1 대입 & 곱의 미분법 연습장
[정답 및 해설] $x=1$ 대입: $2f(1) = 1 \implies f(1) = \frac{1}{2}$.
양변 미분: $2f(x) + 2xf'(x) = 2x + 2f(x) \implies 2xf'(x) = 2x \implies f'(x) = 1$.
$f(x) = x - \frac{1}{2} \implies f(3) = 3 - \frac{1}{2} = \mathbf{\frac{5}{2}}$ (또는 $\mathbf{2.5}$) 입니다.
08번 교과서 154쪽 / 미분계수의 정의와 정적분

함수 $f(x) = 4x^3 - 2x + 3$에 대하여 $\lim_{x \to 1} \frac{1}{x - 1} \int_1^x f(t)\,dt$의 값은?

✏️ 08번 FTC와 미분계수 극한 정의 풀이 연습장
[정답 및 해설] $F'(x) = f(x)$라 하면 $\lim_{x \to 1} \frac{F(x) - F(1)}{x - 1} = F'(1) = f(1)$ 입니다.
따라서 $f(1) = 4(1)^3 - 2(1) + 3 = 4 - 2 + 3 = \mathbf{5}$ (정답: ⑤)
09번 교과서 154쪽 / 접선과 y축 둘러싸인 넓이

곡선 $y = -3x^2 + 3$과 이 곡선 위의 점 $(1, 0)$에서의 접선 및 $y$축으로 둘러싸인 도형의 넓이를 구하시오.

✏️ 09번 접선의 방정식 및 정적분 연습장
[정답 및 해설] $y' = -6x \implies$ 접선: $y - 0 = -6(x - 1) \implies y = -6x + 6$.
닫힌구간 $[0, 1]$에서 접선이 위쪽: $S = \int_0^1 \{(-6x + 6) - (-3x^2 + 3)\}\,dx = \int_0^1 (3x^2 - 6x + 3)\,dx = [x^3 - 3x^2 + 3x]_0^1 = \mathbf{1}$ 입니다.
10번 익스플로라그램 ②
대칭축 x=2와 정적분 = 0

곡선 $y = x^2 - 4x + a$와 $x$축 및 $y$축으로 둘러싸인 두 도형의 넓이를 각각 $A, B$라고 하자. $A : B = 1 : 2$일 때, 상수 $a$의 값을 구하시오. (단, $0 < a < 4$)

✏️ 10번 대칭축 x=2까지의 정적분=0 풀이 연습장
[정답 및 해설] 포물선 $y = (x-2)^2 + a - 4$의 대칭축은 $x = 2$입니다. $B$ 영역은 $x=2$에 의해 반으로 나뉘므로, $[0, 2]$에서의 정적분이 $0$이 됩니다:
$\int_0^2 (x^2 - 4x + a)\,dx = \left[\frac{1}{3}x^3 - 2x^2 + ax\right]_0^2 = \frac{8}{3} - 8 + 2a = 0 \implies 2a = \frac{16}{3} \implies \mathbf{a = \frac{8}{3}}$ 입니다.
11번 교과서 154쪽 / 속도 v(t) 그래프 판정

원점을 출발하여 수직선 위를 $7$초 동안 움직이는 점 $P$의 시각 $t$에서의 속도 $v(t)$의 그래프가 주어질 때, [보기]에서 옳은 것만을 있는 대로 고른 것은?

• ㄱ. 점 $P$는 $t=2$일 때 다시 원점을 지난다.
• ㄴ. $t=1$일 때와 $t=5$일 때 점 $P$의 위치가 서로 같다.
• ㄷ. 점 $P$가 출발한 후 처음으로 운동 방향을 바꾼 시각($t=3$)부터 두 번째로 바꾼 시각($t=5$)까지 움직인 거리는 $2$이다.
✏️ 11번 속도 정적분 면적 분석 연습장
[정답 및 해설]
• ㄱ (거짓): $t=2$일 때 $x(2) = \int_0^2 v(t)\,dt = 1 \neq 0$ 입니다.
• ㄴ (참): $\int_1^5 v(t)\,dt = 2 - 2 = 0$이므로 $t=1$과 $t=5$에서의 위치는 같습니다.
• ㄷ (참): 운동 방향이 바뀌는 $t=3$부터 $t=5$까지 움직인 실제 거리는 밑변 2, 높이 2인 삼각형 넓이 $\frac{1}{2} \times 2 \times 2 = \mathbf{2}$ 입니다. (정답: ⑤ ㄴ, ㄷ)
12번 교과서 154쪽 / 열기구 수직 속도와 높이

지면과 수직으로 움직이는 열기구의 $t$분 후 속도가 $v(t) = \begin{cases} t & (0 \le t < 20) \\ 60 - 2t & (20 \le t \le 30) \end{cases}\text{ (m/min)}$ 일 때, $t = 25$일 때 열기구의 지면으로부터의 높이(m)를 구하시오.

✏️ 12번 구간별 속도 적분 연습장
[정답 및 해설] 지면에서 출발하였으므로 $x(0) = 0$입니다:
$h(25) = \int_0^{20} t\,dt + \int_{20}^{25} (60 - 2t)\,dt = \left[\frac{1}{2}t^2\right]_0^{20} + [60t - t^2]_{20}^{25} = 200 + (875 - 800) = 200 + 75 = \mathbf{275\text{ m}}$ 입니다.
13번 서술형 평가 (155쪽)
도함수 포물선과 극댓값 추론

삼차함수 $f(x)$에 대하여 도함수 $y = f'(x)$의 그래프가 꼭짓점이 $(1, 1)$이고 원점과 $(2, 0)$을 지나는 포물선이다. 함수 $f(x)$의 극솟값이 $\frac{5}{3}$일 때, $f(x)$의 극댓값을 구하시오.

✏️ 13번 서술형 단계별 전개 연습장
[정답 및 해설]
• 꼭짓점이 $(1, 1)$이고 원점을 지나므로 $f'(x) = -x(x-2) = -x^2 + 2x$.
• $f(x) = \int (-x^2+2x)\,dx = -\frac{1}{3}x^3 + x^2 + C$.
• $x=0$에서 극소이므로 $f(0) = C = \frac{5}{3}$. 따라서 $f(x) = -\frac{1}{3}x^3 + x^2 + \frac{5}{3}$.
• $x=2$에서 극대이므로 극댓값은 $f(2) = -\frac{8}{3} + 4 + \frac{5}{3} = -\frac{3}{3} + 4 = \mathbf{3}$ 입니다.
14번 서술형 평가 (155쪽)
대칭 구간 성질을 활용한 미정계수 결정

함수 $f(x) = ax^3 + bx^2 + x$가 $\int_{-1}^1 f(x)\,dx = 2$이고, $\int_{-1}^1 xf(x)\,dx = \frac{16}{15}$를 만족시킬 때, 상수 $a + b$의 값을 구하시오.

✏️ 14번 기함수 소거 및 우함수 연립 연습장
[정답 및 해설]
• $\int_{-1}^1 (ax^3+bx^2+x)\,dx = 2\int_0^1 bx^2\,dx = \frac{2}{3}b = 2 \implies \mathbf{b = 3}$.
• $xf(x) = ax^4 + bx^3 + x^2$이므로 $\int_{-1}^1 (ax^4+bx^3+x^2)\,dx = 2\int_0^1 (ax^4+x^2)\,dx = 2\left(\frac{1}{5}a + \frac{1}{3}\right) = \frac{16}{15} \implies \frac{1}{5}a = \frac{1}{5} \implies \mathbf{a = 1}$.
• 따라서 $a + b = 1 + 3 = \mathbf{4}$ 입니다.
15번 사고력 최고난도 (155쪽)
정적분 전개식과 이중 미분

다항함수 $f(x)$가 모든 실수 $x$에 대하여 $\int_1^x (x - t)f(t)\,dt = ax^2 + bx - 1$을 만족시킬 때, 상수 $a, b$에 대하여 $ab$의 값을 구하시오.

✏️ 15번 x 꺼내기 전개 및 미분 연습장
[정답 및 해설]
• $x = 1$ 대입: $0 = a + b - 1 \implies a + b = 1$.
• 좌변 전개: $x\int_1^x f(t)\,dt - \int_1^x tf(t)\,dt = ax^2 + bx - 1$.
• 양변을 $x$에 대해 미분: $\int_1^x f(t)\,dt + xf(x) - xf(x) = 2ax + b \implies \int_1^x f(t)\,dt = 2ax + b$.
• 여기에 $x=1$ 대입: $0 = 2a + b \implies b = -2a$.
• $a + (-2a) = 1 \implies a = -1, b = 2$. 따라서 $ab = (-1)(2) = \mathbf{-2}$ 입니다.
16번 사고력 최고난도 (155쪽)
포물선과 직선 사이의 넓이 이등분

곡선 $y = x^2 + 2x$와 직선 $y = mx$로 둘러싸인 도형의 넓이가 $x$축에 의하여 이등분될 때, $(m - 2)^3$의 값을 구하시오. (단, $m < 0$)

✏️ 16번 포물선 넓이 쾌속 공식 연립 연습장
[정답 및 해설]
• 곡선과 $x$축으로 둘러싸인 넓이: $S_1 = \frac{1}{6}(0 - (-2))^3 = \frac{8}{6} = \frac{4}{3}$.
• 곡선과 직선 $y=mx$의 교점: $x^2 + 2x = mx \implies x\{x - (m - 2)\} = 0 \implies x = m - 2, 0$.
• 둘러싸인 전체 넓이: $S = \frac{1}{6}(0 - (m - 2))^3 = \frac{1}{6}(2 - m)^3$.
• $S = 2S_1$이므로 $\frac{1}{6}(2 - m)^3 = \frac{8}{3} \implies (2 - m)^3 = 16$.
• 따라서 $(m - 2)^3 = -(2 - m)^3 = \mathbf{-16}$ 입니다.

교통안전 & 수학적 모델링

자동차가 멈추기까지는 왜 생각보다 훨씬 긴 거리가 필요할까?

달리는 자동차의 브레이크를 밟는다고 즉시 멈추지 않습니다. 운전자가 위험을 인지하고 브레이크를 밟기까지 걸리는 반응시간 동안 달린 공주거리($d_1$)와, 실제 브레이크가 작동하여 멈출 때까지 감속 주행한 제동거리($d_2$)를 합친 것이 바로 정지거리(Stopping Distance)입니다. 적분의 눈으로 속도-시간 그래프의 넓이를 분석하여 안전거리의 과학적 원리를 밝혀봅시다.

🚗 속도-시간 그래프와 정지거리 인터랙티브 시뮬레이터

초기 속도와 노면 상태(마른 도로 vs 빗길)를 조정해 보세요. 직사각형 넓이(공주거리)와 삼각형 넓이(제동거리)의 합이 총 이동거리(정적분)가 되는 과정을 눈으로 직접 확인합니다.

📊 속도-시간 $v(t)$ 그래프 & 적분 영역 정지거리: 37.8 m
주행 속도: 60 km/h
반응 시간: 0.8 초
노면 조건:
💡 정지거리의 적분 분해 공식
공주거리 $d_1$:
$\int_0^{t_R} v_0\,dt = v_0 \cdot t_R$ (등속)
제동거리 $d_2$:
$\int_0^{T} (v_0 - at)\,dt = \frac{v_0^2}{2a}$ (등가속 감속)
• 60 km/h (16.7 m/s) 기준: 공주거리 13.3 m + 제동거리 20.2 m = 총 33.5 m
자율 작성 후 확인
[모범 답변 예시] 제동거리 공식 $d_2 = \frac{v_0^2}{2a}$에서 노면이 젖으면 타이어와 도로 사이의 마찰계수가 감소하여 감속도 $a$가 약 절반으로 줄어듭니다. 분모가 $1/2$이 되므로 제동거리는 2배로 급증합니다. 따라서 동일한 안전거리를 유지하려면 초기 속도 $v_0$를 교과서 지침대로 평소보다 20~50% 감속하여 운전해야 합니다.

🛣️ 고속도로 '안전거리 100m'와 '3초의 법칙'의 적분학적 근거

고속도로 표지판에 적힌 "시속 100km 주행 시 안전거리 100m 확보"는 단순한 권고가 아닙니다. 차량의 속도가 2배가 되면 제동거리는 $2^2 = 4$배로 급증한다는 이차함수적 적분 원리와 예기치 못한 돌발 상황에서의 인간 반응시간을 완벽히 수학적으로 반영한 안전선입니다.

⏱️ 운전자 필수 상식: '3초의 법칙(3-Second Rule)'

앞차가 도로 표지판이나 가로등을 통과한 순간부터 마음속으로 "1초, 2초, 3초"를 센 뒤 내 차가 그 지점을 통과하면 안전거리가 확보된 것입니다.

수학적 증명: 시속 $100\,\text{km/h}$ ($27.8\,\text{m/s}$) 주행 시 3초 동안 달리는 거리는 $$27.8\,\text{m/s} \times 3\,\text{s} = \mathbf{83.4\,\text{m}}$$ 운전자의 공주거리(약 $28\,\text{m}$)와 제동거리(약 $56\,\text{m}$)의 합인 약 $84\,\text{m}$와 정확히 일치합니다!

자율 작성 후 확인
[모범 답변 예시] 시속 $100\,\text{km/h}$에서 빗길 주행 시 제동거리는 약 $112.4\,\text{m}$까지 늘어나고, 반응시간 1초 동안 달리는 공주거리 $27.8\,\text{m}$를 더하면 정지거리가 무려 $\mathbf{140.2\,\text{m}}$에 달합니다. 평소 마른 도로의 안전거리 100m로는 추돌을 피할 수 없으므로, 빗길에서는 반드시 140m 이상의 넉넉한 차간 거리를 확보해야 합니다.
