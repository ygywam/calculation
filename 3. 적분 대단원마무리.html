01. 배운 내용 정리하기 (Ⅲ. 적분 핵심 공식 총정리)

교과서 150~151쪽 · 부정적분, 정적분, 넓이, 속도와 거리의 4대 핵심 체계

1

부정적분의 뜻과 계산법

함수 $F(x)$의 도함수가 $f(x)$일 때, $F(x)$를 $f(x)$의 부정적분이라 하며 기호로 $\int f(x)\,dx = F(x) + C$ ($C$는 적분상수)로 나타냅니다.

• $\int x^n\,dx = \frac{1}{n+1}x^{n+1} + C$ ($n$은 양의 정수)
• $\int k\,dx = kx + C$, $\int k f(x)\,dx = k\int f(x)\,dx$
• $\int \{f(x) \pm g(x)\}\,dx = \int f(x)\,dx \pm \int g(x)\,dx$
2

정적분과 미적분의 기본정리

닫힌구간 $[a, b]$에서 연속인 함수 $f(x)$에 대하여 $F'(x) = f(x)$일 때, 미적분의 기본정리가 성립합니다.

• $\int_a^b f(x)\,dx = [F(x)]_a^b = F(b) - F(a)$
• $\frac{d}{dx}\int_a^x f(t)\,dt = f(x)$, $\frac{d}{dx}\int_x^{x+a} f(t)\,dt = f(x+a) - f(x)$
• 대칭성: 기함수 $\int_{-a}^a f(x)\,dx = 0$, 우함수 $\int_{-a}^a g(x)\,dx = 2\int_0^a g(x)\,dx$
3

곡선과 도형의 넓이

닫힌구간 $[a, b]$에서 곡선과 축, 또는 두 곡선으로 둘러싸인 넓이는 항상 위쪽 식에서 아래쪽 식을 뺀 절댓값 함수의 정적분입니다.

• 곡선과 $x$축 사이: $S = \int_a^b |f(x)|\,dx$
• 두 곡선 사이 넓이: $S = \int_a^b |f(x) - g(x)|\,dx$
• 포물선 넓이 공식: $S = \frac{|a|}{6}(\beta - \alpha)^3$ (교점 $\alpha, \beta$)
4

속도와 거리의 물리적 의미

수직선 위를 움직이는 점 $P$의 시각 $t$에서의 속도 $v(t)$와 처음 위치 $x_0$에 대하여 위치, 변위, 거리를 정적분으로 구합니다.

• 시각 $t$에서의 위치: $x(t) = x_0 + \int_0^t v(t)\,dt$
• $t_1$에서 $t_2$까지 위치의 변화량(변위): $\Delta x = \int_{t_1}^{t_2} v(t)\,dt$
• $t_1$에서 $t_2$까지 실제 움직인 거리: $s = \int_{t_1}^{t_2} |v(t)|\,dt$
개념 자가진단

적분 핵심 개념 진위 판정 (OX)

1. 속도 $v(t)$의 정적분 $\int_{t_1}^{t_2} v(t)\,dt$는 항상 점이 실제로 움직인 거리와 같다.

2. 기함수 $f(-x) = -f(x)$를 대칭 구간 $[-a, a]$에서 정적분하면 항상 그 값은 0이다.

3. 임의의 연속함수 $f(t)$에 대하여 $\frac{d}{dx}\int_a^x f(t)\,dt = f(x)$가 성립한다.

[단계별 상세 해설]
• 1단계 (양변 미분): $\int f(x)\,dx = x^4 + x^2 + C$의 양변을 $x$에 대하여 미분합니다.

03번 교과서 152쪽 / 기본 · 접선의 기울기와 부정적분

곡선 $y = f(x)$ 위의 점 $(x, f(x))$에서의 접선의 기울기가 $6x + 2$이다. 이 곡선이 점 $(1, 6)$을 지날 때, $f(2)$의 값은?

[단계별 상세 해설]
• 1단계 (도함수 해석): 점 $(x, f(x))$에서의 접선 기울기가 $6x + 2$이므로 $f'(x) = 6x + 2$입니다.
• 2단계 (부정적분 계산): $f(x) = \int (6x + 2)\,dx = 3x^2 + 2x + C$.
• 3단계 (적분상수 결정): 곡선이 점 $(1, 6)$을 지나므로 $f(1) = 3(1)^2 + 2(1) + C = 5 + C = 6 \implies C = 1$.
• 4단계 ($f(2)$ 계산): $f(x) = 3x^2 + 2x + 1 \implies f(2) = 3(4) + 2(2) + 1 = 12 + 4 + 1 = \mathbf{17}$.

04번 교과서 152쪽 / 기본 · 정적분의 구간 결합

$\int_1^2 (3x^2 + 1)\,dx - \int_4^2 (3t^2 + 1)\,dt$의 값은?

[단계별 상세 해설]
• 1단계 (적분 구간의 성질): 정적분에서 적분 변수의 문자는 값을 바꾸지 않으므로 $\int_4^2 (3t^2 + 1)\,dt = \int_4^2 (3x^2 + 1)\,dx$입니다.
• 또한 $-\int_4^2 (3x^2 + 1)\,dx = +\int_2^4 (3x^2 + 1)\,dx$이므로 식을 하나로 합칩니다:
$$\int_1^2 (3x^2 + 1)\,dx + \int_2^4 (3x^2 + 1)\,dx = \int_1^4 (3x^2 + 1)\,dx$$
• 2단계 (정적분 계산): $\int_1^4 (3x^2 + 1)\,dx = [x^3 + x]_1^4 = (4^3 + 4) - (1^3 + 1) = (64 + 4) - (1 + 1) = 68 - 2 = \mathbf{66}$.

[단계별 상세 해설]

06번 교과서 153쪽 / 표준 · 삼차곡선과 이차곡선 사이의 넓이

두 곡선 $y = x^3 - 2x^2 + x + 1$과 $y = x^2 - x + 1$로 둘러싸인 도형의 넓이는?

[단계별 상세 해설]

- 구간 $[0, 1]$: $x = 0.5$ 대입 시 삼차함수가 위쪽 ($f(x) - g(x) \ge 0$)
- 구간 $[1, 2]$: $x = 1.5$ 대입 시 이차함수가 위쪽 ($g(x) - f(x) \ge 0$)
• 3단계 (정적분 계산):
$S_1 = \int_0^1 (x^3 - 3x^2 + 2x)\,dx = \left[\frac{1}{4}x^4 - x^3 + x^2 \right]_0^1 = \frac{1}{4} - 1 + 1 = \frac{1}{4}$
$S_2 = \int_1^2 -(x^3 - 3x^2 + 2x)\,dx = \left[-\frac{1}{4}x^4 + x^3 - x^2 \right]_1^2 = (-4 + 8 - 4) - \left(-\frac{1}{4} + 1 - 1 \right) = \frac{1}{4}$

다항함수 $f(x)$가 모든 실수 $x$에 대하여 $2xf(x) = x^2 + 2\int_1^x f(t)\,dt$를 만족시킬 때, $f(3)$의 값을 구하시오.

답:
[단계별 상세 해설]
• 1단계 ($x = 1$ 대입하여 함수값 확인):
$2(1)f(1) = 1^2 + 2\int_1^1 f(t)\,dt \implies 2f(1) = 1 + 0 \implies \mathbf{f(1) = \frac{1}{2}}$.
• 2단계 (양변 미분): 곱의 미분법과 기본정리를 적용합니다.
$(2x)'f(x) + 2xf'(x) = (x^2)' + 2\frac{d}{dx}\int_1^x f(t)\,dt$
$2f(x) + 2xf'(x) = 2x + 2f(x) \implies 2xf'(x) = 2x$
• $x \neq 0$에서 $f'(x) = 1$이므로 $f(x) = x + C$ (연속성에 의해 모든 실수).
• 3단계 ($f(1) = \frac{1}{2}$ 적용): $1 + C = \frac{1}{2} \implies C = -\frac{1}{2}$.

• 4단계 ($f(3)$ 계산): $f(3) = 3 - \frac{1}{2} = \mathbf{\frac{5}{2}}$ (또는 $2.5$).
08번 교과서 154쪽 / 표준 · 정적분으로 정의된 함수의 극한

함수 $f(x) = 4x^3 - 2x + 3$에 대하여 $\lim_{x \to 1} \frac{1}{x - 1} \int_1^x f(t)\,dt$의 값은?

[단계별 상세 해설]
• 1단계 (미분계수의 정의와 연결): $f(t)$의 한 부정적분을 $F(t)$라 하면 $\int_1^x f(t)\,dt = F(x) - F(1)$입니다.
$$\lim_{x \to 1} \frac{1}{x - 1} \int_1^x f(t)\,dt = \lim_{x \to 1} \frac{F(x) - F(1)}{x - 1} = F'(1) = f(1)$$
• 2단계 ($f(1)$ 계산): $f(1) = 4(1)^3 - 2(1) + 3 = 4 - 2 + 3 = \mathbf{5}$.
• 정답: ⑤ 5

[단계별 상세 해설]

• ㄴ 분석 (참): $t = 1$부터 $t = 5$까지의 위치 변화량 $\int_1^5 v(t)\,dt$를 확인합니다.
- $[1, 3]$ 넓이: 삼각형 $\frac{1}{2} \times 2 \times 2 = +2$
- $[3, 5]$ 넓이: 아래쪽 삼각형 $\frac{1}{2} \times 2 \times (-2) = -2$
따라서 $\int_1^5 v(t)\,dt = 2 - 2 = 0 \implies x(5) - x(1) = 0 \implies x(1) = x(5)$로 위치가 같습니다.
• ㄷ 분석 (참): $v(t) = 0$이 되어 운동 방향이 바뀌는 시각은 $t = 3$과 $t = 5$입니다.
$t = 3$부터 $t = 5$까지 움직인 실제 거리는 절댓값의 정적분이므로 밑변 2, 높이 2인 삼각형의 넓이 $\frac{1}{2} \times 2 \times 2 = \mathbf{2}$입니다.
• 정답: ⑤ ㄴ, ㄷ
12번 교과서 154쪽 / 표준 · 열기구 수직 속도와 높이

지면과 수직으로 움직이는 열기구의 $t$분 후 속도가 $v(t) = \begin{cases} t & (0 \le t < 20) \ 60 - 2t & (20 \le t \le 30) \end{cases}\text{ (m/min)}$ 일 때, $t = 25$일 때 열기구의 지면으로부터의 높이(m)를 구하시오.

열기구 높이:
[단계별 상세 해설]
• 1단계 (초기조건): 지면에서 출발하였으므로 $t = 0$일 때의 위치는 $h(0) = 0$입니다.
• 2단계 (구간별 정적분): $t = 25$일 때의 높이는 $0$부터 $25$까지의 속도의 정적분입니다.
$h(25) = \int_0^{20} t\,dt + \int_{20}^{25} (60 - 2t)\,dt$
$\int_0^{20} t\,dt = \left[\frac{1}{2}t^2 \right]_0^{20} = \frac{1}{2}(400) = 200\text{ m}$
$\int_{20}^{25} (60 - 2t)\,dt = [60t - t^2]_{20}^{25} = (1500 - 625) - (1200 - 400) = 875 - 800 = 75\text{ m}$
• 3단계 (총 높이 합산): $h(25) = 200 + 75 = \mathbf{275\text{ m}}$
13번 교과서 155쪽 / 발전 서술형 · 도함수 그래프와 극대/극소

삼차함수 $f(x)$에 대하여 도함수 $y = f'(x)$의 그래프가 꼭짓점이 $(1, 1)$이고 원점과 $(2, 0)$을 지나는 포물선이다. $f(x)$의 극솟값이 $\frac{5}{3}$일 때, $f(x)$의 극댓값을 구하시오.

극댓값:
[단계별 상세 해설]
• 1단계 (도함수 식 세우기): 꼭짓점이 $(1, 1)$이고 $(0, 0)$을 지나므로 $f'(x) = a(x - 1)^2 + 1$.
$0 = a(0 - 1)^2 + 1 \implies a = -1$. 따라서 $f'(x) = -(x - 1)^2 + 1 = -x^2 + 2x = -x(x - 2)$.
• 2단계 (부정적분 및 극값 위치 파악):
$f(x) = \int (-x^2 + 2x)\,dx = -\frac{1}{3}x^3 + x^2 + C$.
$f'(x)$의 부호가 음에서 양으로 바뀌는 $x = 0$에서 극소, 양에서 음으로 바뀌는 $x = 2$에서 극대를 갖습니다.
• 3단계 (극솟값으로 $C$ 결정): $f(0) = C = \frac{5}{3}$.
따라서 $f(x) = -\frac{1}{3}x^3 + x^2 + \frac{5}{3}$.
• 4단계 (극댓값 계산): $f(2) = -\frac{1}{3}(8) + 4 + \frac{5}{3} = -\frac{8}{3} + \frac{5}{3} + 4 = -\frac{3}{3} + 4 = -1 + 4 = \mathbf{3}$.
14번 교과서 155쪽 / 발전 서술형 · 우함수·기함수 대칭 적분

함수 $f(x) = ax^3 + bx^2 + x$가 $\int_{-1}^1 f(x)\,dx = 2$이고, $\int_{-1}^1 xf(x)\,dx = \frac{16}{15}$를 만족시킬 때, 상수 $a + b$의 값을 구하시오.

상수 a + b:
[단계별 상세 해설]
• 1단계 (첫 번째 식 해석): 구간 $[-1, 1]$에서 홀수차수(기함수)는 적분값이 $0$입니다.
$$\int_{-1}^1 (ax^3 + bx^2 + x)\,dx = 2\int_0^1 bx^2\,dx = 2\left[\frac{1}{3}bx^3 \right]_0^1 = \frac{2}{3}b = 2 \implies \mathbf{b = 3}$$
• 2단계 (두 번째 식 해석): $xf(x) = x(ax^3 + bx^2 + x) = ax^4 + bx^3 + x^2$.
홀수차수 $bx^3$은 소거되므로:
$$\int_{-1}^1 (ax^4 + bx^3 + x^2)\,dx = 2\int_0^1 (ax^4 + x^2)\,dx = 2\left[\frac{1}{5}ax^5 + \frac{1}{3}x^3 \right]_0^1 = 2\left(\frac{1}{5}a + \frac{1}{3} \right) = \frac{16}{15}$$ $$\frac{1}{5}a + \frac{1}{3} = \frac{8}{15} \implies \frac{1}{5}a = \frac{8}{15} - \frac{5}{15} = \frac{3}{15} = \frac{1}{5} \implies \mathbf{a = 1}$$
• 3단계 (합 계산): $a + b = 1 + 3 = \mathbf{4}$.
15번 교과서 155쪽 / 발전 사고력 · 정적분 복합 전개 항등식

다항함수 $f(x)$가 모든 실수 $x$에 대하여 $\int_1^x (x - t)f(t)\,dt = ax^2 + bx - 1$을 만족시킬 때, 상수 $ab$의 값을 구하시오.

상수 ab:
[단계별 상세 해설]
• 1단계 ($x = 1$ 대입하여 첫 번째 관계식 도출):
$\int_1^1 (1 - t)f(t)\,dt = 0 = a(1)^2 + b(1) - 1 \implies \mathbf{a + b = 1}$.
• 2단계 (좌변 분리 전개 후 양변 미분):
좌변: $x\int_1^x f(t)\,dt - \int_1^x tf(t)\,dt = ax^2 + bx - 1$.
양변을 $x$에 대하여 미분하면 곱의 미분법에 의해:
$\left(1 \cdot \int_1^x f(t)\,dt + x f(x) \right) - x f(x) = 2ax + b$
$\implies \mathbf{\int_1^x f(t)\,dt = 2ax + b}$.
• 3단계 ($x = 1$ 대입하여 두 번째 관계식 도출):
$\int_1^1 f(t)\,dt = 0 = 2a(1) + b \implies \mathbf{b = -2a}$.
• 4단계 (연립방정식 풀이):
$a + (-2a) = 1 \implies -a = 1 \implies \mathbf{a = -1}$.
$b = -2(-1) = \mathbf{2}$.
따라서 $ab = (-1) \times 2 = \mathbf{-2}$입니다.
16번 교과서 155쪽 / 발전 사고력 · 넓이의 이등분과 포물선 공식

곡선 $y = x^2 + 2x$와 직선 $y = mx$로 둘러싸인 도형의 넓이가 $x$축에 의하여 이등분될 때, $(m - 2)^3$의 값을 구하시오. (단, $m < 0$)

(m - 2)³의 값:
[단계별 상세 해설]
• 1단계 (곡선과 $x$축 사이의 기본 넓이 $S_1$):
$y = x^2 + 2x = x(x + 2) = 0 \implies x = -2, 0$. 포물선 넓이 공식에 의해:
$$S_1 = \frac{1}{6}(0 - (-2))^3 = \frac{1}{6}(8) = \frac{4}{3}$$
• 2단계 (곡선과 직선 $y = mx$로 둘러싸인 전체 넓이 $S$):
교점: $x^2 + 2x = mx \implies x^2 + (2 - m)x = 0 \implies x\{x - (m - 2)\} = 0$.
$m < 0$이므로 $m - 2 < -2 < 0$. 교점의 $x$좌표는 $x = m - 2$와 $x = 0$입니다.
따라서 둘러싸인 전체 넓이 $S$는:
$$S = \frac{1}{6}\{0 - (m - 2)\}^3 = \frac{1}{6}(2 - m)^3$$
• 3단계 (넓이 이등분 조건 $S = 2S_1$ 적용):
$\frac{1}{6}(2 - m)^3 = 2 \times \frac{4}{3} = \frac{8}{3} \implies (2 - m)^3 = \frac{8}{3} \times 6 = 16$.
• 4단계 ($(m - 2)^3$ 계산):
$(m - 2)^3 = \{-(2 - m)\}^3 = -(2 - m)^3 = \mathbf{-16}$.

교통안전 & 수학적 모델링

자동차가 멈추기까지는 왜 생각보다 훨씬 긴 거리가 필요할까?

달리는 자동차의 브레이크를 밟는다고 즉시 멈추지 않습니다. 운전자가 위험을 인지하고 브레이크를 밟기까지 걸리는 반응시간 동안 달린 공주거리($d_1$)와, 실제 브레이크가 작동하여 멈출 때까지 감속 주행한 제동거리($d_2$)를 합친 것이 바로 정지거리(Stopping Distance)입니다. 적분의 눈으로 속도-시간 그래프의 넓이를 분석하여 안전거리의 과학적 원리를 밝혀봅시다.

🛣️ 고속도로 '안전거리 100m'와 '3초의 법칙'의 적분학적 근거

고속도로 표지판에 적힌 "시속 100km 주행 시 안전거리 100m 확보"는 단순한 권고가 아닙니다. 차량의 속도가 2배가 되면 제동거리는 $2^2 = 4$배로 급증한다는 이차함수적 적분 원리와 예기치 못한 돌발 상황에서의 인간 반응시간을 완벽히 수학적으로 반영한 안전선입니다.

자율 작성 후 확인
