    $\displaystyle\int f(x)\,dx = $ $F(x) + C$ (단, $C$는 적분상수)
  • (2) 함수 $y=x^n$ ($n$은 양의 정수)과 상수함수의 부정적분:
    ① $\displaystyle\int x^n\,dx = $ $\dfrac{1}{n+1}x^{n+1} + C$  |  ② $\displaystyle\int 1\,dx = $ $x + C$
  • (3) 실수배, 합, 차의 부정적분:
    ① $\int kf(x)\,dx = k\int f(x)\,dx$ (단, $k \ne 0$인 실수)
    ② $\int \{f(x) \pm g(x)\}\,dx = \int f(x)\,dx \pm \int g(x)\,dx$

정적분 (p.152)

  • (1) 정적분의 정의: $[a, b]$에서 $f(x) \ge 0$인 넓이를 $S_1$, $f(x) \le 0$인 넓이를 $S_2$라 할 때 $\int_a^b f(x)\,dx = $ $S_1 - S_2$
    ① $a=b$이면 $\int_a^a f(x)\,dx = 0$  |  ② $a>b$이면 $\int_a^b f(x)\,dx = $ $-\int_b^a f(x)\,dx$
  • (2) 정적분과 미분의 관계: $\dfrac{d}{dx}\int_a^x f(t)\,dt = $ $f(x)$ (단, $a < x < b$)
  • (3) 부정적분과 정적분의 관계: $\int_a^b f(x)\,dx = [F(x)]_a^b = $ $F(b) - F(a)$
  • (4) 구간 결합 성질: $\int_a^c f(x)\,dx + \int_c^b f(x)\,dx = $ $\int_a^b f(x)\,dx$

다항함수 $f(x)$에 대하여 $\displaystyle\int f(x)\,dx = x^4 + x^2 + C$일 때, $f(-1)$의 값은? (단, $C$는 적분상수)

01번 단계별 상세 풀이 보기 (클릭하여 펼치기)

• 1단계 [부정적분과 미분의 관계]: $\displaystyle\int f(x)\,dx = x^4 + x^2 + C$의 양변을 $x$에 대하여 미분하면 좌변은 $f(x)$가 됩니다.

$$f(x) = \frac{d}{dx}(x^4 + x^2 + C) = 4x^3 + 2x$$

• 2단계 [함숫값 계산]: 구한 $f(x)$에 $x = -1$을 대입하면

$$f(-1) = 4(-1)^3 + 2(-1) = -4 - 2 = \mathbf{-6} \quad (\text{정답: ①})$$

02 ★★☆ 다항함수의 부정적분

다음 부정적분을 구하시오. (단, $C$는 적분상수)

(1) $F(x)=\int (2x^3+4x-1)\,dx$ ($F(0)=0$일 때 $F(2)$의 값)
(2) $G(x)=\int (x^2-3)(x+2)\,dx$ ($G(0)=0$일 때 $G(2)$의 값)
(3) $\int (2x+1)^2\,dx - \int (2x-1)^2\,dx = ax^2 + C$에서 상수 $a$
02번 (1)~(3) 단계별 상세 풀이 보기 (클릭하여 펼치기)

• (1) 항별 부정적분 공식 적용:
$\displaystyle\int (2x^3+4x-1)\,dx = 2\cdot\frac{1}{4}x^4 + 4\cdot\frac{1}{2}x^2 - x + C = \mathbf{\frac{1}{2}x^4 + 2x^2 - x + C}$
($F(0)=0$이면 $C=0$이므로 $F(2) = \frac{1}{2}(16) + 2(4) - 2 = 8 + 8 - 2 = \mathbf{14}$)

• (2) 곱의 다항식을 먼저 전개한 후 적분:
$(x^2-3)(x+2) = x^3 + 2x^2 - 3x - 6$이므로
$\displaystyle\int (x^3+2x^2-3x-6)\,dx = \mathbf{\frac{1}{4}x^4 + \frac{2}{3}x^3 - \frac{3}{2}x^2 - 6x + C}$
($G(0)=0$일 때 $G(2) = 4 + \frac{16}{3} - 6 - 12 = -14 + \frac{16}{3} = \mathbf{-\frac{26}{3}}$)

• (3) 부정적분의 차의 성질로 피적분함수 먼저 정리:
$\displaystyle\int \{(2x+1)^2 - (2x-1)^2\}\,dx = \int \{(4x^2+4x+1)-(4x^2-4x+1)\}\,dx = \int 8x\,dx = \mathbf{4x^2 + C}$ (따라서 $a = \mathbf{4}$)

03 ★★☆ 접선의 기울기와 부정적분

곡선 $y = f(x)$ 위의 점 $(x, f(x))$에서의 접선의 기울기가 $6x + 2$이다. 이 곡선이 점 $(1, 6)$을 지날 때, $f(2)$의 값은?

03번 단계별 상세 풀이 보기 (클릭하여 펼치기)

• 1단계 [도함수에서 부정적분 구하기]: 점 $(x, f(x))$에서의 접선의 기울기가 $6x+2$이므로 $f'(x) = 6x + 2$입니다.

$$f(x) = \int (6x + 2)\,dx = 3x^2 + 2x + C \quad (\text{단, } C\text{는 적분상수})$$

• 2단계 [적분상수 $C$ 결정]: 곡선이 점 $(1, 6)$을 지나므로 $f(1) = 6$입니다.

$$f(1) = 3(1)^2 + 2(1) + C = 5 + C = 6 \implies C = 1$$

• 3단계 [$f(2)$ 계산]: $f(x) = 3x^2 + 2x + 1$이므로 $f(2) = 3(2)^2 + 2(2) + 1 = 12 + 4 + 1 = \mathbf{17}$ (정답: ③)

04 ★★☆ 나누어진 구간의 정적분 결합

$\displaystyle\int_{1}^{2} (3x^2 + 1)\,dx - \int_{4}^{2} (3t^2 + 1)\,dt$의 값은?

04번 단계별 상세 풀이 보기 (클릭하여 펼치기)

• 1단계 [적분 변수 통일 및 위끝·아래끝 교환]: 정적분은 적분 변수에 관계없이 값이 같고, $-\displaystyle\int_{4}^{2} (3x^2+1)\,dx = +\int_{2}^{4} (3x^2+1)\,dx$입니다.

• 2단계 [나누어진 구간 결합]: 구간 $[1, 2]$와 $[2, 4]$를 하나로 합치면

$$\int_{1}^{2} (3x^2 + 1)\,dx + \int_{2}^{4} (3x^2 + 1)\,dx = \int_{1}^{4} (3x^2 + 1)\,dx = \Big[x^3 + x\Big]_{1}^{4} = (64 + 4) - (1 + 1) = \mathbf{66} \quad (\text{정답: ④})$$

05번 단계별 상세 풀이 보기 (클릭)

• 1단계 [부호 경계 찾기]: $x^2-4x = x(x-4) = 0$이므로 적분 구간 $[3, 5]$ 내부의 경계는 $x = 4$입니다.

• 2단계 [구간 분할 적분]: $[3, 4]$에서는 $x^2-4x \le 0$, $[4, 5]$에서는 $x^2-4x \ge 0$이므로

08번: 함수 $f(x) = 4x^3 - 2x + 3$에 대하여 $\lim_{x\to 1}\dfrac{1}{x-1}\displaystyle\int_{1}^{x} f(t)\,dt$의 값은?

08번 단계별 상세 풀이 보기 (클릭)

• 1단계 [공주 거리]: $1$초 동안 $\dfrac{40}{3}\text{ m/s}$로 이동하므로 $\dfrac{40}{3}\times 1 = \dfrac{40}{3}\text{ (m)} \approx 13.33\text{ m}$

• 2단계 [제동 거리]: $v(t) = \dfrac{40}{3} - 0.6\times 10t = \dfrac{40}{3} - 6t = 0$에서 정지 시각은 $t = \dfrac{20}{9}$초이므로
$\displaystyle\int_{0}^{20/9} \left(\frac{40}{3} - 6t\right)\,dt = \left[\frac{40}{3}t - 3t^2\right]_0^{20/9} = \frac{400}{27}\text{ (m)} \approx 14.81\text{ m}$

• 3단계 [정지거리 및 안전거리]: 정지거리는 $\dfrac{40}{3} + \dfrac{400}{27} = \dfrac{760}{27} \approx \mathbf{28.15\text{ (m)}}$이며, 일반 도로 안전거리는 $48 - 15 = \mathbf{33\text{ (m)}}$입니다.

활동 2 (p.157) · 고속 도로 $90\text{ km/h}$ $90\text{ km/h} = 25\text{ m/s},\; f=0.8,\; g=10$

고속 도로를 $90\text{ km/h}$($25\text{ m/s}$)로 달리던 운전자가 $1$초 만에 브레이크를 밟았을 때($f=0.8$), 정지거리(소수 둘째 자리 반올림)와 고속 도로 안전거리 기준값을 각각 구하시오.

정지거리: $\text{m}$ 안전거리: $\text{m}$
활동 2 단계별 상세 풀이 보기 (클릭)

• 1단계 [공주 거리]: $25 \times 1 = \mathbf{25\text{ (m)}}$

• 2단계 [제동 거리]: $v(t) = 25 - 0.8\times 10t = 25 - 8t = 0$에서 정지 시각은 $t = \dfrac{25}{8}$초이므로
$\displaystyle\int_{0}^{25/8} (25 - 8t)\,dt = \left[25t - 4t^2\right]_0^{25/8} = \frac{625}{16} = 39.0625\text{ (m)}$

• 3단계 [정지거리 및 안전거리]: 정지거리는 $25 + 39.0625 = 64.0625 \approx \mathbf{64.06\text{ (m)}}$이며, 고속 도로 안전거리는 주행 속도 수치 그대로인 $\mathbf{90\text{ (m)}}$입니다.
