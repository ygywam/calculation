❶ $y = 2x^3 + 3x^2 + 3$의 그래프 분석

$y' = 6x^2 + 6x = 6x(x+1)$이므로 $x=-1$에서 극댓값 $4$, $x=0$에서 극솟값 $3$을 갖습니다.

개념

방정식 $f(x)=0$의 실근의 개수

일반적으로 방정식 $f(x)=0$의 실근은 함수 $y=f(x)$의 그래프와 $x$축의 교점의 $x$좌표와 같다.

따라서 방정식 $f(x)=0$의 서로 다른 실근의 개수는 함수 $y=f(x)$의 그래프와 $x$축의 교점의 개수를 조사하여 구할 수 있다.

$y = f(x)$
교점 1개 $\implies$ 실근 1개
$y = g(x)$
교점 2개(접점 포함) $\implies$ 실근 2개
$y = h(x)$
교점 3개 $\implies$ 실근 3개
예제 1

방정식의 실근의 개수 구하기 (p.96)

방정식 $x^3 - 3x^2 + 1 = 0$의 서로 다른 실근의 개수를 구하시오.

풀이 단계 1. $f(x) = x^3 - 3x^2 + 1$이라 하고 도함수 $f'(x)$를 구합니다.

$$f'(x) = 3x^2 - 6x = 3x(x - 2)$$ $$f'(x) = 0\text{에서 } x = 0 \text{ 또는 } x = 2$$

풀이 단계 2. $f'(x)$의 부호를 조사하여 $f(x)$의 증가와 감소를 표(증감표)로 나타냅니다.

$x$ $\cdots$ $0$ $\cdots$ $2$ $\cdots$
$f'(x)$ $+$ $0$ $-$ $0$ $+$
$f(x)$ $\nearrow$ $1$ (극대) $\searrow$ $-3$ (극소) $\nearrow$

결론: 함수 $y = f(x)$의 그래프는 $x$축과 서로 다른 세 점에서 만나므로 방정식 $x^3 - 3x^2 + 1 = 0$의 서로 다른 실근의 개수는 3이다.

$y = x^3 - 3x^2 + 1$의 그래프와 실근 3개
문제 1

다음 방정식의 서로 다른 실근의 개수를 구하시오. (p.96)

(1) $x^3 - 3x^2 - 9x - 5 = 0$
풀이 및 증감표 열기

$f(x) = x^3 - 3x^2 - 9x - 5$라 하면

$f'(x) = 3x^2 - 6x - 9 = 3(x+1)(x-3) = 0 \implies x = -1, 3$

• 극댓값: $f(-1) = -1 - 3 + 9 - 5 = 0$ ($x$축에 접함!)

• 극솟값: $f(3) = 27 - 27 - 27 - 5 = -32$

따라서 $x=-1$에서 접하고 $x>3$에서 한 번 만나므로 서로 다른 실근의 개수는 2이다.

(2) $2x^4 - 4x^2 + 1 = 0$
풀이 및 증감표 열기

$f(x) = 2x^4 - 4x^2 + 1$이라 하면

$f'(x) = 8x^3 - 8x = 8x(x+1)(x-1) = 0 \implies x = -1, 0, 1$

• 극솟값: $f(-1) = -1$, $f(1) = -1$

• 극댓값: $f(0) = 1$

그래프가 $x$축과 서로 다른 네 점에서 만나므로 실근의 개수는 4이다.

2. 방정식 $f(x)=g(x)$의 실근의 개수와 조건

개념

방정식 $f(x)=g(x)$의 실근의 개수

방정식 $f(x)=g(x)$의 실근은 두 함수 $y=f(x)$, $y=g(x)$의 그래프의 교점의 $x$좌표와 같다. 따라서 방정식 $f(x)=g(x)$의 서로 다른 실근의 개수는 두 함수 $y=f(x)$, $y=g(x)$의 그래프의 교점의 개수를 조사하여 구할 수 있다.

참고: 방정식 $f(x)=g(x)$의 서로 다른 실근의 개수는 이항한 함수 $y = f(x) - g(x)$의 그래프와 $x$축의 교점의 개수를 조사하여 구할 수도 있다. 특히 상수 $a$를 분리하여 $f(x) = a$ 꼴로 만들면 직선 $y=a$를 위아래로 움직이며 쉽게 파악할 수 있다!
예제 2

방정식이 실근을 가질 조건 구하기 (p.97)

방정식 $x^3 + 6x^2 + 9x = a$가 서로 다른 세 실근을 갖도록 하는 실수 $a$의 값의 범위를 구하시오.
$y = x^3 + 6x^2 + 9x$ 와 직선 $y = a$ 현재 교점: 3개 (서로 다른 세 실근!)
직선 $y = a$ 조절 슬라이더 $a = $ -2.0

방정식 $x^3 + 6x^2 + 9x = a$의 실근의 개수는 함수 $y = x^3 + 6x^2 + 9x$의 그래프와 직선 $y = a$의 교점의 개수와 같습니다.

$f(x) = x^3 + 6x^2 + 9x$라 하면
$f'(x) = 3x^2 + 12x + 9 = 3(x+1)(x+3) = 0$
$\implies x = -3 \text{ 또는 } x = -1$
$x$ $\cdots$ $-3$ $\cdots$ $-1$ $\cdots$
$f'(x)$ $+$ $0$ $-$ $0$ $+$
$f(x)$ $\nearrow$ $0$ (극대) $\searrow$ $-4$ (극소) $\nearrow$

직선 $y=a$가 극솟값 $-4$와 극댓값 $0$ 사이를 지나야 세 점에서 만나므로 구하는 범위는:

$-4 < a < 0$

실수 $k$의 값의 범위에 따른 실근의 개수 조사하기 (p.97)

② $k = 0$ 또는 $k = 1$일 때 서로 다른 실근의 개수:

3. 부등식은 어떻게 증명할까?

개념

부등식의 증명 원리

원리 1. $f(x) \ge 0$의 증명

어떤 구간에서 부등식 $f(x) \ge 0$이 성립함을 보이려면 그 구간에서

$(\text{함수 } f(x)\text{의 최솟값}) \ge 0$

임을 보이면 된다.

원리 2. $f(x) \ge g(x)$의 증명

두 식 $A, B$에 대하여 $A \ge B \iff A - B \ge 0$이므로

$h(x) = f(x) - g(x) \ge 0$

라 하고, 그 구간에서 $h(x)$의 최솟값 $\ge 0$임을 보이면 된다.

예제 3

부등식 증명하기 (p.98)

$x \ge 0$일 때, 부등식 $x^3 - 3x + 2 \ge 0$이 성립함을 보이시오.

$f(x) = x^3 - 3x + 2$라고 하면
$$f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$$ $f'(x) = 0$에서 $x = -1$ 또는 $x = 1$입니다.

제한된 구간 $x \ge 0$에서 $f'(x)$의 부호를 조사하여 $f(x)$의 증감표를 그리면 다음과 같습니다.

$x$ $0$ $\cdots$ $1$ $\cdots$
$f'(x)$ $-$ $0$ $+$
$f(x)$ $2$ $\searrow$ $0$ (최소) $\nearrow$

$x \ge 0$일 때, 함수 $f(x)$는 $x=1$에서 최솟값 $0$을 가지므로 $f(x) = x^3 - 3x + 2 \ge 0$이다. 따라서 $x \ge 0$일 때 주어진 부등식이 성립한다. ■

$x < 0$ (점선) vs $x \ge 0$ (실선 강조 영역)
문제 3

다음 부등식이 성립함을 보이시오. (p.98)

(1) $x \ge 0$일 때, $x^2 + x \le x^3 + 1$
증명 과정 펼쳐보기

우변에서 좌변을 뺀 함수를 $f(x) = x^3 - x^2 - x + 1$이라 하자.

$f'(x) = 3x^2 - 2x - 1 = (3x+1)(x-1) = 0 \implies x = -\frac{1}{3}$ 또는 $x = 1$

$x \ge 0$에서 $f(x)$는 $x=1$에서 극소이자 최소가 되며, 최솟값은 $f(1) = 1 - 1 - 1 + 1 = 0$이다.

따라서 $x \ge 0$일 때 $f(x) \ge 0$이므로 $x^2 + x \le x^3 + 1$이 성립한다. ■

(2) 모든 실수 $x$에 대하여 $3x^4 + 32 \ge 4x^3 + 12x^2$
증명 과정 펼쳐보기

$f(x) = 3x^4 - 4x^3 - 12x^2 + 32$라고 하자.

$f'(x) = 12x^3 - 12x^2 - 24x = 12x(x+1)(x-2) = 0 \implies x = -1, 0, 2$

극솟값은 $f(-1) = 3 + 4 - 12 + 32 = 27$, $f(2) = 48 - 32 - 48 + 32 = 0$이다.

모든 실수 $x$에서 함수 $f(x)$의 최솟값은 $f(2) = 0$이므로 $f(x) \ge 0$이다.

따라서 모든 실수 $x$에 대하여 $3x^4 + 32 \ge 4x^3 + 12x^2$이 성립한다. ■

문제 4

부등식이 성립할 미지수 $k$의 범위 (p.98)

$x \ge 0$일 때, 부등식 $\dfrac{1}{3}x^3 - 2x^2 + k > 0$이 성립하도록 하는 실수 $k$의 값의 범위를 구하시오.
정답 선택: $k > $
풀이 보기

$f(x) = \frac{1}{3}x^3 - 2x^2 + k$라 하면 $f'(x) = x^2 - 4x = x(x-4) = 0 \implies x = 0, 4$

$x \ge 0$에서 $f(x)$는 $x=4$일 때 극소이자 최소가 됩니다.

$\text{최솟값 } f(4) = \frac{64}{3} - 32 + k = -\frac{32}{3} + k > 0$

따라서 구하는 실수 $k$의 값의 범위는 $k > \dfrac{32}{3}$이다.

생각 넓히기 (문제해결 · 추론 | p.98)
동일 변수 $x$ vs 서로 다른 독립 변수 $a, b$ 비교!
칠판 문제

"임의의 두 실수 $a, b$에 대하여 $3a^4 - 4a^3 + k \ge -b^2 - 2b$가 성립하기 위한 실수 $k$의 값의 범위를 구하시오."

정우의 생각 (주의!)

"모든 실수 $x$에 대하여 부등식 $3x^4 - 4x^3 + k \ge -x^2 - 2x$가 성립하도록 하는 실수 $k$의 값의 범위를 구하면 되겠지?"

$\rightarrow$ 오류 이유: 정우는 $a=b=x$인 경우만 생각했습니다. 문제에서는 $a$와 $b$가 서로 다르게 움직일 수 있습니다!

보라의 생각 (정답 해법!)

"아니야. $a$와 $b$는 서로 다른 변수이기 때문에 좌변의 식의 최솟값과 우변의 식의 최댓값을 비교해야 해."

$\rightarrow \text{(좌변 } f(a)\text{의 최솟값)} \ge \text{(우변 } g(b)\text{의 최댓값)}$

좌변 $f(a) = 3a^4 - 4a^3 + k$ (파랑) vs 우변 $g(b) = -b^2 - 2b$ (주황) 항상 성립 ($k \ge 2$)
실수 $k$ 값 조절: 2.0 $\min f(a) = $ 1.0

❶ 좌변 $f(a) = 3a^4 - 4a^3 + k$:

$f'(a) = 12a^3 - 12a^2 = 12a^2(a-1) = 0$에서 $a=1$일 때 최솟값 $f(1) = k - 1$

❷ 우변 $g(b) = -b^2 - 2b = -(b+1)^2 + 1$:

$b=-1$일 때 최댓값 $g(-1) = 1$

❸ 결론: $k - 1 \ge 1 \implies \mathbf{k \ge 2}$

• 극댓값: $f(0) = a > 0$

따라서 서로 다른 네 실근을 가질 범위는 $0 < a < 9$이다.
