방정식의 실근의 개수와 미분

🎯

30차시 학습 목표

방정식 $f(x) = 0$의 서로 다른 실근의 개수를 함수 $y = f(x)$의 그래프와 $x$축의 교점의 개수를 조사하여 구하고, 상수항 $a$를 분리하여 곡선과 직선 $y = a$의 위치 관계를 통해 실근의 개수 및 미정계수의 범위를 능숙하게 결정합니다.

생각 열기

방정식의 실근의 개수는 어떻게 구할까?

교과서 95쪽
학생 A 🧑‍🎓
"방정식 $2x^3 + 3x^2 + 3 = 0$의 실근의 개수는 어떻게 구할 수 있을까?"
학생 B 👩‍🎓
"다항식 $2x^3 + 3x^2 + 3$의 유리수 범위 인수분해가 어려운데 어떻게 하지?"
학생 C 🧑‍🏫
"미분을 배워서 함수의 그래프를 그릴 수 있으니, $x$축과의 교점을 이용하면 어떨까?"

함수 $y = 2x^3 + 3x^2 + 3$의 도함수를 구하여 증감을 조사하고, 이 그래프와 $x$축이 만나는 점의 개수를 말해보자.

✏️ 도함수 및 증감표 작성 연습장
개
💡 생각 열기 분석:
1) $y' = 6x^2 + 6x = 6x(x + 1) = 0 \implies x = -1$ 또는 $x = 0$
2) 극댓값 $f(-1) = 2(-1) + 3(1) + 3 = 4$, 극솟값 $f(0) = 3$
3) 극솟값 $f(0) = 3 > 0$이므로 극값 구간에서 그래프가 $x$축보다 완전히 위에 떠 있습니다.
4) 따라서 $x < -1$인 구간에서 $x$축과 오직 1개의 점에서만 만납니다! (실근의 개수 = 1개)

방정식의 실근과 그래프의 교점

1

$f(x) = 0$의 실근의 개수

방정식 $f(x) = 0$의 서로 다른 실근의 개수는 함수 $y = f(x)$의 그래프와 $x$축의 교점의 개수와 같습니다.

실근의 개수 = $y = f(x)$와 $y = 0$ ($x$축)의 교점 수
2

$f(x) = g(x)$의 실근의 개수

방정식 $f(x) = g(x)$의 서로 다른 실근의 개수는 두 곡선 $y = f(x)$와 $y = g(x)$의 교점의 개수와 같습니다.

또는 $h(x) = f(x) - g(x) = 0$으로 이항하여 판정!
예제 1

방정식의 서로 다른 실근의 개수 구하기

교과서 96쪽

방정식 $x^3 - 3x^2 + 1 = 0$의 서로 다른 실근의 개수를 구하시오.

$f(x) = x^3 - 3x^2 + 1$이라고 하면
$f'(x) = 3x^2 - 6x = 3x(x - 2)$
$f'(x) = 0$에서 $x = 0$ 또는 $x = 2$입니다.
$x$ $\cdots$ 0 $\cdots$ 2 $\cdots$
$f'(x)$ $+$ 0 $-$ 0 $+$
$f(x)$ $\nearrow$ 1 (극대) $\searrow$ -3 (극소) $\nearrow$
극댓값이 $1 > 0$이고 극솟값이 $-3 < 0$이므로, 함수 $y = f(x)$의 그래프는 $x$축과 서로 다른 세 점에서 만납니다.
따라서 방정식 $x^3 - 3x^2 + 1 = 0$의 서로 다른 실근의 개수는 3입니다.

문제 2 k의 범위에 따른 실근의 개수 조사

방정식 $2x^3 - 3x^2 + k = 0$의 서로 다른 실근의 개수가 다음과 같도록 하는 실수 $k$의 값 또는 범위를 구하시오.

✏️ g(x) = -2x³ + 3x² = k 분리 및 미분 연습장
💡 상세 해설:
1) $2x^3 - 3x^2 = -k$ 또는 $f(x) = 2x^3 - 3x^2 + k$로 둡니다.
2) $f'(x) = 6x^2 - 6x = 6x(x - 1) = 0 \implies x = 0, 1$
3) 극댓값 $f(0) = k$, 극솟값 $f(1) = 2 - 3 + k = k - 1$
4) 결론:
  • 세 실근: 극대 $> 0$, 극소 $< 0 \implies k > 0$ 이고 $k - 1 < 0 \implies \mathbf{0 < k < 1}$
  • 두 실근: 극대 $= 0$ 또는 극소 $= 0 \implies \mathbf{k = 0 \text{ 또는 } k = 1}$
  • 한 실근: 극대, 극소가 모두 양수이거나 모두 음수 $\implies \mathbf{k < 0 \text{ 또는 } k > 1}$

부등식의 증명과 수학적 추론

🏆

31차시 학습 목표

미분을 이용하여 함수의 그래프 개형과 최솟값을 구함으로써 어떤 구간에서 부등식 $f(x) \ge 0$이 항상 성립함을 증명하고, 서로 다른 두 변수를 포함하는 부등식의 조건을 수학적으로 엄밀하게 추론합니다.

미분을 이용한 부등식 증명의 3원칙

1

모든 실수에서 $f(x) \ge 0$

실수 전체에서 함수 $f(x)$의 최솟값을 찾아,
[함수 $f(x)$의 최솟값] $\ge 0$임을 보이면 충분합니다!

2

$x \ge a$ 구간에서 $f(x) \ge 0$

제한된 구간 $x \ge a$에서 함수 $f(x)$의 최솟값을 구하여
($x \ge a$에서 최솟값) $\ge 0$임을 증명합니다.

3

두 식의 비교 $f(x) \ge g(x)$

모든 항을 좌변으로 이항하여
$h(x) = f(x) - g(x) \ge 0$의 형태로 만든 뒤 최솟값을 조사합니다.

💡
핵심 논리: "가장 작은 꼴찌(최솟값)가 0 이상이면, 나머지 모든 값은 당연히 0 이상이다!" 부등식 증명의 본질은 최솟값 추적입니다.
예제 3

구간에서 부등식의 성립 증명하기

교과서 98쪽

$x \ge 0$일 때, 부등식 $x^3 - 3x + 2 \ge 0$이 성립함을 보이시오.

$f(x) = x^3 - 3x + 2$라고 하면
$f'(x) = 3x^2 - 3 = 3(x + 1)(x - 1)$
$f'(x) = 0$에서 $x = -1$ 또는 $x = 1$입니다.
이때 $x \ge 0$이므로 고려해야 할 극값 위치는 $x = 1$입니다.
$x$ 0 $\cdots$ 1 $\cdots$
$f'(x)$ $-$ 0 $+$
$f(x)$ 2 $\searrow$ 0 (최소) $\nearrow$
$x \ge 0$일 때, 함수 $f(x)$의 최솟값은 $f(1) = 0$입니다.
최솟값이 0이므로, $x \ge 0$인 모든 $x$에 대하여 $f(x) \ge 0$이 성립합니다.
따라서 $x \ge 0$일 때, 부등식 $x^3 - 3x + 2 \ge 0$이 성립합니다. (증명 완료)
✏️ 예제 3 연습장 (증감표 및 최솟값 계산)
문제 3-⑴ 제한된 범위에서의 부등식 증명
교과서 98쪽

$x \ge 0$일 때, 부등식 $x^2 + x \le x^3 + 1$이 성립함을 보이시오.

✏️ 이항식 f(x) = x³ - x² - x + 1 미분 연습장
[증명] 모든 항을 우변으로 이항하여 $f(x) = x^3 - x^2 - x + 1$이라 하자.
1) $f'(x) = 3x^2 - 2x - 1 = (3x + 1)(x - 1) = 0 \implies x \ge 0$에서 $x = 1$
2) $x \ge 0$에서 증감표: $x = 0$일 때 $f(0) = 1$, $x = 1$에서 극소이자 최솟값 $f(1) = 1 - 1 - 1 + 1 = 0$
3) 따라서 $x \ge 0$일 때 $f(x) \ge 0$이므로 $x^2 + x \le x^3 + 1$이 항상 성립합니다.
문제 3-⑵ 모든 실수에서의 사차부등식 증명
교과서 98쪽

모든 실수 $x$에 대하여 부등식 $3x^4 + 32 \ge 4x^3 + 12x^2$이 성립함을 보이시오.

✏️ f(x) = 3x⁴ - 4x³ - 12x² + 32 미분 연습장
[증명] $f(x) = 3x^4 - 4x^3 - 12x^2 + 32$라 하자.
1) $f'(x) = 12x^3 - 12x^2 - 24x = 12x(x^2 - x - 2) = 12x(x - 2)(x + 1) = 0 \implies x = -1, 0, 2$
2) 극값 조사:
  • $f(-1) = 3 + 4 - 12 + 32 = 27$ (극소)
  • $f(0) = 32$ (극대)
  • $f(2) = 48 - 32 - 48 + 32 = \mathbf{0}$ (극소이자 전체 최솟값!)
3) 실수 전체에서 $f(x)$의 최솟값은 $f(2) = 0 \ge 0$이므로 모든 실수 $x$에 대하여 $f(x) \ge 0$이 성립합니다.

k = 11.5

📊 실시간 부등식 상태 부등식 항상 성립! (f(x) > 0) ✨
최솟값 위치 ($x$): x = 4
최솟값 $f(4) = k - \frac{32}{3}$: +0.83
부등식 성립 여부: 성립 (TRUE)

문제 4 부등식이 성립하기 위한 실수 k의 범위
교과서 98쪽

$x \ge 0$일 때, 부등식 $\frac{1}{3}x^3 - 2x^2 + k > 0$이 성립하도록 하는 실수 $k$의 값의 범위를 구하시오.

✏️ f'(x) = x² - 4x = 0 및 최솟값 계산 연습장
실수 $k$의 값의 범위를 선택하세요:
💡 상세 해설:
1) $f(x) = \frac{1}{3}x^3 - 2x^2 + k$라 하면 $f'(x) = x^2 - 4x = x(x - 4) = 0 \implies x \ge 0$에서 $x = 4$
2) $x \ge 0$에서 증감표: $0 < x < 4$에서 감소, $x > 4$에서 증가하므로 $x = 4$에서 최솟값을 갖습니다.
3) 최솟값: $f(4) = \frac{1}{3}(64) - 2(16) + k = \frac{64}{3} - 32 + k = k - \frac{32}{3}$
4) 문제의 부등호가 등호 없는 엄격한 부등호($> 0$)이므로 최솟값이 0보다 커야 합니다:
$k - \frac{32}{3} > 0 \implies \mathbf{k > \frac{32}{3}}$

다음 부등식에 대한 정우와 보라의 대화를 읽고, 부등식이 성립하기 위한 실수 $k$의 값의 범위를 구해 보자.
"임의의 두 실수 $a, b$에 대하여 $3a^4 - 4a^3 + k \ge -b^2 - 2b$가 성립하기 위한 실수 $k$의 값의 범위를 구하시오."

정우의 생각 🧑‍🎓 흔한 착각!

"모든 실수 $x$에 대하여 부등식 $3x^4 - 4x^3 + k \ge -x^2 - 2x$가 성립하도록 하는 $k$의 범위를 구하면 되겠지?"

⚠️ 오류 지적: 문제에서 $a$와 $b$는 서로 다른 독립 변수입니다! 동일한 $x$로 묶어 이항하는 것은 $a = b$인 특수한 경우만 다루는 것이므로 잘못된 풀이입니다.
보라의 생각 👩‍🎓 수학적 정답!

"아니야. $a$와 $b$는 서로 다른 변수이기 때문에 좌변 식의 최솟값과 우변 식의 최댓값을 비교해야 해!"

✨ 정답 논리: 임의의 $a, b$에 대해 $f(a) \ge g(b)$가 되려면, $f(a)$의 최솟값이 $g(b)$의 최댓값보다 크거나 같아야만 어떠한 $a, b$를 뽑아도 항상 성립합니다!
📝 보라의 논리에 따른 엄밀한 풀이:
• 좌변: $f(a) = 3a^4 - 4a^3 + k \implies f'(a) = 12a^2(a - 1) = 0 \implies a = 1$에서 최솟값 $f(1) = k - 1$
• 우변: $g(b) = -b^2 - 2b = -(b + 1)^2 + 1 \implies b = -1$에서 최댓값 $g(-1) = 1$
• 부등식 $f(a) \ge g(b)$가 항상 성립하려면:
$[f(a)\text{의 최솟값}] \ge [g(b)\text{의 최댓값}] \implies k - 1 \ge 1 \implies \mathbf{k \ge 2}$

✏️ 미분 연습장

교과서 99쪽

모든 실수 $x$에 대하여 부등식 $x^4 - 4x^3 + 27 \ge 0$이 성립함을 보이시오.

✏️ 미분 및 최솟값 계산 연습장
[증명] $f(x) = x^4 - 4x^3 + 27$이라 하자.
1) $f'(x) = 4x^3 - 12x^2 = 4x^2(x - 3) = 0 \implies x = 0$ (중근), $x = 3$ (극소)
2) 증감표에 의해 $x < 3$에서 감소하고 $x > 3$에서 증가하므로, 함수 $f(x)$는 $x = 3$에서 유일한 극소이자 최솟값을 갖습니다.
3) 최솟값: $f(3) = 3^4 - 4(3^3) + 27 = 81 - 108 + 27 = \mathbf{0}$
4) 최솟값이 $0 \ge 0$이므로 모든 실수 $x$에 대하여 $f(x) \ge 0$이 성립합니다. (증명 완료)

✏️ g(x) = -x⁴ + 6x² = a 분리 및 미분 연습장
실수 $a$의 값의 범위를 선택하세요:
💡 상세 풀이:
1) $x^4 - 6x^2 = -a$로 두거나, $g(x) = -x^4 + 6x^2 = a$로 분리합니다.

곡선 $y = 2x^3 + 3x^2$과 직선 $y = 12x + k$가 서로 다른 두 점에서 만나도록 하는 양수 $k$의 값을 구하시오.

✏️ 2x³ + 3x² - 12x = k 미분 연습장
💡 상세 풀이:
1) $2x^3 + 3x^2 - 12x = k$로 두고 $f(x) = 2x^3 + 3x^2 - 12x$라 하자.
2) $f'(x) = 6x^2 + 6x - 12 = 6(x^2 + x - 2) = 6(x + 2)(x - 1) = 0 \implies x = -2, 1$
3) 극댓값: $f(-2) = 2(-8) + 3(4) - 12(-2) = -16 + 12 + 24 = \mathbf{20}$
4) 극솟값: $f(1) = 2 + 3 - 12 = \mathbf{-7}$
5) 곡선과 직선이 서로 다른 두 점에서 만나려면(접선이 되려면) $k$가 극댓값이거나 극솟값이어야 하므로 $k = 20$ 또는 $k = -7$입니다.
6) 문제에서 양수 $k$를 구하라고 하였으므로 구하는 정답은 20입니다.

치환을 활용한 고난도 부등식 증명

교과서 99쪽

부등식 $(x^2 + 1)^3 - 12(x^2 + 1) \ge k$에 대하여 모든 실수 $x$에 대하여 성립하도록 하는 실수 $k$의 최댓값을 구하시오.

✏️ t = x² + 1 ≥ 1 치환 및 g(t) = t³ - 12t 미분 연습장
💡 단계별 해설:
⑴ $x^2 \ge 0$이므로 $t = x^2 + 1 \implies \mathbf{t \ge 1}$ (정의역 치환!)
⑵ $t$에 대한 부등식: $t^3 - 12t \ge k \quad (t \ge 1)$
⑶ $g(t) = t^3 - 12t$라 하면 $g'(t) = 3t^2 - 12 = 3(t - 2)(t + 2) = 0 \implies t \ge 1$에서 $t = 2$
⑷ $t \ge 1$에서 $t = 2$일 때 극소이자 최솟값: $g(2) = 8 - 24 = \mathbf{-16}$
⑸ 최솟값이 $k$ 이상이어야 하므로 $-16 \ge k \implies k \le -16$. 따라서 $k$의 최댓값은 -16입니다.
