32차시 학습 목표

생각 열기

방정식의 실근의 개수는 어떻게 구할까?

교과서 95쪽

함수 $y = 2x^3 + 3x^2 + 3$의 도함수를 구하여 증감을 조사하고, 이 그래프와 $x$축이 만나는 점의 개수를 구해보자.

개
생각열기 단계별 풀이
$f(x) = 2x^3 + 3x^2 + 3$에서 도함수는
$$f'(x) = 6x^2 + 6x = 6x(x + 1)$$
$f'(x) = 0$에서 $x = -1$ 또는 $x = 0$입니다.
증감표를 작성하면 다음과 같습니다:
  • $x < -1$ : $f'(x) > 0$ (증가)
  • $x = -1$ : 극댓값 $f(-1) = 2(-1)^3 + 3(-1)^2 + 3 = 4$
  • $-1 < x < 0$ : $f'(x) < 0$ (감소)
  • $x = 0$ : 극솟값 $f(0) = 3$
  • $x > 0$ : $f'(x) > 0$ (증가)
💡 판정: 극솟값 $f(0) = 3 > 0$이므로 극소점 $(0, 3)$조차 $x$축보다 완전히 위에 위치합니다. 따라서 그래프는 $x < -1$ 구간에서 $x$축과 오직 한 점에서만 만납니다. (교점의 개수 = 1개)

방정식의 실근과 그래프의 교점

01 $f(x) = 0$의 실근

방정식 $f(x) = 0$의 서로 다른 실근의 개수는 함수 $y = f(x)$의 그래프와 $x$축과의 교점의 개수와 같습니다.

$y = f(x)$와 $x$축 ($y = 0$)의 교점
02 $f(x) = g(x)$의 실근

방정식 $f(x) = g(x)$의 서로 다른 실근의 개수는 두 곡선 $y = f(x)$와 $y = g(x)$의 교점의 개수와 같습니다.

$y = f(x)$와 $y = g(x)$의 교점
03 미정계수 분리법

방정식 $f(x) - k = 0$은 $f(x) = k$로 변형하여, 고정된 곡선 $y = f(x)$와 움직이는 수평선 $y = k$의 교점으로 관찰합니다.

$y = f(x)$와 수평선 $y = k$의 교점
예제 1

방정식의 서로 다른 실근의 개수 구하기

교과서 96쪽

방정식 $x^3 - 3x^2 + 2 = 0$의 서로 다른 실근의 개수를 구하시오.

💡 정석 풀이 과정:
$f(x) = x^3 - 3x^2 + 2$로 놓으면
$$f'(x) = 3x^2 - 6x = 3x(x - 2)$$
$f'(x) = 0$에서 $x = 0$ 또는 $x = 2$입니다.
함수 $f(x)$의 극값을 조사하면:
  • 극댓값: $f(0) = \mathbf{2} > 0$
  • 극솟값: $f(2) = 2^3 - 3(2^2) + 2 = 8 - 12 + 2 = \mathbf{-2} < 0$
💡 판정: 극댓값은 양수($> 0$)이고 극솟값은 음수($< 0$)이므로, 삼차함수 그래프는 $x$축과 서로 다른 3점에서 교차합니다.
따라서 주어진 방정식의 서로 다른 실근의 개수는 3개입니다.

예제 2

방정식이 서로 다른 세 실근을 가질 조건

교과서 97쪽

방정식 $2x^3 - 3x^2 - 12x - k = 0$이 서로 다른 세 실근을 갖도록 하는 실수 $k$의 값의 범위를 구하시오.

💡 정석 풀이 과정:
상수 $k$를 우변으로 이항하여 $2x^3 - 3x^2 - 12x = k$로 놓습니다.
$f(x) = 2x^3 - 3x^2 - 12x$라 하면
$$f'(x) = 6x^2 - 6x - 12 = 6(x^2 - x - 2) = 6(x+1)(x-2)$$
$f'(x) = 0$에서 $x = -1$ 또는 $x = 2$입니다.
함수 $f(x)$의 극값을 구하면:
  • 극댓값: $f(-1) = 2(-1) - 3(1) - 12(-1) = -2 - 3 + 12 = \mathbf{7}$
  • 극솟값: $f(2) = 2(8) - 3(4) - 12(2) = 16 - 12 - 24 = \mathbf{-20}$
💡 판정: 곡선 $y = f(x)$와 수평선 $y = k$가 서로 다른 3점에서 만나려면, $k$가 극솟값과 극댓값 사이에 위치해야 합니다.
따라서 실수 $k$의 값의 범위는 $-20 < k < 7$ 입니다.
문제 2

방정식 $2x^3 - 3x^2 + k = 0$의 실근 조건 분석

교과서 97쪽

방정식 $2x^3 - 3x^2 + k = 0$의 서로 다른 실근의 개수가 다음과 같도록 하는 실수 $k$의 값 또는 범위를 구하시오.

💡 문제 2 상세 풀이:
방정식을 $-2x^3 + 3x^2 = k$로 놓거나, $f(x) = 2x^3 - 3x^2 + k$ 자체의 극값을 분석합니다.
$f'(x) = 6x^2 - 6x = 6x(x-1) = 0 \implies x = 0$ 또는 $x = 1$
극댓값: $f(0) = k$, 극솟값: $f(1) = 2 - 3 + k = k - 1$
⑴ 서로 다른 세 실근: 극댓값과 극솟값의 부호가 달라야 하므로 $f(0) > 0$이고 $f(1) < 0 \implies k > 0$ 이고 $k - 1 < 0 \implies \mathbf{0 < k < 1}$
⑵ 서로 다른 두 실근: 극값 중 하나가 0이어야 하므로 $f(0) = 0$ 또는 $f(1) = 0 \implies \mathbf{k = 0 \text{ 또는 } k = 1}$
⑶ 오직 한 실근: 두 극값의 부호가 같아야 하므로 $f(0)f(1) > 0 \implies k(k-1) > 0 \implies \mathbf{k < 0 \text{ 또는 } k > 1}$

미분을 이용한 부등식 증명의 3원칙

원칙 1 모든 실수에서 $f(x) \ge 0$

함수 $f(x)$의 (최솟값) $\ge 0$임을 보이면 충분합니다. 꼴찌가 0 이상이면 전원이 0 이상입니다!

$f(x)\text{의 최솟값} \ge 0 \implies f(x) \ge 0$
원칙 2 $x \ge a$ 구간에서 $f(x) \ge 0$

$x \ge a$에서의 최솟값 $\ge 0$이거나, 출발점 $f(a) \ge 0$이고 $x > a$에서 $f'(x) \ge 0$(증가)임을 보입니다.

$f(a) \ge 0 \text{ 이고 } f'(x) \ge 0 \implies f(x) \ge 0$
원칙 3 두 식의 비교 $f(x) \ge g(x)$

차의 함수 $h(x) = f(x) - g(x)$로 치환하여 $h(x) \ge 0$의 최솟값 문제로 변환하여 해결합니다.

$h(x) = f(x) - g(x) \ge 0\text{의 최솟값 탐색}$

문제 4

구간에서 부등식이 항상 성립할 조건

교과서 98쪽

$x > 0$일 때, 부등식 $\frac{1}{3}x^3 - 2x^2 + k > 0$이 항상 성립하도록 하는 실수 $k$의 값의 범위를 구하시오.

풀이:
$f(x) = \frac{1}{3}x^3 - 2x^2 + k$로 놓으면 $f'(x) = x^2 - 4x = x(x-4)$ 입니다.
$x > 0$ 범위에서 $f'(x) = 0$인 점은 오직 $x = 4$뿐이며, $0 < x < 4$에서 $f'(x) < 0$ (감소), $x > 4$에서 $f'(x) > 0$ (증가)합니다.
따라서 $f(x)$는 $x = 4$에서 최솟값을 갖습니다:
$$f(4) = \frac{1}{3}(64) - 2(16) + k = \frac{64}{3} - 32 + k = k - \frac{32}{3}$$
모든 $x > 0$에서 $f(x) > 0$이 성립하려면 (최솟값) > 0 이어야 하므로:
$k - \frac{32}{3} > 0 \implies \mathbf{k > \frac{32}{3}}$ 입니다. (정답: ①)

문항 01

개념 되새기기 O/X 퀴즈

⑴ 삼차방정식 $f(x) = 0$에서 $(\text{극댓값}) \times (\text{극솟값}) < 0$이면 서로 다른 세 실근을 갖는다.
⑵ $x \ge a$에서 부등식 $f(x) \ge 0$이 성립하려면 구간에서의 $f(x)$의 최솟값이 0 이상이어야 한다.
해설:
⑴ 참(O): 극댓값과 극솟값의 부호가 다르면 $x$축이 두 극값 사이에 위치하므로 서로 다른 3점에서 교차합니다.
⑵ 참(O): 구간 $x \ge a$에서 최솟값이 0 이상이면 모든 $x \ge a$에 대하여 $f(x) \ge \text{최솟값} \ge 0$이므로 항상 성립합니다.

개
⑵ $x^3 + 3x^2 - 4 = 0$
개

문항 03

사차부등식의 성립 증명하기

모든 실수 $x$에 대하여 부등식 $x^4 - 4x^3 + 27 \ge 0$이 성립함을 증명하시오.

💡 증명 과정:
$f(x) = x^4 - 4x^3 + 27$로 놓으면
$$f'(x) = 4x^3 - 12x^2 = 4x^2(x - 3)$$
$f'(x) = 0$인 $x$는 $x = 0$ 또는 $x = 3$입니다.
$x < 3$에서 $f'(x) \le 0$이고 $x > 3$에서 $f'(x) > 0$이므로, 함수 $f(x)$는 $x = 3$에서 극소이면서 최솟값을 갖습니다.
$$f(3) = 3^4 - 4(3^3) + 27 = 81 - 108 + 27 = \mathbf{0}$$
따라서 모든 실수 $x$에 대하여 $f(x) \ge f(3) = 0$이 성립합니다. (Q.E.D.)
문항 04

방정식이 서로 다른 네 실근을 가질 조건

사차방정식 $x^4 - 6x^2 + a = 0$이 서로 다른 네 실근을 갖도록 하는 실수 $a$의 값의 범위를 구하시오.

풀이:
방정식을 $-x^4 + 6x^2 = a$로 변형하고 $f(x) = -x^4 + 6x^2$로 둡니다.
$f'(x) = -4x^3 + 12x = -4x(x^2 - 3) = 0 \implies x = 0, \pm\sqrt{3}$
극솟값: $f(0) = \mathbf{0}$, 극댓값: $f(\pm\sqrt{3}) = -9 + 18 = \mathbf{9}$
W자형 뒤집힌 M자형 곡선과 $y = a$가 4점에서 만나려면 극소와 극대 사이여야 하므로 $\mathbf{0 < a < 9}$ 입니다. (정답: ①)
문항 05

곡선과 직선이 서로 다른 두 점에서 만날 조건

곡선 $y = 2x^3 + 3x^2 - 12x$와 직선 $y = k$가 서로 다른 두 점에서만 만나도록 하는 양수 $k$의 값을 구하시오.

풀이:
$f(x) = 2x^3 + 3x^2 - 12x \implies f'(x) = 6x^2 + 6x - 12 = 6(x+2)(x-1) = 0$
극댓값: $f(-2) = 2(-8) + 3(4) - 12(-2) = -16 + 12 + 24 = \mathbf{20}$
극솟값: $f(1) = 2 + 3 - 12 = \mathbf{-7}$
서로 다른 두 점에서 만나려면 직선 $y = k$가 극대 또는 극소에 접해야 합니다 ($k = 20$ 또는 $k = -7$).
문제에서 양수 $k$를 요구하였으므로 정답은 $\mathbf{20}$입니다.
문항 06

치환을 활용한 고난도 부등식 증명

부등식 $(x^2 + 1)^3 - 12(x^2 + 1) \ge k$가 모든 실수 $x$에 대하여 성립하도록 하는 실수 $k$의 최댓값을 구하시오.

풀이 (치환을 이용한 해결):
$x^2 \ge 0$이므로 $t = x^2 + 1$로 치환하면 $t \ge 1$입니다.
$g(t) = t^3 - 12t$ ($t \ge 1$)의 최솟값을 구합니다:
$g'(t) = 3t^2 - 12 = 3(t+2)(t-2) = 0$이므로 $t \ge 1$에서 극소점은 $t = 2$입니다.
$g(1) = 1 - 12 = -11$, 극솟값 $g(2) = 8 - 24 = \mathbf{-16}$
따라서 $t \ge 1$에서 함수 $g(t)$의 최솟값은 $-16$입니다.
모든 실수 $x$에서 $g(t) \ge k$가 성립하려면 $k \le \text{최솟값} = -16$이어야 하므로, 실수 $k$의 최댓값은 $\mathbf{-16}$입니다.
