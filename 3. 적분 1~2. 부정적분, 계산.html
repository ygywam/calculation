📖 부정적분의 정의와 기호 표기법

함수 $F(x)$의 도함수가 $f(x)$일 때, 즉 $F'(x) = f(x)$일 때, $F(x)$를 $f(x)$의 부정적분(원시함수, Antiderivative)이라고 하며, 다음과 같이 나타냅니다.

※ 하나의 피적분함수 $f(x)$에 대하여 부정적분은 적분상수 $C$에 따라 무수히 많이 정해지므로 '정해지지 않은(不定, Indefinite) 적분'이라 부릅니다.

⚡ 미분과 적분의 관계: 연산 순서에 따른 적분상수 $C$의 유무

관계 1 적분한 후 미분하기
$$\frac{d}{dx} \left( \int f(x)\,dx \right) = \mathbf{f(x)}$$

$\int f(x)dx = F(x) + C$를 $x$에 대해 다시 미분하면, 상수 $C$는 미분되어 $0$이 되므로 알맹이 함수 $f(x)$가 그대로 튀어나옵니다!

관계 2 미분한 후 적분하기
$$\int \left( \frac{d}{dx} f(x) \right) dx = \mathbf{f(x) + C}$$

$f'(x)$를 다시 적분하면 원함수 $f(x)$로 복원되지만, 마지막에 적분 연산을 수행했으므로 반드시 적분상수 $+ C$가 남게 됩니다!

🎯 38차시 개념 자가진단 (O/X 퀴즈)

1. $\frac{d}{dx} \left(\int f(x)\,dx\right) = f(x)$ 이다. (O/X)
2. $\int \left(\frac{d}{dx} f(x)\right)\,dx = f(x)$ 이다. (O/X)
3. 도함수가 같은 두 함수 $F(x), G(x)$의 차 $F(x) - G(x)$는 항상 상수이다. (O/X)

핵심 정리 2 (121쪽)

부정적분의 3대 기본 성질 (선형성, Linearity)

미분의 성질 $(kf)'=kf'$, $(f \pm g)' = f' \pm g'$로부터 부정적분의 3대 연산 성질이 도출됩니다.

1 상수배(실수배)
$$\int k f(x)\,dx = k \int f(x)\,dx$$

0이 아닌 상수는 적분 기호 밖으로 자유롭게 드나들 수 있습니다.

2 두 함수의 합
$$\int \{f(x)+g(x)\}\,dx = \int f(x)\,dx + \int g(x)\,dx$$

각 항별로 따로따로 적분한 뒤 더할 수 있습니다.

3 두 함수의 차
$$\int \{f(x)-g(x)\}\,dx = \int f(x)\,dx - \int g(x)\,dx$$

각 항별로 따로 적분한 뒤 뺄 수 있습니다.

⚠️ [오개념 방지] 곱이나 몫으로 이루어진 식의 적분 주의사항 (122쪽)

✕ 절대 금지: $\int f(x)g(x)\,dx \ne \left(\int f(x)\,dx\right)\left(\int g(x)\,dx\right)$

예를 들어 $x^3 = x \times x^2$이지만, $\int x^3\,dx = \frac{1}{4}x^4 + C$이고, 각각 적분해 곱하면 $(\frac{1}{2}x^2)(\frac{1}{3}x^3) = \frac{1}{6}x^5$가 되어 차수부터 완전히 달라집니다!

💡 해결 원칙: 곱이나 분수 꼴로 된 다항식은 반드시 먼저 식을 전개하거나 인수분해하여 약분한 후, 합·차의 꼴로 만들어 항별로 적분해야 합니다!

• (2) $f'(x) = 18x - 2$를 적분하면 $f(x) = 9x^2 - 2x + C$.
$f(-1) = 9(-1)^2 - 2(-1) + C = 9 + 2 + C = 11 + C = 2 \implies C = -9$.
따라서 $f(x) = 9x^2 - 2x - 9$ 이므로, $f(1) = 9 - 2 - 9 = \mathbf{-2}$ 입니다.
12번 발전 / 삼차함수의 극대·극소와 부정적분

도함수가 $f'(x) = 3x^2 - 6x$인 삼차함수 $f(x)$의 극댓값이 $5$일 때, 함수 $f(x)$의 극솟값을 구하시오.

✏️ 12번 극대·극소 좌표 판정 및 계산 연습장
[정답 및 해설] $f'(x) = 3x(x - 2) = 0$에서 $x = 0$ 또는 $x = 2$.
$f'(x)$의 부호가 양에서 음으로 바뀌는 $x=0$에서 극대, 음에서 양으로 바뀌는 $x=2$에서 극소입니다.
$f(x) = \int (3x^2 - 6x)\,dx = x^3 - 3x^2 + C$. 극댓값이 $5$이므로 $f(0) = C = 5$.
따라서 $f(x) = x^3 - 3x^2 + 5$이고, 극솟값은 $f(2) = 2^3 - 3(2)^2 + 5 = 8 - 12 + 5 = \mathbf{1}$ 입니다.
